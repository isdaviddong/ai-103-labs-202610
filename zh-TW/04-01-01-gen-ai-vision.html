開發具備視覺功能的聊天應用程式

在本練習中，您將使用 generative AI model，針對包含影像的 prompt 產生回應。您將使用 Microsoft Foundry 和 OpenAI SDK 開發應用程式，為雜貨店的新鮮農產品提供 AI 協助。

雖然本練習以 OpenAI Python SDK 為基礎，但您也可以使用各種語言專用的 SDK 開發 AI 聊天應用程式，包括：

  • OpenAI Projects for Microsoft .NET
  • OpenAI Projects for JavaScript

本練習大約需要 30 分鐘。

注意：本練習使用的部分技術仍處於預覽階段或積極開發中。您可能會遇到非預期的行為、警告或錯誤。

必要條件

開始本練習前，請確認您已具備：

  • 有效的 Azure 訂用帳戶
  • Visual Studio Code 已安裝
  • Python 版本 3.13.xx 已安裝*
  • Git 已安裝並設定
  • Azure CLI 已安裝

* Python 3.14 已推出，但部分相依套件尚未針對該版本編譯。本實驗已使用 Python 3.13.12 成功測試。

建立 Microsoft Foundry project

Microsoft Foundry 使用 project 來組織開發 AI 解決方案所用的 model、resource、資料及其他資產。

  1. 在網頁瀏覽器中，開啟 Microsoft Foundry portal ，網址為 https://ai.azure.com 以開始建置；請使用 Azure 認證登入。關閉首次登入時開啟的所有提示或快速入門窗格。

  2. 如果尚未啟用，請在頁面頂端的工具列啟用 New Foundry 選項。接著，如果出現提示，請建立名稱唯一的新 project；展開 Advanced options 區域，為 project 指定下列設定：
    • Foundry resource: 使用 resource 的預設名稱（通常為 {project_name}-resource）
    • Subscription: 您的 Azure 訂用帳戶
    • Resource group: 建立或選取 resource group
    • Region：選取任何可用的區域

  3. 等待 project 建立完成。然後在 project 首頁上，留意此處顯示的 API key、project endpoint 和 Azure OpenAI endpoint。

    提示：稍後會用到 Azure OpenAI endpoint！

部署 model

您需要能處理影像輸入的 model。

  1. 現在您已準備好探索 model。在 Discover 頁面上，選取 Models 索引標籤，以檢視 Microsoft Foundry model catalog。

  2. 搜尋並使用預設設定部署 gpt-5.2 model。部署可能需要約一分鐘。

    提示：model deployment 受區域配額限制。如果 project 所在區域的配額不足以部署該 model，您可以改用其他 model，例如 gpt-5.2-mini 或 gpt-4o。或者，您可以在其他區域建立新的 project。

  3. model 部署完成後，請檢視開啟的 model playground 頁面，您可以在其中與 model 聊天。

    提示：記下 model deployment 名稱（預設應為 gpt-5.2）—稍後會用到！

在 playground 中測試 model

現在您可以在 chat playground 中使用影像 prompt 測試 model deployment。

  1. 在新的瀏覽器索引標籤中，下載 mango.jpeg ，來源為 https://microsoftlearning.github.io/mslearn-ai-vision/Labfiles/gen-ai-vision/mango.jpeg ，並將其儲存至本機檔案系統中的資料夾。

  2. 返回 Foundry portal 中 model deployment 的 chat playground 頁面。

  3. 在主要聊天工作階段面板中，使用聊天輸入方塊下方的附件按鈕（📎）上傳 mango.jpeg 影像檔案，然後加入文字 What desserts could I make with this fruit? 並提交 prompt。

  4. 檢閱回應，確認其中是否提供使用芒果製作甜點的相關建議。

建立用戶端應用程式

既然已部署 model，您便可以在用戶端應用程式中使用此 deployment。

從 GitHub 取得應用程式檔案

開發翻譯應用程式所需的初始應用程式檔案，已提供於 GitHub repo 中。

  1. 開啟 Visual Studio Code。

  2. 開啟命令選擇區（Ctrl+Shift+P），並使用 Git:clone 命令將 https://github.com/microsoftlearning/mslearn-ai-vision repo 複製到本機資料夾（任意資料夾皆可）。然後開啟它。

    系統可能會提示您確認是否信任作者。

  3. 在 Visual Studio Code 中，檢視 Extensions 窗格；如果尚未安裝，請安裝 Python 擴充功能。

  4. 在 Command Palette中，使用命令 python:select interpreter。如果您已有環境，請選取現有環境，或根據已安裝的 Python 3.13.x 建立新的 Venv 環境。

    提示：如果系統提示您安裝相依套件，可以安裝 requirements.txt 檔案中列出的套件，此檔案位於 labfiles/gen-ai-vision/python 資料夾；不安裝也沒關係，稍後我們會進行安裝！

準備應用程式設定

  1. 複製 repo 後，在 VS Code 中開啟資料夾（File > Open Folder），並瀏覽至 Labfiles/gen-ai-vision/python 資料夾。

  2. 在 VS Code 的 Explorer 窗格中，檢閱資料夾內的檔案：

    • .env —應用程式設定的組態檔。
    • image-chat-app.py —影像應用程式的 Python 程式碼檔案。
    • requirements.txt —列出相依套件的檔案。
    • mystery-fruit.jpeg —水果影像。

  3. 在 Explorer 窗格中的 python 資料夾內，選取 .env 檔案以開啟它。接著更新設定值，加入 Foundry resource 的 Azure OpenAI endpoint ，以及已部署的 generative AI model 的 model deployment 名稱。

    重要：請務必加入 https://{foundry-resource-name}.openai.azure.com/openai/v1/ Azure OpenAI endpoint， 而不是 project endpoint！

    儲存修改後的組態檔。

  4. 在 Explorer 窗格中，以滑鼠右鍵按一下 python 資料夾（其中包含應用程式檔案），並選取 Open in integrated terminal （或在 Terminal 功能表中開啟終端機，然後瀏覽至 labfiles/gen-ai-vision/python 資料夾）。

    注意：在 Visual Studio Code 中開啟終端機會自動啟用 Python 環境。您可能需要在系統上啟用 script 執行。

  5. 確認終端機目前位於 Labfiles/gen-ai-vision/python 資料夾，且帶有前綴 (.venv) ，表示您建立的 Python 環境已啟用。

  6. 執行下列命令以安裝必要的 Python 套件：

     pip install -r requirements.txt

撰寫程式碼，為 model 取得 OpenAI chat client

提示：加入程式碼時，請務必維持正確的縮排。

  1. 在 VS Code 中開啟 image-chat-app.py 檔案。

  2. 在程式碼檔案中，留意檔案頂端已加入匯入必要 SDK namespace 的陳述式。接著找出註解 Add references，加入下列程式碼，以參考先前安裝之程式庫中的 namespace：

    # Add references
from openai import OpenAI
from azure.identity import DefaultAzureCredential, get_bearer_token_provider

  3. 在 main 函式中的註解 Get configuration settings下方，留意程式碼會載入您在組態檔中定義的 project connection string 和 model deployment 名稱值。

  4. 找出註解 Create an OpenAI client，並加入下列程式碼，以連線至您的 Azure AI Foundry project：

    提示：請小心維持程式碼正確的縮排層級。

    # Create an OpenAI client
credential = DefaultAzureCredential()
token_provider = get_bearer_token_provider(credential, "https://ai.azure.com/.default")
client = OpenAI(
    base_url=openai_endpoint,
    api_key=token_provider()
)

撰寫程式碼以提交包含影像 URL 的 prompt

  1. 留意程式碼包含迴圈，讓使用者持續輸入 prompt，直到輸入「quit」為止。然後在迴圈區段中找出註解 Get a response to image input，加入下列程式碼，以提交包含下列影像的 prompt：

    # Get a response to image input
image_url = "https://microsoftlearning.github.io/mslearn-ai-vision/Labfiles/gen-ai-vision/orange.jpeg"
response = client.responses.create(
     model=model_deployment,
     input=[
         {"role": "developer", "content": system_message},
         { "role": "user", "content": [  
             { "type": "input_text", "text": prompt},
             { "type": "input_image", "image_url": image_url}
         ]} 
     ]
)
print(response.output_text)

  2. 儲存對程式碼檔案的變更。

登入 Azure 並執行應用程式

  1. 在終端機窗格中，使用下列命令登入 Azure。

     az login

    注意：在大多數情況下，只要使用 az login 即可。不過，如果您的訂用帳戶分布於多個 tenant，可能需要使用 –tenant 參數指定 tenant。詳情請參閱 使用 Azure CLI 以互動方式登入 Azure 。

  2. 出現提示時，請依照指示登入 Azure。接著在命令列中完成登入程序，檢視（並視需要確認）包含 Foundry resource 的訂用帳戶詳細資料。

  3. 登入後，輸入下列命令以執行應用程式：

    python image-chat-app.py

  4. 出現提示時，輸入下列 prompt：

    Suggest some recipes that include this fruit
  5. 檢閱回應。然後輸入 quit 以結束程式。

修改程式碼以上傳本機影像檔案

  1. 在應用程式程式碼的編輯器中，於迴圈區段找出先前加入於註解 Get a response to image input下方的程式碼。接著依下列方式修改程式碼，以上傳此本機影像檔案：

    # Get a response to image input
image_path = Path("mystery-fruit.jpeg")
image_format = "jpeg"
with open(image_path, "rb") as image_file:
     image_data = base64.b64encode(image_file.read()).decode("utf-8")

data_url = f"data:image/{image_format};base64,{image_data}"

response = client.responses.create(
     model=model_deployment,
     input=[
         {"role": "developer", "content": system_message},
         { "role": "user", "content": [  
             { "type": "input_text", "text": prompt},
             { "type": "input_image", "image_url": data_url}
         ]} 
     ]
)
 print(response.output_text)

  2. 使用 CTRL+S 命令儲存對程式碼檔案的變更。

  3. 在終端機中，輸入下列命令以執行應用程式：

    python image-chat-app.py

  4. 出現提示時，輸入下列 prompt：

    What is this fruit? What recipes could I use it in?

  5. 檢閱回應。然後輸入 quit 以結束程式。

    注意：在這個簡單的應用程式中，我們尚未實作保留對話歷程的邏輯，因此 model 會將每個 prompt 視為新要求，不包含前一個 prompt 的上下文。

清理

如果您已完成 Azure AI Foundry portal 的探索，請刪除本練習中建立的 resource，以避免產生不必要的 Azure 費用。

  1. 開啟 Azure portal ，並檢視部署本練習所用 resource 的 resource group 內容。
  2. 在工具列上，選取 Delete resource group.
  3. 輸入 resource group 名稱，並確認您要將其刪除。
