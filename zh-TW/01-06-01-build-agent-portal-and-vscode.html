在 Azure 中開發 AI agent  首頁

使用 portal 與 VS Code 建置 AI agent

在此練習中，您將使用 Microsoft Foundry portal 與 Foundry Toolkit VS Code 擴充功能，建置完整的 AI agent 解決方案。您會先在 portal 中建立具備 grounding data 及內建工具的基本 agent，接著透過 VS Code，以程式化方式與它互動，使用 code interpreter 等進階功能進行資料分析。

此練習大約需要 45 分鐘。

注意：此練習使用的部分技術仍處於預覽階段或持續開發中。您可能遇到非預期的行為、警告或錯誤。

先決條件

開始此練習之前，請確認您具備下列項目：

  • 一個 Azure subscription ，具有足夠的權限及 quota，可佈建 Azure AI resource
  • Visual Studio Code 已安裝於您的本機電腦
  • Python 3.13 已安裝
  • Git 已安裝於您的本機電腦
  • 對 Azure AI services 及 Python 程式設計具備基本認識

* 尚未支援 Python 3.14：部分相依套件沒有 3.14 的組建版本。此實驗已使用 Python 3.13.12 測試。

建立 Microsoft Foundry 專案

Microsoft Foundry 使用專案來組織開發 AI 解決方案所需的 model、resource、資料及其他資產。

  1. 在網頁瀏覽器中，開啟 Foundry portal ，網址為 https://ai.azure.com ，並使用您的 Azure 認證登入。關閉首次登入時開啟的任何提示或快速入門窗格；必要時使用左上角的 Foundry 標誌，瀏覽至首頁。

    重要：此實驗使用 New Foundry 體驗。

  2. 在頂端橫幅中，選取 Start building ，試用新的 Microsoft Foundry 體驗。

  3. 出現提示時，建立 新的 專案，並輸入有效的專案名稱（例如 it-support-agent-project).

  4. 展開 Advanced options ，並指定下列設定：
    • Microsoft Foundry resource: 有效的 Foundry resource 名稱
    • Region: 選取鄰近且可用的區域**
    • Subscription: 您的 Azure subscription
    • Resource group: 選取您的 resource group，或建立新的 resource group

    * 部分 Azure AI resource 受到區域 model quota 的限制。如果稍後在練習中超過 quota 上限，您可能需要在其他區域建立另一個 resource。

  5. 選取 Create ，並等候專案建立完成。

  6. 專案建立完成後，可能會出現歡迎對話方塊。選取 Next 閱讀歡迎訊息，接著選取 Create agent.

    您也可以在首頁選取 Start building ，再從下拉式選單中選取 Create agents 。

  7. 將 Agent name 設為 it-support-agent ，並建立 agent。

新建立的 agent 會在 playground 中開啟。您會看到系統已為您選取可用且已部署的 model。

為 agent 設定指示與 grounding data

現在您已建立 agent，讓我們設定指示並新增 grounding data。

  1. 在 agent playground 中，將 Instructions 設為：

    You are an IT Support Agent for Contoso Corporation.
You help employees with technical issues and IT policy questions.

Guidelines:
- Always be professional and helpful
- Use the IT policy documentation to answer questions accurately
- If you don't know the answer, admit it and suggest contacting IT support directly
- When creating tickets, collect all necessary information before proceeding

  2. 從實驗 repository 下載 IT 政策文件。開啟新的瀏覽器索引標籤，並瀏覽至：

    https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-agents/main/Labfiles/01-build-agent-portal-and-vscode/IT_Policy.txt

    將檔案儲存到您的本機電腦。

    注意：此文件包含密碼重設、軟體安裝申請及硬體疑難排解的 IT 政策範例。

  3. 返回 agent playground。在 Tools 區段中，選取 Add，然後新增 File search 與 </> Code interpreter.

  4. 在 Add右側，選取 Upload files。在 Attach files下方，瀏覽並上傳 IT_Policy.txt 檔案（也就是您剛下載的檔案），然後選取 Attach.

  5. 等候檔案完成索引建立。準備就緒時，您會看到確認訊息。

  6. 現在，讓我們新增一些效能資料，供 code interpreter 分析。從下列位置下載系統效能資料檔案：

    https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-agents/main/Labfiles/01-build-agent-portal-and-vscode/system_performance.csv

    將此檔案儲存到您的本機電腦。

  7. 在 </> Code interpreter右側，選取 + Files，然後上傳 system_performance.csv 檔案（也就是您剛下載的檔案）。

    注意：此 CSV 檔案包含隨時間變化的模擬系統指標（CPU、記憶體、磁碟使用量），供 agent 分析。

  8. 儲存 agent。

測試 agent

讓我們測試 agent，看看它如何使用 grounding data 回應。

  1. 在 playground 右側的聊天介面中，輸入下列 prompt：

    What's the policy for password resets?

  2. 檢閱回應。Agent 應會參考 IT 政策文件，提供密碼重設程序的正確資訊。

  3. 嘗試另一個 prompt：

    How do I request new software?

  4. 再次檢閱回應，並觀察 agent 如何使用 grounding data。

  5. 現在，透過資料分析請求測試 code interpreter：

    Can you analyze the system performance data and tell me if there are any concerning trends?

  6. Agent 應會使用 code interpreter 分析 CSV 檔案，提供系統效能的深入見解。

  7. 嘗試要求視覺化呈現：

    Create a chart showing CPU usage over time from the performance data

  8. Agent 會使用 code interpreter 產生視覺化圖表及分析。

太好了！您已建立具備 grounding data、file search 及 code interpreter 功能的 agent。在下一節中，您將使用 VS Code，以程式化方式與此 agent 互動。

使用 VS Code 與 agent 互動

身為開發人員，您可能會花一些時間在 Foundry portal 中工作，但也可能會花很多時間使用 Visual Studio Code。Foundry Toolkit for VS Code 擴充功能提供便利的方式，讓您不必離開開發環境就能使用 Foundry 專案 resource。

安裝並設定 VS Code 擴充功能

如果您已安裝 Foundry Toolkit 擴充功能，可以略過此節。

  1. 開啟 Visual Studio Code。

  2. 選取 Extensions （位於左側窗格），或按下 Ctrl+Shift+X).

  3. 在擴充功能市集中搜尋 Foundry Toolkit for VS Code 擴充功能（由 Microsoft 提供），然後選取 Install.

    安裝 Foundry Toolkit 擴充功能後，即會將它新增至 VS Code。

    注意：此擴充功能目前列名為 Foundry Toolkit，但部分 VS Code 標籤、命令或舊版螢幕擷取畫面可能仍使用 AI Toolkit名稱。在此實驗中，請將這些名稱視為同一個擴充功能體驗。

  4. 安裝擴充功能後，在側邊欄中選取 Foundry Toolkit 圖示。

    如果您尚未登入，系統應會提示您登入 Azure 帳戶。

在 VS Code 中測試 agent

撰寫任何程式碼之前，您可以直接在擴充功能介面中與 agent 互動。

  1. 在 Microsoft Foundry Resources下方，選擇 Set Default Project

    如果已有預設專案處於作用中，resource 清單會顯示專案名稱。您可以選取同一個 Select project 圖示，改選其他專案。

  2. 展開專案區段。在 Prompt Agents下方，您應會看到 it-support-agent （您在 portal 中建立的 agent）。選取 agent 名稱，開啟 Agent Builder 介面。

    Agent playground 會顯示在 Agent Builder 介面中，讓您不必離開 VS Code，就能與 agent 互動並調整其設定。

  3. 在 playground 聊天窗格中，輸入問題，例如：

    What is the policy for reporting a lost or stolen device?

  4. 檢閱 agent 的回應。它應會使用您先前上傳的 grounding data，提供相關的 IT 政策資訊。

    提示：您可以使用此內建 playground，快速測試 agent 的指示及知識，不必撰寫任何程式碼。

建立與 agent 互動的用戶端應用程式

現在，讓我們建立以程式化方式與 agent 互動的用戶端應用程式。

  1. 在 VS Code 中，開啟命令選擇區（Ctrl+Shift+P 或 View > Command Palette).

  2. 輸入 Git: Clone ，並從清單中選取它。

  3. 輸入 repository URL：

    https://github.com/MicrosoftLearning/mslearn-ai-agents.git

  4. 在本機電腦上選擇一個位置，以複製 repository。

  5. 出現提示時，選取 Open ，在 VS Code 中開啟複製的 repository。

  6. Repository 開啟後，選取 File > Open Folder ，並瀏覽至 mslearn-ai-agents/Labfiles/01-build-agent-portal-and-vscode/Python，然後選擇 Select Folder.

  7. 在 Explorer 窗格中，開啟 agent_with_functions.py 檔案。如果檔案是空的，請將其內容替換為下列程式碼。

  8. 使用下列程式碼：

    import base64
import os
from pathlib import Path

from azure.ai.projects import AIProjectClient
from azure.identity import DefaultAzureCredential
from dotenv import load_dotenv


OUTPUT_DIR = Path("agent_outputs")


def get_output_path(filename):
    """Create a unique path for generated files."""
    OUTPUT_DIR.mkdir(exist_ok=True)
    file_name = Path(filename).name
    stem = Path(file_name).stem or "output"
    suffix = Path(file_name).suffix
    output_path = OUTPUT_DIR / file_name

    counter = 1
    while output_path.exists():
        output_path = OUTPUT_DIR / f"{stem}_{counter}{suffix}"
        counter += 1

    return output_path


def save_bytes(file_bytes, filename):
    """Save binary content to a local file."""
    output_path = get_output_path(filename)
    with open(output_path, "wb") as file_handle:
        file_handle.write(file_bytes)
    return output_path


def save_image(image_data, filename):
    """Save base64 image data to a file."""
    return save_bytes(base64.b64decode(image_data), filename)


def download_container_file(openai_client, annotation, downloaded_files):
    """Download a cited container file once and return its local path."""
    cache_key = (annotation.container_id, annotation.file_id)
    if cache_key in downloaded_files:
        return downloaded_files[cache_key]

    file_content = openai_client.containers.files.content.retrieve(
        file_id=annotation.file_id,
        container_id=annotation.container_id,
    )
    output_path = save_bytes(
        file_content.read(),
        annotation.filename or f"{annotation.file_id}.bin",
    )
    downloaded_files[cache_key] = output_path
    return output_path


def format_output_text(content_item, openai_client, downloaded_files):
    """Replace sandbox file citations with local file paths."""
    text = content_item.text or ""
    replacements = []
    referenced_files = set()

    for annotation in content_item.annotations or []:
        if getattr(annotation, "type", "") != "container_file_citation":
            continue

        output_path = download_container_file(openai_client, annotation, downloaded_files)
        replacement_text = f"{annotation.filename} (saved to {output_path})"
        referenced_files.add(output_path)

        start_index = getattr(annotation, "start_index", None)
        end_index = getattr(annotation, "end_index", None)
        if start_index is not None and end_index is not None:
            replacements.append((start_index, end_index, replacement_text))
            continue

        annotated_text = getattr(annotation, "text", "")
        if annotated_text:
            text = text.replace(annotated_text, replacement_text)

    for start_index, end_index, replacement_text in sorted(replacements, reverse=True):
        text = f"{text[:start_index]}{replacement_text}{text[end_index:]}"

    return text, referenced_files


def main():
    # Initialize the project client
    load_dotenv()
    project_endpoint = os.environ.get("PROJECT_ENDPOINT")
    agent_name = os.environ.get("AGENT_NAME", "it-support-agent")

    if not project_endpoint:
        print("Error: PROJECT_ENDPOINT environment variable not set")
        print("Please set it in your .env file or environment")
        return

    print("Connecting to Microsoft Foundry project...")
    credential = DefaultAzureCredential()
    project_client = AIProjectClient(
        credential=credential,
        endpoint=project_endpoint
    )

    # Get the OpenAI client for Responses API
    openai_client = project_client.get_openai_client()

    # Get the agent created in the portal
    print(f"Loading agent: {agent_name}")
    agent = project_client.agents.get(agent_name=agent_name)
    print(f"Connected to agent: {agent.name} (id: {agent.id})")

    # Create a conversation
    conversation = openai_client.conversations.create(items=[])
    print(f"Conversation created (id: {conversation.id})")

    # Chat loop
    print("\n" + "="*60)
    print("IT Support Agent Ready!")
    print("Ask questions, request data analysis, or get help.")
    print("Type 'exit' to quit.")
    print("="*60 + "\n")

    while True:
        user_input = input("You: ").strip()

        if user_input.lower() in ['exit', 'quit', 'bye']:
            print("Goodbye!")
            break

        if not user_input:
            continue

        # Add user message to conversation
        openai_client.conversations.items.create(
            conversation_id=conversation.id,
            items=[{"type": "message", "role": "user", "content": user_input}]
        )

        # Get response from agent
        print("\n[Agent is thinking...]")
        response = openai_client.responses.create(
            conversation=conversation.id,
            extra_body={"agent_reference": {"name": agent.name, "type": "agent_reference"}},
            input=""
        )

        # Display response and save any generated files locally
        handled_output = False
        downloaded_files = {}
        referenced_files = set()
        image_count = 0

        if hasattr(response, "output") and response.output:
            for item in response.output:
                item_type = getattr(item, "type", "")

                if item_type == "message" and getattr(item, "content", None):
                    for content_item in item.content:
                        if getattr(content_item, "type", "") != "output_text":
                            continue

                        formatted_text, message_files = format_output_text(
                            content_item,
                            openai_client,
                            downloaded_files,
                        )
                        referenced_files.update(message_files)

                        if formatted_text:
                            print(f"\nAgent: {formatted_text}\n")
                            handled_output = True

                elif hasattr(item, "text") and item.text:
                    print(f"\nAgent: {item.text}\n")
                    handled_output = True

                elif item_type == "image":
                    image_count += 1
                    filename = f"chart_{image_count}.png"

                    if hasattr(item, "image") and hasattr(item.image, "data"):
                        file_path = save_image(item.image.data, filename)
                        print(f"\n[Agent generated a chart - saved to: {file_path}]")
                    else:
                        print("\n[Agent generated an image]")
                    handled_output = True

            for file_path in downloaded_files.values():
                if file_path not in referenced_files:
                    print(f"\n[Agent generated a file - saved to: {file_path}]")
                    handled_output = True

        if not handled_output and hasattr(response, "output_text") and response.output_text:
            print(f"\nAgent: {response.output_text}\n")

if __name__ == "__main__":
    main()

  9. 儲存 agent_with_functions.py 檔案（Ctrl+S 或 File > Save).

設定環境並執行應用程式

  1. 在 Explorer 窗格中，您會看到資料夾中已有 .env.example 與 requirements.txt 檔案。

  2. 複製 .env.example 檔案，並將副本重新命名為 .env.

  3. 在 .env 檔案中，將 your_project_endpoint_here 替換成您實際的 project endpoint：

    PROJECT_ENDPOINT=<your_project_endpoint>
AGENT_NAME=it-support-agent

    若要取得 project endpoint： 在 VS Code 中，開啟 Foundry Toolkit 擴充功能，以滑鼠右鍵按一下作用中的專案，並選取 Copy Endpoint。如果 Copy Endpoint 在您安裝的 Foundry Toolkit 版本中不可用，請改為開啟 Microsoft Foundry portal，前往您的專案，並從專案概觀頁面複製 project endpoint。

  4. 儲存 .env 檔案（Ctrl+S 或 File > Save).

  5. 在 VS Code 中開啟終端機（Terminal > New Terminal），並瀏覽至工作目錄。

  6. 安裝必要套件並登入：

    python -m venv labenv
.\labenv\Scripts\Activate.ps1
pip install -r requirements.txt

    az login

  7. 執行應用程式：

    python agent_with_functions.py

測試用戶端應用程式

Agent 啟動後，嘗試下列 prompt，測試不同功能：

  1. 使用 file search 測試政策搜尋：

    What's the policy for password resets?

  2. 使用 code interpreter 要求資料分析：

    Analyze the system performance data and identify any periods where CPU usage exceeded 80%

  3. 要求視覺化呈現：

    Create a line chart showing memory usage trends over time

    應用程式會將產生的圖表及引用的檔案儲存至 agent_outputs 資料夾，並在終端機中印出本機檔案路徑。

  4. 要求統計分析：

    What are the average, minimum, and maximum values for disk usage in the performance data?

  5. 綜合分析：

    Find any correlation between high CPU usage and memory usage in the performance data

觀察 agent 如何同時使用 file search（處理政策問題）與 code interpreter（進行資料分析），滿足您的請求。Code interpreter 會分析 CSV 資料、執行計算，甚至能產生視覺化圖表。輸入 exit 以結束測試。

清理

為避免不必要的 Azure 費用，請刪除您建立的 resource：

  1. 在 Foundry portal 中，瀏覽至您的專案
  2. 選取 Settings > Delete project
  3. 或者，從 Azure portal 刪除整個 resource group
