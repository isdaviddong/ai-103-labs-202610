使用 Microsoft Agent Framework 開發 multi-agent 解決方案

在本練習中，您將練習使用 Microsoft Agent Framework SDK 的 sequential orchestration pattern。您將建立由三個 agent 組成的簡單 pipeline，它們會共同處理客戶意見回饋，並提出後續步驟的建議。您將建立下列 agent：

  • Summarizer agent 會將原始意見回饋濃縮為簡短且中立的句子。
  • Classifier agent 會將意見回饋分類為 Positive、Negative 或 Feature request。
  • 最後，Recommended Action agent 會建議適當的後續處理步驟。

您將學習如何使用 Microsoft Agent Framework SDK 拆解問題，交由適當的 agent 依序處理，並產生可付諸行動的結果。開始吧！

本練習大約需要 30 分鐘才能完成。

注意：本練習使用的部分技術仍處於預覽階段或積極開發中。您可能會遇到非預期的行為、警告或錯誤。

必要條件

開始本練習之前，請確認您已具備以下條件：

  • Visual Studio Code 已安裝於本機
  • 有效的 Azure subscription
  • Python 3.13 已安裝
  • Git 已安裝於本機

* 目前尚不支援 Python 3.14：部分相依套件沒有 3.14 的版本。本實驗已使用 Python 3.13.12 測試。

使用 Foundry Toolkit for VS Code 擴充功能建立 Foundry project

身為開發人員，您可能會花一些時間在 Foundry portal 中操作，但也很可能會花大量時間使用 Visual Studio Code。Foundry Toolkit for VS Code 擴充功能可讓您不必離開開發環境，就能方便地使用 Foundry project 的資源。

  1. 開啟 Visual Studio Code。

  2. 選取 Extensions （位於左側窗格），或按下 Ctrl+Shift+X).

  3. 在擴充功能市集中搜尋 Microsoft 提供的 Foundry Toolkit 擴充功能，然後選取 Install.

    注意：此擴充功能目前列出的名稱為 Foundry Toolkit，但部分 VS Code 標籤、命令或較舊的螢幕擷取畫面可能仍使用 AI Toolkit這個名稱。在本實驗中，請將這些名稱視為同一個擴充功能體驗。

  4. 安裝擴充功能後，選取側邊欄中的圖示，以開啟 Foundry Toolkit 檢視。

    如果您尚未登入，系統應會提示您登入 Azure 帳戶。

  5. 選取 Create Project ，位於 Microsoft Foundry Resources.

    如果已有啟用中的預設 project，project 名稱會顯示在 My Resources下。您可以在目前啟用的 project 上按一下滑鼠右鍵，然後選取 Switch Default Project in Azure Extension.

  6. 選取您的 Azure subscription 和 resource group，然後輸入 Foundry project 的名稱，以建立本練習使用的新 project。

    deployment 完成後，您應該會看到此 project 出現在 Foundry Toolkit 窗格中，並設為預設 project。

部署 model

每個 generative AI project 的核心都至少有一個 generative AI model。在此任務中，您將從 Model Catalog 部署一個 model，供 agent 使用。

  1. 當「Project deployed successfully」快顯視窗出現時，選取 Deploy a new model 按鈕。這會開啟 Model Catalog。

    提示：您也可以選取 + 圖示（位於 Resources 區段的 Models 旁），或按下 F1 並執行命令 Foundry Toolkit: Show model catalog.

  2. 在 Model Catalog 中找到 gpt-5 model（您可以使用搜尋列快速找到它）。

  3. 選取 Deploy （位於 gpt-5 model 旁）。

  4. 設定 deployment 選項：
    • Deployment name：輸入名稱，例如「gpt-5」
    • Deployment type：選取 Global Standard （或 Standard ，如果無法使用 Global Standard）
    • Model version：保留預設值
    • Tokens per minute：保留預設值

  5. 選取 Deploy to Microsoft Foundry （位於左下角）。

  6. 等待 deployment 完成。已部署的 model 會出現在 Resources 檢視中的 Models 區段。

  7. 在 project deployment 的名稱上按一下滑鼠右鍵，然後選取 Copy Project Endpoint。在後續步驟中，您需要使用這個 URL 將 agent 連線至 Foundry project。

複製起始程式碼 repository

本練習將使用起始程式碼，協助您連線至 Foundry project，並建立能處理客戶意見回饋的 multi-agent 解決方案。您將從 GitHub repository 複製此程式碼。

  1. 在 VS Code 中開啟 Command Palette（Ctrl+Shift+P 或 View > Command Palette).

  2. 輸入 Git: Clone 並從清單中選取該命令。

  3. 輸入 repository URL：

    https://github.com/MicrosoftLearning/mslearn-ai-agents.git

  4. 選擇本機上的位置，以複製 repository。

  5. 系統提示時，選取 Open 以在 VS Code 中開啟已複製的 repository。

  6. repository 開啟後，選取 File > Open Folder 並瀏覽至 mslearn-ai-agents/Labfiles/08-agent-orchestration，然後選擇 Select Folder.

  7. 在 Explorer 窗格中，展開 Python 資料夾，以檢視本練習的程式碼檔案。

  8. 在 requirements.txt 檔案上按一下滑鼠右鍵，然後選取 Open in Integrated Terminal.

  9. 在終端機中輸入下列命令，在 virtual environment 中安裝所需的 Python 套件：

    python -m venv labenv
.\labenv\Scripts\Activate.ps1
pip install -r requirements.txt

  10. 開啟 .env 檔案，將 your_project_endpoint 預留位置替換為您 project 的 endpoint（從 Foundry Toolkit 擴充功能中的 project deployment 資源複製），並確認 MODEL_DEPLOYMENT_NAME 變數已設為您的 model deployment 名稱。使用 Ctrl+S 儲存修改後的檔案。

建立 AI agent

現在，您已準備好建立 multi-agent 解決方案所需的 agent！開始吧！

  1. 在程式碼編輯器中開啟 agents.py 檔案。

  2. 在檔案頂端的註解 Add references下方，新增下列程式碼，以參考實作 agent 所需程式庫中的 namespace：

    # Add references
from agent_framework import Message
from agent_framework.foundry import FoundryChatClient
from agent_framework.orchestrations import SequentialBuilder
from azure.identity import AzureCliCredential

  3. 在 main 函式中，花一點時間檢閱 agent 的指示。這些指示定義了 orchestration 中每個 agent 的行為。

  4. 在下列註解下方新增程式碼： Create the chat client:

    # Create the chat client
credential = AzureCliCredential()
chat_client = FoundryChatClient(
    credential=credential,
    project_endpoint=os.getenv("AZURE_AI_PROJECT_ENDPOINT"),
    model=os.getenv("AZURE_AI_MODEL_DEPLOYMENT_NAME"),
)

    請注意， AzureCliCredential 物件會讓程式碼能向您的 Azure 帳戶進行驗證。 FoundryChatClient 物件會使用 .env 組態中的 endpoint 和 model deployment 名稱，連線至 Foundry project。

  5. 在下列註解下方新增程式碼： Create agents:

    （請務必保持縮排層級）

    # Create agents
summarizer_agent = chat_client.as_agent(
    name="summarizer",
    instructions=summarizer_instructions,
)

classifier_agent = chat_client.as_agent(
    name="classifier",
    instructions=classifier_instructions,
)

action_agent = chat_client.as_agent(
    name="action",
    instructions=action_instructions,
)

建立 sequential orchestration

  1. 在 main 函式中，找到註解 Initialize the current feedback 並新增下列程式碼：

    （請務必保持縮排層級）

    # Initialize the current feedback
feedback="""
I use the dashboard every day to monitor metrics, and it works well overall. 
But when I'm working late at night, the bright screen is really harsh on my eyes. 
If you added a dark mode option, it would make the experience much more comfortable.
"""

  2. 在註解 Build a sequential orchestration下方，新增下列程式碼，以使用您定義的 agent 定義 sequential orchestration：

    # Build sequential orchestration
workflow = SequentialBuilder(
    participants=[summarizer_agent, classifier_agent, action_agent],
    output_from="all",
).build()

    agent 會依照加入 orchestration 的順序處理意見回饋。 output_from="all" 參數可確保收集所有 agent 的輸出。

  3. 在下列註解下方新增程式碼： Run and collect outputs:

    # Run and collect outputs
result = await workflow.run(f"Customer feedback: {feedback}")
outputs = result.get_outputs()

    此程式碼會執行 orchestration，並收集每個參與 agent 的輸出。

  4. 在下列註解下方新增程式碼： Display outputs:

    # Display outputs
i = 1
for response in outputs:
    for msg in cast(list[Message], response.messages):
        name = msg.author_name or ("assistant" if msg.role == "assistant" else "user")
        print(f"{'-' * 60}\n{i:02d} [{name}]\n{msg.text}")
        i += 1

    此程式碼會將您從 orchestration 收集的 workflow 輸出訊息格式化並顯示。

  5. 使用 CTRL+S 命令，將變更儲存至程式碼檔案。

測試應用程式

現在，您已準備好執行程式碼，觀察 AI agent 如何協作。

  1. 在整合式終端機中輸入下列命令，以執行應用程式：

    az login

    python agents.py

  2. 您應該會看到類似下列內容的輸出：

    User requests a dark mode option for more comfortable nighttime use.
Feature request
Log as enhancement request to add dark mode for improved user comfort during nighttime use.

User requests a dark mode option for more comfortable nighttime use.
------------------------------------------------------------

Feature request
------------------------------------------------------------

Log as enhancement request to add dark mode for improved user comfort during nighttime use.

  3. 您也可以選擇使用不同的意見回饋輸入來執行程式碼，例如：

    I reached out to your customer support yesterday because I couldn't access my account. The representative responded almost immediately, was polite and professional, and fixed the issue within minutes. Honestly, it was one of the best support experiences I've ever had.

  4. 完成後，輸入 deactivate （在終端機中），以離開 Python virtual environment。

清理

如果您已完成探索 Azure AI Agent Service，請刪除本練習中建立的資源，以避免產生不必要的 Azure 費用。

刪除您的 model

  1. 在 VS Code 中重新整理 Azure Resources 檢視。

  2. 展開 Models 子區段。

  3. 在已部署的 model 上按一下滑鼠右鍵，然後選取 Delete.

刪除 resource group

  1. 開啟 Azure portal.

  2. 瀏覽至包含 Microsoft Foundry 資源的 resource group。

  3. 選取 Delete resource group 並確認刪除。
