使用 Model Context Protocol (MCP) 工具擴充 agent

在本練習中，您將使用 Foundry Toolkit for VS Code 擴充功能建立 agent，讓它能使用 Model Context Protocol (MCP) server 工具存取外部資料來源和 API。agent 將能透過 MCP 工具擷取最新資訊，並與自訂服務互動。

本練習大約需要 60 分鐘才能完成。

注意：本練習使用的部分技術仍處於預覽階段或積極開發中。您可能會遇到非預期的行為、警告或錯誤。

必要條件

開始本練習之前，請確認您已具備以下條件：

  • Visual Studio Code 已安裝於本機
  • 有效的 Azure subscription
  • Python 3.13 已安裝
  • Git 已安裝於本機

* 目前尚不支援 Python 3.14：部分相依套件沒有 3.14 的版本。本實驗已使用 Python 3.12 測試。

使用 Foundry Toolkit for VS Code 擴充功能建立 Foundry project

身為開發人員，您可能會花一些時間在 Foundry portal 中操作，但也很可能會花大量時間使用 Visual Studio Code。Foundry Toolkit for VS Code 擴充功能可讓您不必離開開發環境，就能方便地使用 Foundry project 的資源。

  1. 開啟 Visual Studio Code。

  2. 選取 Extensions （位於左側窗格），或按下 Ctrl+Shift+X).

  3. 在擴充功能市集中搜尋 Microsoft 提供的 Foundry Toolkit 擴充功能，然後選取 Install.

    注意：此擴充功能目前列出的名稱為 Foundry Toolkit，但部分 VS Code 標籤、命令或較舊的螢幕擷取畫面可能仍使用 AI Toolkit這個名稱。在本實驗中，請將這些名稱視為同一個擴充功能體驗。

  4. 安裝擴充功能後，選取側邊欄中的圖示，以開啟 Foundry Toolkit 檢視。

    如果您尚未登入，系統應會提示您登入 Azure 帳戶。

  5. 選取 Create Project ，位於 Microsoft Foundry Resources.

    如果已有啟用中的預設 project，project 名稱會顯示在 My Resources下。您可以在目前啟用的 project 上按一下滑鼠右鍵，然後選取 Switch Default Project in Azure Resources.

  6. 選取您的 Azure subscription 和 resource group，然後輸入 Foundry project 的名稱，以建立本練習使用的新 project。

    deployment 完成後，您應該會看到此 project 出現在 Foundry Toolkit 窗格中，並設為預設 project。

部署 model

每個 generative AI project 的核心都至少有一個 generative AI model。在此任務中，您將從 Model Catalog 部署一個 model，供 agent 使用。

  1. 當「Project deployed successfully」快顯視窗出現時，選取 Deploy a new model 按鈕。這會開啟 Model Catalog。

    提示：您也可以選取 + 圖示（位於 Resources 區段的 Models 旁），或按下 F1 並執行命令 Foundry Toolkit: Show model catalog.

  2. 在 Model Catalog 中找到 gpt-5 model（您可以使用搜尋列快速找到它）。

  3. 選取 Deploy （位於 gpt-5 model 旁）。

  4. 設定 deployment 選項：
    • Deployment name：輸入名稱，例如「gpt-5」
    • Deployment type：選取 Global Standard （或 Standard ，如果無法使用 Global Standard）
    • Model version：保留預設值
    • Tokens per minute：將 Tokens per Minute 上限提高至 150000 或更高。

  5. 選取 Deploy to Microsoft Foundry （位於左下角）。

  6. 等待 deployment 完成。已部署的 model 會出現在 Resources 檢視中的 Models 區段。

  7. 在 project deployment 的名稱上按一下滑鼠右鍵，然後選取 Copy Project Endpoint。在後續步驟中，您需要使用這個 URL 將 agent 連線至 Foundry project。

複製起始程式碼 repository

本練習將使用起始程式碼，協助您連線至 Foundry project，並建立使用 MCP server 工具的 agent。

  1. 在 VS Code 中開啟 Command Palette（Ctrl+Shift+P 或 View > Command Palette).

  2. 輸入 Git: Clone 並從清單中選取該命令。

  3. 輸入 repository URL：

    https://github.com/MicrosoftLearning/mslearn-ai-agents.git

  4. 選擇本機上的位置，以複製 repository。

  5. 系統提示時，選取 Open 以在 VS Code 中開啟已複製的 repository。

  6. repository 開啟後，選取 File > Open Folder 並瀏覽至 mslearn-ai-agents/Labfiles/03-mcp-integration，然後選擇 Select Folder.

  7. 在 Explorer 窗格中，展開 Python 資料夾，以檢視本練習的程式碼檔案。

  8. 在 requirements.txt 檔案上按一下滑鼠右鍵，然後選取 Open in Integrated Terminal.

  9. 在終端機中輸入下列命令，在 virtual environment 中安裝所需的 Python 套件：

    python -m venv labenv
.\labenv\Scripts\Activate.ps1
pip install -r requirements.txt

  10. 開啟 .env 檔案，將 your_project_endpoint 預留位置替換為您 project 的 endpoint（從 Foundry Toolkit 擴充功能中的 project deployment 資源複製），並確認 MODEL_DEPLOYMENT_NAME 變數已設為您的 model deployment 名稱。使用 Ctrl+S 儲存修改後的檔案。

現在，您已準備好建立使用 MCP server 工具來存取外部資料來源和 API 的 AI agent。

將 Azure AI Agent 連線至遠端 MCP server

在此任務中，您將連線至遠端 MCP server、準備 AI agent，並執行使用者 prompt。

  1. 在程式碼編輯器中開啟 agent.py 檔案。

    提示：新增程式碼時，請務必保持正確的縮排。請以註解的縮排層級作為參考。

  2. 找到註解 Add references 並新增下列程式碼以匯入類別：

    # Add references
from azure.identity import DefaultAzureCredential
from azure.ai.projects import AIProjectClient
from azure.ai.projects.models import PromptAgentDefinition, MCPTool
from openai.types.responses.response_input_param import McpApprovalResponse, ResponseInputParam

  3. 找到註解 Connect to the agents client 並新增下列程式碼，使用目前的 Azure 認證連線至 Azure AI project。

    # Connect to the agents client
with (
    DefaultAzureCredential() as credential,
    AIProjectClient(endpoint=project_endpoint, credential=credential) as project_client,
    project_client.get_openai_client() as openai_client,
):

  4. 在註解 Initialize agent MCP tool下方新增下列程式碼：

    # Initialize agent MCP tool
mcp_tool = MCPTool(
    server_label="api-specs",
    server_url="https://learn.microsoft.com/api/mcp",
    require_approval="always",
)

    此程式碼會連線至 Microsoft Learn Docs 遠端 MCP server。這是由雲端託管的服務，讓 client 能直接從 Microsoft 官方文件存取可信且最新的資訊。

  5. 在註解 Create a new agent with the MCP tool 下方新增下列程式碼：

    # Create a new agent with the MCP tool
agent = project_client.agents.create_version(
    agent_name="MyAgent",
    definition=PromptAgentDefinition(
        model=model_deployment,
        instructions="You are a helpful agent that can use MCP tools to assist users. Use the available MCP tools to answer questions and perform tasks.",
        tools=[mcp_tool],
    ),
)
print(f"Agent created (id: {agent.id}, name: {agent.name}, version: {agent.version})")

    在此程式碼中，您會提供 agent 的指示，並為它提供 MCP 工具定義。

  6. 找到註解 Create a conversation thread 並新增下列程式碼：

    # Create a conversation thread
conversation = openai_client.conversations.create()
print(f"Created conversation (id: {conversation.id})")

  7. 找到註解 Send initial request that will trigger the MCP tool 並新增下列程式碼：

    # Send initial request that will trigger the MCP tool
response = openai_client.responses.create(
    conversation=conversation.id,
    input="Give me the Azure CLI commands to create an Azure Container App with a managed identity.",
   extra_body={"agent_reference": {"name": agent.name, "type": "agent_reference"}},
)

  8. 找到註解 Process any MCP approval requests that were generated 並新增下列程式碼：

    # Process any MCP approval requests that were generated
# The agent may issue several tool calls, each needing its own approval,
# so we loop until there are none left.
while True:
    # Collect any MCP approval requests from the latest response
    input_list: ResponseInputParam = []
    for item in response.output:
        if item.type == "mcp_approval_request":
            if item.server_label == "api-specs" and item.id:
                # Automatically approve the MCP request to allow the agent to proceed
                input_list.append(
                    McpApprovalResponse(
                        type="mcp_approval_response",
                        approve=True,
                        approval_request_id=item.id,
                    )
                )

    # No more approvals needed -> the agent has produced its final response
    if not input_list:
        break

    # Send the approval response back and retrieve the next response
    response = openai_client.responses.create(
        input=input_list,
        previous_response_id=response.id,
        extra_body={"agent_reference": {"name": agent.name, "type": "agent_reference"}},
    )

print(f"\nAgent response: {response.output_text}")

    此程式碼會監聽 agent 回應中的任何 MCP 核准要求，並自動核准它們。

  9. 找到註解 Clean up resources by deleting the agent version 並新增下列程式碼：

    # Clean up resources by deleting the agent version
project_client.agents.delete_version(agent_name=agent.name, agent_version=agent.version)
print("Agent deleted")

  10. 完成後，儲存程式碼檔案（CTRL+S）。

建立具有自訂工具的 MCP server

除了連線至遠端 MCP server，您也可以建立自己的自訂 MCP server 工具，並將它們連線至 agent。Model Context Protocol (MCP) Server 是託管可呼叫工具的元件。這些工具是可提供給 AI agent 使用的 Python 函式。當工具加上 @mcp.tool()註記時，client 就能探索這些工具，讓 AI agent 在對話或任務期間自主呼叫它們。在此任務中，您將新增工具，讓 agent 能查詢庫存並提供建議。

  1. 在程式碼編輯器中開啟 server.py 檔案。

    在此程式碼檔案中，您將定義 agent 可使用的工具，以模擬零售商店的後端服務。請注意檔案頂端的 server 設定程式碼。它使用 FastMCP 快速啟動名為「Inventory」的 MCP server 執行個體。此 server 將託管您定義的工具，讓 agent 在實驗期間能存取它們。

  2. 在註解 Add references下方新增下列程式碼：

    # Add references
from fastmcp import FastMCP

  3. 在註解 Create an MCP server下方新增下列程式碼，以建立新的 MCP server 執行個體：

    # Create an MCP server
mcp = FastMCP(name="Inventory")

    此程式碼會初始化標籤為「Inventory」的新 MCP server。

  4. 找到註解 Add an inventory check mcp tool 並在函式定義上方新增下列 decorator，完成後應如下所示：

    # Add an inventory check mcp tool
@mcp.tool()
def get_inventory_levels() -> dict:
   # continued...

    此 dictionary 代表範例庫存。 @mcp.tool() decorator 會將函式註冊為 MCP server 上的工具，讓 LLM 能探索您的函式。

  5. 找到註解 Add a weekly sales mcp tool 並在函式定義上方新增下列 decorator，完成後應如下所示：

    # Add a weekly sales mcp tool
@mcp.tool()
def get_weekly_sales() -> dict:
   # continued...

  6. 找到註解 Run the MCP server 並新增下列程式碼以啟動 server：

    # Run the MCP server
mcp.run(show_banner=False)

    此程式碼會啟動 MCP server，讓 agent 能探索及使用您的工具。設定 show_banner=False 可防止啟動橫幅印至 stdout，避免破壞 MCP stdio protocol。

  7. 儲存檔案（CTRL+S).

實作 MCP client 以連線至自訂 MCP server

MCP client 是連線至 MCP server 以探索並呼叫工具的元件。您可以將它視為 agent 與 server 託管函式之間的橋樑，讓 agent 能依據使用者 prompt 動態使用工具。

  1. 瀏覽至 client.py 檔案。

  2. 找到註解 Add references 並新增下列程式碼以匯入類別：

    # Add references
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

  3. 在 connect_to_server 方法中，找到註解 Start the MCP server 並新增下列程式碼：

    # Start the MCP server
stdio_transport = await exit_stack.enter_async_context(stdio_client(server_params))
stdio, write = stdio_transport

    在標準的正式環境設定中，server 會與 client 分開執行。不過，為了本實驗方便起見，client 會負責使用標準輸入／輸出傳輸來啟動 server。這會在兩個元件之間建立輕量的通訊通道，並簡化本機開發設定。

  4. 找到註解 Create an MCP client session 並新增下列程式碼：

    # Create an MCP client session
session = await exit_stack.enter_async_context(ClientSession(stdio, write))
await session.initialize()

    這會使用上一個步驟的輸入和輸出串流，建立新的 client 工作階段。呼叫 session.initialize 會讓工作階段準備好探索並呼叫已註冊至 MCP server 的工具。

  5. 在註解 List available tools下方新增下列程式碼，以確認 client 已連線至 server：

    # List available tools
response = await session.list_tools()
tools = response.tools
print("\nConnected to server with tools:", [tool.name for tool in tools])

    現在，您的 client 工作階段已準備好搭配 Azure AI Agent 使用。

將 MCP 工具連線至 agent

在此任務中，您將把 MCP server 工具連線至 agent，讓它能回應使用者 prompt 並呼叫這些工具。

提示：新增程式碼時，請務必保持正確的縮排。請以註解的縮排層級作為參考。

  1. 在 chat_loop 方法中，找到註解 Build a function for each tool 並新增下列程式碼：

    # Build a function for each tool
def make_tool_func(tool_name):
    async def tool_func(**kwargs):
        result = await session.call_tool(tool_name, kwargs)
        return result

    tool_func.__name__ = tool_name
    return tool_func

# Store the functions in a dictionary for easy access when processing function calls
functions_dict = {tool.name: make_tool_func(tool.name) for tool in tools}

    此程式碼會動態包裝 MCP server 中可用的工具，讓 AI agent 能呼叫它們。每個工具都會轉換為 agent 可呼叫的 async 函式。

  2. 找到註解 Create FunctionTool definitions for the agent 並新增下列程式碼：

    # Create FunctionTool definitions for the agent
mcp_function_tools: FunctionTool = []
for tool in tools:
    function_tool = FunctionTool(
        name=tool.name,
        description=tool.description,
        parameters={
            "type": "object",
            "properties": {},
            "additionalProperties": False,
        },
        strict=True
    )
    mcp_function_tools.append(function_tool)

  3. 找到註解 Create the agent 並新增下列程式碼：

    # Create the agent
agent = project_client.agents.create_version(
    agent_name="inventory-agent",
    definition=PromptAgentDefinition(
        model=model_deployment,
        instructions="""
        You are an inventory assistant. Here are some general guidelines:
        - Recommend restock if item inventory < 10  and weekly sales > 15
        - Recommend clearance if item inventory > 20 and weekly sales < 5
        """,
        tools=mcp_function_tools
    ),
)

    透過這些指示和工具，agent 能呼叫工具擷取庫存與銷售資料，然後使用這些資訊，為使用者提供有用的回應。

  4. 找到註解 Process function calls 並新增下列程式碼：

    # Process function calls
for item in response.output:
    if item.type == "function_call":
        # Retrieve the matching function tool
        function_name = item.name
        kwargs = json.loads(item.arguments)
        required_function = functions_dict.get(function_name)

        # Invoke the function
        output = await required_function(**kwargs)

        # Append the output text
        input_list.append(
           FunctionCallOutput(
              type="function_call_output",
              call_id=item.call_id,
              output=output.content[0].text,
           )
        )

    此程式碼會監聽 agent 回應中的任何函式呼叫，呼叫對應的工具函式，並準備要傳回 agent 的輸出。

  5. 找到註解 Send function call outputs back to the model and retrieve a response 並新增下列程式碼：

    # Send function call outputs back to the model and retrieve a response
if input_list:
   response = openai_client.responses.create(
         input=input_list,
         previous_response_id=response.id,
         extra_body={"agent_reference": {"name": agent.name, "type": "agent_reference"}},
   )
print(f"Agent response: {response.output_text}")

  6. 完成後，儲存程式碼檔案（CTRL+S）。

使用 agent 測試自訂 MCP 工具

  1. 在整合式終端機中輸入下列命令，以執行應用程式：

    python client.py

  2. 系統提示時，輸入 prompt，例如：

    Show me the current inventory levels for all products.

    提示：如果應用程式因超過 rate limit 而失敗，請稍等幾秒後再試一次。如果您的 subscription 沒有足夠的 quota，model 可能無法回應。

    您應該會看到類似下列內容的輸出：

     MessageRole.AGENT:
 Agent response: Here are the current inventory levels for all items:

- Moisturizer: 6
- Shampoo: 8
- Body Spray: 28
[continued ...]

Would you like recommendations for restocking or clearance? If so, I can check the weekly sales to advise accordingly.

    請注意，agent 能呼叫 MCP 工具來擷取庫存與銷售資料，然後使用這些資訊，為使用者提供有用的回應。

  3. 您可以視需要繼續對話。此 thread 是 有狀態的，因此會保留對話記錄，也就是說，agent 在每次回應時都具有完整的 context。

    嘗試輸入 prompt，例如：

    Are there any products that should be restocked?

    Which products would you recommend for clearance?

    What are the best sellers this week?

  4. 輸入 quit 以結束應用程式。

    您也可以使用 deactivate 以在終端機中離開 Python virtual environment。

清理

完成探索 Foundry Toolkit for VS Code 擴充功能後，請清理資源，以避免產生不必要的 Azure 費用。

刪除您的 model

  1. 在 VS Code 中重新整理 Azure Resources 檢視。

  2. 展開 Models 子區段。

  3. 在已部署的 model 上按一下滑鼠右鍵，然後選取 Delete.

刪除 resource group

  1. 開啟 Azure portal.

  2. 瀏覽至包含 Microsoft Foundry 資源的 resource group。

  3. 選取 Delete resource group 並確認刪除。
