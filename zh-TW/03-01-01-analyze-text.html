分析文字

Azure Language in Foundry Tools 支援文字分析，包括 language detection、entity recognition 與 PII redaction。

例如，假設一家旅行社想要處理提交至公司網站的飯店評論。透過 Azure Language，他們可以判斷每則評論使用的語言、識別評論中提及的地點、地標或人物等 named entities，並在將評論發布至公司網站之前，遮蔽任何可識別個人身分的資訊。在本練習中，您將使用 Azure Language Python SDK 的文字分析功能，實作一個簡單的飯店評論應用程式。

雖然本練習以 Python 為基礎，但您也可以使用多種語言專屬的 SDK 開發文字分析應用程式，包括：

本練習所用的程式碼以 Microsoft Foundry Tools SDK for Python 為基礎。您可以使用 Microsoft .NET、JavaScript 與 Java 的 SDK 開發類似的解決方案。請參閱 Microsoft Foundry SDK client libraries 以取得詳細資訊。

本練習約需 30 分鐘。

注意：本練習使用的部分技術仍處於預覽階段或積極開發中。您可能會遇到非預期的行為、警告或錯誤。

必要條件

開始本練習之前，請確認您已具備：

  • 有效的 Azure subscription
  • Visual Studio Code 已安裝
  • Python 版本 3.13.xx 已安裝*
  • Git 已安裝並完成設定
  • Azure CLI 已安裝

* Python 3.14 已推出，但部分相依套件尚未針對該版本完成編譯。本實驗已使用 Python 3.13.12 成功測試。

建立 Microsoft Foundry project

Microsoft Foundry 使用 project 來整理開發 AI 解決方案所需的 model、resource、資料及其他資產。

  1. 在網頁瀏覽器中開啟 Microsoft Foundry portal ，網址為 https://ai.azure.com ，並使用您的 Azure 認證登入。關閉首次登入時開啟的任何提示或快速入門窗格，必要時使用左上角的 Foundry 標誌導覽至首頁。

  2. 如果尚未啟用，請在頁面頂端的工具列啟用 New Foundry 選項。接著，如果出現提示，請建立名稱唯一的新 project；展開 Advanced options 區域，為 project 指定下列設定：

    • Foundry resource: 使用 resource 的預設名稱（通常為 {project_name}-resource）
    • Subscription: 您的 Azure subscription
    • Resource group: 建立或選取 resource group
    • Region：選取任何可用的 region

    注意：請使用建議的 Microsoft Foundry region。可用的 model 可能因 region 而異。

  3. 選取 Create。等待 project 建立完成。

  4. 在 project 首頁上，請注意此處顯示了 API key、project endpoint 及 OpenAI endpoint。

    提示：稍後您將需要 project endpoint！

從 GitHub 取得應用程式檔案

開發評論分析應用程式所需的初始應用程式檔案，已提供於 GitHub repo 中。

  1. 開啟 Visual Studio Code。

  2. 開啟命令選擇區（Ctrl+Shift+P），並使用 Git:clone 命令將 https://github.com/microsoftlearning/mslearn-ai-language repo 複製到本機資料夾（任一資料夾皆可），然後開啟它。

    系統可能會要求您確認是否信任作者。

  3. 複製 repo 後，在 Explorer 窗格中導覽至應用程式程式碼檔案所在的資料夾： /Labfiles/01-analyze-text/Python/text-analysis。應用程式檔案包括：

    • reviews （包含評論文件的子資料夾）
    • .env （應用程式設定檔）
    • requirements.txt （需要安裝的 Python 套件相依性）
    • text-analysis.py （應用程式的程式碼檔案）

設定應用程式

  1. 在 Visual Studio Code 中檢視 Extensions 窗格；如果尚未安裝，請安裝 Python 擴充功能。

  2. 在 Command Palette中使用命令 python:select interpreter。接著，若已有環境，請選取現有環境；或根據已安裝的 Python 3.13.x 建立新的 Venv 環境。

    提示：若系統提示您安裝相依套件，可以安裝 requirements.txt 檔案中列出的套件，該檔案位於 /Labfiles/01-analyze-text/Python/text-analysis 資料夾；但即使現在不安裝也沒關係，我們稍後會安裝！

    提示：如果您偏好使用終端機，可以建立 Venv 環境，使用 python -m venv labenv，然後使用以下命令啟用它： \labenv\Scripts\activate.

  3. 在 Explorer 窗格中，以滑鼠右鍵按一下 text-analysis 資料夾（其中包含應用程式檔案），然後選取 Open in integrated terminal （或從 Terminal 選單開啟終端機，並導覽至 /Labfiles/01-analyze-text/Python/text-analysis 資料夾）。

    注意：在 Visual Studio Code 中開啟終端機會自動啟用 Python 環境。您可能需要允許系統執行 script。

  4. 確認終端機已在 text-analysis 資料夾中開啟，且顯示前綴 (.venv) ，表示您建立的 Python 環境已啟用。

  5. 執行下列命令，安裝 Azure Language Text Analytics SDK 及其他必要套件：

    pip install -r requirements.txt

  6. 在 Explorer 窗格的 text-analysis 資料夾中，選取 .env 檔案以開啟它。接著更新設定值，填入 Foundry project 的 endpoint （只保留到 .com 網域；請從 Foundry portal 複製這些值）。

    重要：修改貼上的 endpoint，移除 "/api/projects/{project_name}" 後綴；endpoint 應為 https://{your-foundry-resource-name}.services.ai.azure.com.

    儲存修改後的設定檔。

新增連線至 Azure AI Language resource 的程式碼

  1. 在 Explorer 窗格的 text-analysis 資料夾中，開啟 text-analysis.py 檔案。

  2. 檢閱現有程式碼。您將新增使用 Azure Language Text Analytics SDK 的程式碼。

    提示：將程式碼新增至程式碼檔案時，請務必維持正確的縮排。

  3. 在程式碼檔案頂端、現有 namespace 參考下方，找出註解 Import namespaces ，然後新增下列程式碼，以匯入使用 Text Analytics SDK 所需的 namespace：

    # import namespaces
from azure.identity import DefaultAzureCredential
from azure.ai.textanalytics import TextAnalyticsClient

  4. 在 main 函式中，請注意已提供從設定檔載入 endpoint 的程式碼。接著找出註解 Create client using endpoint，並新增下列程式碼，以建立 Text Analysis API 的 client：

    # Create client using endpoint
credential = DefaultAzureCredential()
ai_client = TextAnalyticsClient(endpoint=foundry_endpoint, credential=credential)

  5. 儲存程式碼檔案的變更。接著在終端機窗格中，使用下列命令登入 Azure。

    az login

    注意：在大多數情況下，僅使用 az login 即可。不過，如果您的 subscription 分屬多個 tenant，可能需要使用 --tenant 參數指定 tenant。請參閱 使用 Azure CLI 以互動方式登入 Azure 以取得詳細資訊。

  6. 出現提示時，請依照指示登入 Azure。接著在命令列完成登入程序，檢視包含 Foundry resource 的 subscription 詳細資料（必要時進行確認）。

  7. 登入後，輸入下列命令以執行應用程式：

    python text-analysis.py

  8. 觀察輸出；程式碼應能正常執行而不發生錯誤，並顯示 reviews 資料夾中每個評論文字檔的內容。應用程式已成功建立 Text Analytics API 的 client，但尚未使用它。我們將在下一節補上這部分。

新增偵測語言的程式碼

您已建立 API 的 client，接下來讓我們使用它偵測每則評論所使用的語言。

  1. 在程式碼編輯器中找出註解 Get language。接著新增偵測每份評論文件語言所需的程式碼：

    # Get language
detectedLanguage = ai_client.detect_language(documents=[text])[0]
print('\nLanguage: {}'.format(detectedLanguage.primary_language.name))

    注意: 在此範例中，每則評論會個別分析，因此每個檔案都會各自呼叫一次服務。另一種方式是建立文件集合，並在一次呼叫中將它們傳給服務。無論採用哪一種方式，服務的回應都包含文件集合；因此，上述 Python 程式碼指定了回應中第一份（也是唯一一份）文件的索引 ([0])。

  2. 儲存變更，然後重新執行程式。

  3. 觀察輸出，留意這次已識別每則評論的語言。

新增擷取 entity 的程式碼

文件或其他文字內容經常會提及人物、地點、時間範圍或其他 entity。Text Analytics API 可以偵測文字中多種類別（及子類別）的 entity。

  1. 在程式碼編輯器中找出註解 Get entities。接著新增識別每則評論中所提及 entity 所需的程式碼：

    # Get entities
entities = ai_client.recognize_entities(documents=[text])[0].entities
if len(entities) > 0:
    print("\nEntities")
    for entity in entities:
        print('\t{} ({})'.format(entity.text, entity.category))

  2. 儲存變更並重新執行程式。

  3. 觀察輸出，留意文字中偵測到的 entity。

新增遮蔽 PII 的程式碼

隱私權政策與法規通常可能要求遮蔽文件中的可識別個人身分資訊（PII），例如姓名、地址、電話號碼及其他私人資訊。

  1. 在程式碼編輯器中找出註解 Get PII。接著新增識別每則評論中所提及 PII entity 所需的程式碼：

    # Get PII
pii_result = ai_client.recognize_pii_entities(documents=[text])[0]
pii_entities = pii_result.entities
if len(pii_entities) > 0:
    print("\nPII Entities")
    for pii_entity in pii_entities:
        print('\t{} ({})'.format(pii_entity.text, pii_entity.category)) 
    print("Redacted Text:\n {}".format(pii_result.redacted_text))

  2. 儲存變更並重新執行程式。

  3. 觀察輸出，留意識別出的 PII entity，並檢閱所產生的各份文件遮蔽版本。

清理資源

如果您已完成 Azure Language in Foundry Tools 的探索，應刪除在本練習中建立的 resource，以避免產生不必要的 Azure 費用。

  1. 開啟 Azure portal ，並檢視您部署本練習所用 resource 的 resource group 內容。
  2. 在工具列上選取 Delete resource group.
  3. 輸入 resource group 名稱，並確認要刪除它。
