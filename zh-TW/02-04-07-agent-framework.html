使用 Microsoft Agent Framework SDK 開發 Azure AI 聊天 agent

在本練習中，您將使用 Azure AI Agent Service 和 Microsoft Agent Framework，建立處理費用報銷申請的 AI agent。

本練習大約需要 30 分鐘才能完成。

注意：本練習使用的部分技術仍處於預覽階段或積極開發中。您可能會遇到非預期的行為、警告或錯誤。

必要條件

開始本練習之前，請確認您已具備以下條件：

  • Visual Studio Code 已安裝於本機
  • 有效的 Azure subscription
  • Python 3.13 已安裝
  • Git 已安裝於本機

* 目前尚不支援 Python 3.14：部分相依套件沒有 3.14 的版本。本實驗已使用 Python 3.13.12 測試。

使用 Foundry Toolkit VS Code 擴充功能建立 Foundry project

身為開發人員，您可能會花一些時間在 Foundry portal 中操作，但也很可能會花大量時間使用 Visual Studio Code。Foundry Toolkit 擴充功能可讓您不必離開開發環境，就能方便地使用 Foundry project 的資源。

  1. 開啟 Visual Studio Code。

  2. 選取 Extensions （位於左側窗格），或按下 Ctrl+Shift+X).

  3. 在擴充功能市集中搜尋 Microsoft 提供的 Foundry Toolkit 擴充功能，然後選取 Install.

    注意：此擴充功能目前列出的名稱為 Foundry Toolkit，但部分 VS Code 標籤、命令或較舊的螢幕擷取畫面可能仍使用 AI Toolkit這個名稱。在本實驗中，請將這些名稱視為同一個擴充功能體驗。

  4. 安裝擴充功能後，選取側邊欄中的圖示，以開啟 Foundry Toolkit 檢視。

    如果您尚未登入，系統應會提示您登入 Azure 帳戶。

  5. 選取 Create Project ，位於 Microsoft Foundry Resources.

    如果已有啟用中的預設 project，project 名稱會顯示在 My Resources下。您可以在目前啟用的 project 上按一下滑鼠右鍵，然後選取 Switch Default Project.

  6. 選取您的 Azure subscription 和 resource group，然後輸入 Foundry project 的名稱，以建立本練習使用的新 project。

    deployment 完成後，您應該會看到此 project 出現在 Foundry Toolkit 窗格中，並設為預設 project。

部署 model

每個 generative AI project 的核心都至少有一個 generative AI model。在此任務中，您將從 Model Catalog 部署一個 model，供 agent 使用。

  1. 當「Project deployed successfully」快顯視窗出現時，選取 Deploy a model 按鈕。這會開啟 Model Catalog。

    提示：您也可以選取 + 圖示（位於 Resources 區段的 Models 旁），或按下 F1 並執行命令 Foundry Toolkit: Show model catalog.

  2. 在 Model Catalog 中找到 gpt-5 model（您可以使用搜尋列快速找到它）。

  3. 選取 Deploy （位於 gpt-5 model 旁）。

  4. 設定 deployment 選項：
    • Deployment name：輸入名稱，例如「gpt-5」
    • Deployment type：選取 Global Standard （或 Standard ，如果無法使用 Global Standard）
    • Model version：保留預設值
    • Tokens per minute：保留預設值

  5. 選取 Deploy to Microsoft Foundry （位於左下角）。

  6. 等待 deployment 完成。已部署的 model 會出現在 Resources 檢視中的 Models 區段。

  7. 在 project deployment 的名稱上按一下滑鼠右鍵，然後選取 Copy Project Endpoint。在後續步驟中，您需要使用這個 URL 將 agent 連線至 Foundry project。

複製起始程式碼 repository

本練習將使用起始程式碼，協助您連線至 Foundry project，並建立能處理費用資料的 agent。您將從 GitHub repository 複製此程式碼。

  1. 在 VS Code 中開啟 Command Palette（Ctrl+Shift+P 或 View > Command Palette).

  2. 輸入 Git: Clone 並從清單中選取該命令。

  3. 輸入 repository URL：

    https://github.com/MicrosoftLearning/mslearn-ai-agents.git

  4. 選擇本機上的位置，以複製 repository。

  5. 系統提示時，選取 Open 以在 VS Code 中開啟已複製的 repository。

  6. repository 開啟後，選取 File > Open Folder 並瀏覽至 mslearn-ai-agents/Labfiles/07-agent-framework，然後選擇 Select Folder.

  7. 在 Explorer 窗格中，展開 Python 資料夾，以檢視本練習的程式碼檔案。

  8. 在 requirements.txt 檔案上按一下滑鼠右鍵，然後選取 Open in Integrated Terminal.

  9. 在終端機中輸入下列命令，在 virtual environment 中安裝所需的 Python 套件：

    python -m venv labenv
.\labenv\Scripts\Activate.ps1
pip install -r requirements.txt

  10. 開啟 .env 檔案，將 your_project_endpoint 預留位置替換為您 project 的 endpoint（從 Foundry Toolkit 擴充功能中的 project deployment 資源複製），並確認 MODEL_DEPLOYMENT_NAME 變數已設為您的 model deployment 名稱。使用 Ctrl+S 儲存修改後的檔案。

現在，您已準備好建立使用自訂工具來處理費用資料的 AI agent。

建立具有自訂工具的 agent

提示：新增程式碼時，請務必保持正確的縮排。請以現有註解作為參考，在相同的縮排層級輸入新程式碼。

  1. 在程式碼編輯器中開啟 agent-framework.py 檔案。

  2. 檢閱檔案中的程式碼。它包含：
    • 一些 import 陳述式，用來新增常用 namespace 的參考
    • 一個 main 函式，會載入包含費用資料的檔案、向使用者詢問指示，然後呼叫……
    • 一個 process_expenses_data 函式，您必須在其中新增建立及使用 agent 的程式碼

  3. 在檔案頂端，現有的 import 陳述式之後，找到註解 Add references，並新增下列程式碼，以參考實作 agent 所需程式庫中的 namespace：

    # Add references
from agent_framework import tool, Agent
from agent_framework.foundry import FoundryChatClient
from azure.identity import AzureCliCredential
from pydantic import Field
from typing import Annotated

  4. 在接近檔案底部的位置，找到註解 Create a tool function for the email functionality，並新增下列程式碼，以定義供 agent 傳送電子郵件的函式（工具是為 agent 新增自訂功能的一種方式）

    # Create a tool function for the email functionality
@tool(approval_mode="never_require")
def submit_claim(
    to: Annotated[str, Field(description="Who to send the email to")],
    subject: Annotated[str, Field(description="The subject of the email.")],
    body: Annotated[str, Field(description="The text body of the email.")]):
        print("\nTo:", to)
        print("Subject:", subject)
        print(body, "\n")

    注意：此函式會 模擬 傳送電子郵件，方式是將電子郵件印至 console。在實際應用程式中，您會使用 SMTP service 或類似服務來真正傳送電子郵件！

  5. 返回 send_email 程式碼上方，在 process_expenses_data 函式中找到註解 Create a foundry chat client，並新增下列程式碼：

    （請務必保持縮排層級）

    # Create a foundry chat client 
client = FoundryChatClient(
    project_endpoint=os.getenv("PROJECT_ENDPOINT"),
    model=os.getenv("MODEL_DEPLOYMENT_NAME"),
    credential=AzureCliCredential()
)

    請注意， AzureCliCredential 物件會讓程式碼能向您的 Azure 帳戶進行驗證。此 client 將用來與 Foundry agent services 互動。

  6. 找到註解 Initialize an agent with the tool and instructions，並新增下列程式碼：

    （請務必保持縮排層級）

    # Initialize an agent with the tool and instructions
async with (
    Agent(
        client=client,
        name="ExpenseClaimAgent",
        instructions="""You are an AI assistant for expense claim submission.
                    At the user's request, create an expense claim and use the plug-in function to send an email to expenses@contoso.com with the subject 'Expense Claim`and a body that contains itemized expenses with a total.
                    Then confirm to the user that you've done so. Don't ask for any more information from the user, just use the data provided to create the email.""",
        tools=[submit_claim],
    ) as agent,
):

    在此程式碼中， Agent 物件會使用 client、agent 的指示，以及您定義的傳送電子郵件工具函式進行初始化。

  7. 找到註解 Use the agent to process the expenses data，並新增下列程式碼，建立供 agent 執行的 thread，接著使用聊天訊息呼叫 agent。

    （請務必保持縮排層級）：

    # Use the agent to process the expenses data
try:
    # Add the input prompt to a list of messages to be submitted
    prompt_messages = [f"{prompt}: {expenses_data}"]
    # Invoke the agent for the specified thread with the messages
    response = await agent.run(prompt_messages)
    # Display the response
    print(f"\n# Agent:\n{response}")
except Exception as e:
    # Something went wrong
    print (e)
  8. 檢閱已完成的 agent 程式碼，使用註解協助理解每個程式碼區塊的作用，然後儲存程式碼變更（CTRL+S).

測試應用程式

  1. 在整合式終端機中輸入下列命令，以執行應用程式：

    az login

    python agent-framework.py

    az login 可讓 AzureCliCredential 向您的 Azure 帳戶進行驗證。

  2. 當系統詢問如何處理費用資料時，輸入下列 prompt：

    Submit an expense claim

  3. 應用程式執行完成後，檢閱輸出。agent 應已根據提供的資料，撰寫一封費用報銷申請電子郵件。

    提示：如果應用程式因超過 rate limit 而失敗，請稍等幾秒後再試一次。如果您的 subscription 沒有足夠的 quota，model 可能無法回應。

  4. 完成後，輸入 deactivate （在終端機中），以離開 Python virtual environment。

清理

如果您已完成探索 Azure AI Agent Service，請刪除本練習中建立的資源，以避免產生不必要的 Azure 費用。

刪除您的 model

  1. 在 VS Code 中重新整理 Azure Resources 檢視。

  2. 展開 Models 子區段。

  3. 在已部署的 model 上按一下滑鼠右鍵，然後選取 Delete.

刪除 resource group

  1. 開啟 Azure portal.

  2. 瀏覽至包含 Microsoft Foundry 資源的 resource group。

  3. 選取 Delete resource group 並確認刪除。
