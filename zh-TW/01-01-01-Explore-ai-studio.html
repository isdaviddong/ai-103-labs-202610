準備 AI 開發專案

在此練習中，您將使用 Microsoft Foundry portal 建立專案，為建置 AI 解決方案做好準備。

此練習大約需要 30 分鐘。

注意：此練習使用的部分技術仍處於預覽階段或持續開發中。您可能遇到非預期的行為、警告或錯誤。

先決條件

開始此練習之前，請確認您具備下列項目：

  • 有效的 Azure subscription
  • Visual Studio Code 已安裝
  • Python 版本 3.13.xx 已安裝*
  • Git 已安裝並完成設定
  • Azure CLI 已安裝

* Python 3.14 已推出，但部分相依套件尚未針對此版本編譯。此實驗已使用 Python 3.13.12 成功測試。

建立 Microsoft Foundry 專案

Microsoft Foundry 使用專案來組織開發 AI 解決方案所需的 model、resource、資料及其他資產。

  1. 在網頁瀏覽器中，開啟 Microsoft Foundry portal ，網址為 https://ai.azure.com ，開始建置；使用您的 Azure 認證登入。關閉首次登入時開啟的任何提示或快速入門窗格。

  2. 如果尚未啟用，請在頁面頂端的工具列中啟用 New Foundry 選項。接著，以唯一的名稱建立新專案；展開 Advanced options 區域，為您的專案指定下列設定：
    • Foundry resource: 使用 resource 的預設名稱（通常為 {project_name}-resource）
    • Subscription: 您的 Azure subscription
    • Resource group: 建立或選取 resource group
    • Region：選取 AI Foundry recommended 的任一區域，請參閱 此清單

    提示：記下您選取的區域，稍後會用到！

  3. 選取 Create。等候專案建立完成。

    專案準備就緒時，會開啟專案首頁。

部署並測試 model

每個 generative AI 專案的核心都至少包含一個 generative AI model。

  1. 現在您已準備好探索 model。在 Discover 頁面中，選取 Models 索引標籤，檢視 Microsoft Foundry model catalog。

  2. 搜尋 gpt-5.2 model，然後在搜尋結果中選取它，檢視其 model card。

    Model card 提供 model 的相關資訊，協助您瞭解其功能與限制，並判斷是否符合您的需求。

  3. 選取 Deploy ，使用預設設定建立此 model 的 deployment。

    Model deployment 可讓您在專案中使用 model。

    Model 部署完成後，model playground 會自動開啟，讓您測試 model：

  4. 在 Instructions 方塊中，輸入下列指示：

     You are an AI assistant that can provide information and advice about AI software development.

  5. 在聊天視窗中，輸入查詢，例如 Describe three key considerations for working with Large Language Models for AI application development. ，並檢視回應：

    希望 model 已提供一些值得您思考的重要考量！

檢視 Foundry Azure resource 與專案 endpoint

  1. 在 Foundry portal 的頂端功能表列中，選取 Manage.

    您可以在管理中心檢視及管理專案與其父層 resource。

    • 其中， resource 層級對應到在 Azure 中建立、用來支援專案的 Foundry resource。此 resource 包含 Foundry Services 與 model 的連線，並提供集中管理 AI 開發專案使用者存取權的位置。
    • 而 project 層級對應到您的個別專案，您可以在其中新增及管理專案專用的 resource。一個 resource 可支援多個專案（首先建立的專案是該 resource 的 預設 專案）。

  2. 選取與此專案關聯的 Parent resource 連結。

    應會顯示 resource 的設定詳細資料。

    請注意，Foundry resource 具有 endpoint，用戶端應用程式可透過它存取 resource 層級的功能（例如該 resource 中所有專案共用的 Foundry Tools）。

  3. 在頂端功能表列中，選取 Home ，返回專案首頁。

  4. 記下 key、project endpoint 及 Azure OpenAI endpoint。

    用戶端應用程式會使用這些資訊連線到您的專案層級 resource。

    • 其中， key 用於對 model 與工具進行 key-based authentication（不過，在大多數正式環境中，您應考慮使用 Microsoft Entra ID authentication，依據已驗證的使用者與應用程式身分進行驗證）。
    • 而 project endpoint 用於透過 OpenAI Responses API 存取 Foundry 直接提供的 model（包括 OpenAI model），以及存取 Foundry 專用 API（例如 Foundry Agent service）。
    • 另外， OpenAI endpoint 用於透過 OpenAI API 存取 model，包括 Chat Completions API 與 Responses API。

安裝適用於 Visual Studio Code 的 Foundry Toolkit 擴充功能

身為開發人員，您可能會花一些時間在 Foundry portal 中工作，但也可能會花很多時間使用 Visual Studio Code。Foundry Toolkit 擴充功能提供便利的方式，讓您不必離開開發環境就能使用 Foundry 專案 resource。

  1. 啟動 Visual Studio Code
  2. 在左側導覽列中，檢視 Extensions 頁面。

  3. 在擴充功能市集中搜尋 Foundry Toolkit，並安裝 Foundry Toolkit for VS Code 擴充功能。

    安裝擴充功能可能需要約一分鐘。

  4. 安裝擴充功能後，在左側導覽列中選取 Foundry Toolkit 頁面，並等候載入完成。

  5. 在 Foundry Toolkit 窗格中，展開 Microsoft Foundry Resources ，然後連線至 Azure（使用您的認證登入），並選取先前建立的 Foundry 專案，將其設為預設專案。

  6. 設定預設專案後，展開專案，再展開 Models，並選取先前部署的 gpt-5.2 model。

    您可以在此檢視 model deployment 的詳細資料。

  7. 在 Foundry Toolkit 窗格的 Developer Tools 區段中，展開 Build 並選取 Model playground。接著選取 gpt-5.2 model（如果尚未選取）。

    Visual Studio Code 中會開啟互動式 playground，讓您測試 model。

摘要

在此練習中，您已建立 Microsoft Foundry 專案，並在 Foundry portal 中探索它。您也已探索 Visual Studio Code 中的 Foundry Toolkit 擴充功能；此擴充功能讓開發人員能便利地使用 Foundry 專案及其資產。

清理

如果您已完成 Foundry portal 的探索，請刪除此練習中建立的 resource，避免產生不必要的 Azure 費用。

  1. 在 Azure portal （網址為 https://portal.azure.com）中，檢視您部署此練習所用 resource 的 resource group 內容。
  2. 在工具列上，選取 Delete resource group.
  3. 輸入 resource group 名稱，並確認您要刪除它。
