使用支援語音的 generative AI model

generative AI model 的能力正逐漸超越以文字為基礎的語言補全，進而支援其他格式的內容，包括可聽見的語音。

在本練習中，您將使用 generative AI model 支援兩種常見情境：

  • speech synthesis（text-to-speech）：產生語音輸出。
  • speech recognition（speech-to-text）：將語音輸入轉錄為文字。

雖然本練習以 Python 為基礎，但您可以使用多種語言專屬的 SDK 開發 generative AI 語音應用程式，包括：

  • OpenAI SDK for Python
  • OpenAI SDK for .NET
  • OpenAI SDK for JavaScript

本練習約需 30 分鐘。

注意：本練習使用的部分技術仍處於預覽階段或積極開發中。您可能會遇到非預期的行為、警告或錯誤。

必要條件

開始本練習之前，請確認您已具備：

  • 有效的 Azure subscription
  • Visual Studio Code 已安裝
  • Python 版本 3.13.xx 已安裝*
  • Git 已安裝並完成設定
  • Azure CLI 已安裝

* Python 3.14 已推出，但部分相依套件尚未針對該版本完成編譯。本實驗已使用 Python 3.13.12 成功測試。

建立 Microsoft Foundry project

Microsoft Foundry 使用 project 來整理開發 AI 解決方案所需的 model、resource、資料及其他資產。

  1. 在網頁瀏覽器中開啟 Microsoft Foundry portal ，網址為 https://ai.azure.com ，並使用您的 Azure 認證登入。關閉首次登入時開啟的任何提示或快速入門窗格，必要時使用左上角的 Foundry 標誌導覽至首頁。

  2. 如果尚未啟用，請在頁面頂端的工具列啟用 New Foundry 選項。接著，如果出現提示，請建立名稱唯一的新 project；展開 Advanced options 區域，為 project 指定下列設定：

    • Foundry resource: 使用 resource 的預設名稱（通常為 {project_name}-resource）
    • Subscription: 您的 Azure subscription
    • Resource group: 建立或選取 resource group
    • Region：選取 East US 2 ，以使用本練習所需的 model 版本及 deployment 類型。

    重要：model 是否可用取決於 resource 的 region、model 版本及 deployment 類型。本練習使用 gpt-4o-mini-tts 及 gpt-4o-mini-transcribe的指定版本 deployment，位於 East US 2。Global Standard 並不表示 model 可部署至所有 resource region。能否部署也取決於 subscription 的 quota 及可用容量。

  3. 選取 Create。等待 project 建立完成，然後檢視其首頁。

部署 model

要開發支援語音的應用程式，我們需要支援語音的 model。具體而言，需要一個能產生語音的 model，以及一個能處理語音輸入的 model。

部署語音產生 model

  1. 現在您已準備好 Start building。讓我們選取 Explore models （或在 Discover 頁面選取 Models 索引標籤），以檢視 Microsoft Foundry model catalog。

  2. 在 model catalog 中搜尋 gpt-4o-mini-tts ，或搜尋您所在 region 可用的其他 text-to-speech model。

  3. 檢閱 model card，然後使用預設設定部署可用的 text-to-speech model。

  4. model 部署完成後，檢視其詳細資料，留意使用它所需的 Endpoint 可在此處取得（稍後您會需要此 Endpoint）。

    重要: gpt-4o-mini-tts 是本練習建議使用的 model，並非必要。如果您所在的 region 無法使用它，請改為部署受支援的 text-to-speech model。

部署 speech recognition model

  1. 在 Foundry portal 選單列中選取 Build，然後檢視 Deployments 頁面。請注意，您部署的 text-to-speech model 已列在其中。

  2. 選取 Deploy a base model，並在 catalog 中搜尋 gpt-4o-mini-transcribe ，或搜尋您所在 region 可用的其他 speech-to-text model。

  3. 使用預設設定部署可用的 speech-to-text model。

  4. 返回 Deployments 頁面，確認您部署的兩個 model 均已列出。

  5. 選取各個 model，以查看其 Endpoint 及 deployment 名稱，供程式碼使用。

    重要: gpt-4o-mini-transcribe 是本練習建議使用的 model，並非必要。如果您所在的 region 無法使用它，請改為部署受支援的 speech-to-text model。

從 GitHub 取得應用程式檔案

開發語音應用程式所需的初始應用程式檔案，已提供於 GitHub repo 中。

  1. 開啟 Visual Studio Code。

  2. 開啟命令選擇區（Ctrl+Shift+P），並使用 Git:clone 命令將 https://github.com/microsoftlearning/mslearn-ai-language repo 複製到本機資料夾（任一資料夾皆可），然後開啟它。

    系統可能會要求您確認是否信任作者。

  3. 在 Visual Studio Code 中檢視 Extensions 窗格；如果尚未安裝，請安裝 Python 擴充功能。

  4. 在 Command Palette中使用命令 python:select interpreter。接著，若已有環境，請選取現有環境；或根據已安裝的 Python 3.1x 建立新的 Venv 環境。

    提示：若系統提示您安裝相依套件，可以安裝 requirements.txt 檔案中列出的套件，該檔案位於 /Labfiles/03-gen-ai-speech/Python/generate-speech 資料夾；但即使現在不安裝也沒關係，我們稍後會安裝！

    提示：如果您偏好使用終端機，可以建立 Venv 環境，使用 python -m venv labenv，然後使用以下命令啟用它： \labenv\Scripts\activate.

建立語音產生應用程式

  1. 複製 repo 後，在 Explorer 窗格中導覽至應用程式程式碼檔案所在的資料夾： /Labfiles/03-gen-ai-speech/Python/generate-speech。應用程式檔案包括：
    • .env （應用程式設定檔）
    • requirements.txt （需要安裝的 Python 套件相依性）
    • generate-speech.py （應用程式的程式碼檔案）

設定應用程式

  1. 在 Explorer 窗格中，以滑鼠右鍵按一下 generate-speech 資料夾（其中包含應用程式檔案），然後選取 Open in integrated terminal （或從 Terminal 選單開啟終端機，並導覽至 /Labfiles/03-gen-ai-speech/Python/generate-speech 資料夾）。

    注意：在 Visual Studio Code 中開啟終端機會自動啟用 Python 環境。您可能需要允許系統執行 script。

  2. 確認終端機已在 generate-speech 資料夾中開啟，且顯示前綴 (.venv) ，表示您建立的 Python 環境已啟用。

  3. 執行下列命令，安裝 OpenAI SDK 套件及其他必要套件：

    pip install -r requirements.txt

  4. 在 Explorer 窗格的 generate-speech 資料夾中，選取 .env 檔案以開啟它。接著更新設定值，填入 Endpoint 及 deployment 名稱，對應的 model 為 gpt-4o-mini-tts 。

    提示：請複製 Endpoint ，其位置在 Foundry portal 的 model deployment 詳細資料頁面。此處使用的 AzureOpenAI client 需要 Azure OpenAI resource endpoint，例如 https://<resource-name>.openai.azure.com/，而不是以 /api/projects/<project-name> 結尾的 Foundry project URL，也不是附加了 /openai/v1/ 的 URL。請使用您的 deployment 名稱，它可能與 model 名稱不同。

    儲存修改後的設定檔。

撰寫使用 model 產生語音的程式碼

  1. 在 Explorer 窗格的 generate-speech 資料夾中，選取 generate-speech.py 檔案以開啟它。

  2. 檢閱現有程式碼。您將新增使用 OpenAI SDK 存取 model 的程式碼。

    提示：將程式碼新增至程式碼檔案時，請務必維持正確的縮排。

  3. 在程式碼檔案頂端、現有 namespace 參考下方，找出註解 Import namespaces ，然後新增下列程式碼，以匯入使用 OpenAI SDK 所需的 namespace：

    # import namespaces
from openai import AzureOpenAI
from azure.identity import DefaultAzureCredential, get_bearer_token_provider

  4. 在 main 函式中，請注意已提供從設定檔載入 endpoint 的程式碼。接著找出註解 Create the Azure OpenAI client，並新增下列程式碼，以建立 OpenAI API 的 client：

    # Create the Azure OpenAI client
token_provider = get_bearer_token_provider(                    
    DefaultAzureCredential(), "https://ai.azure.com/.default"
)

client = AzureOpenAI(
    azure_endpoint=endpoint,
    azure_ad_token_provider = token_provider,
    api_version="2025-03-01-preview"
)

  5. 找出註解 Generate speech and save to file，並新增下列程式碼，將 prompt 提交至語音產生 model，並將回應儲存為檔案。

    # Generate speech and save to file
with client.audio.speech.with_streaming_response.create(
            model=model_deployment,
            voice="alloy",
            input="My voice is my passport!",
            instructions="Speak in a serious tone.",
        ) as response:
    response.stream_to_file(speech_file_path)

  6. 儲存程式碼檔案的變更。

執行應用程式

  1. 在終端機窗格中，使用下列命令登入 Azure。

    az login

    注意：在大多數情況下，僅使用 az login 即可。不過，如果您的 subscription 分屬多個 tenant，可能需要使用 --tenant 參數指定 tenant。請參閱 使用 Azure CLI 以互動方式登入 Azure 以取得詳細資訊。

  2. 出現提示時，請依照指示登入 Azure。接著在命令列完成登入程序，檢視包含 Foundry resource 的 subscription 詳細資料（必要時進行確認）。

  3. 登入後，輸入下列命令以執行應用程式：

    python generate-speech.py

  4. 觀察輸出，程式碼會產生所要求的語音並儲存為檔案。程式碼也應播放產生的音訊檔案。

建立語音轉錄應用程式

  1. 在 Explorer 窗格中，導覽至應用程式程式碼檔案所在的資料夾： /Labfiles/03-gen-ai-speech/Python/transcribe-speech。應用程式檔案包括：
    • .env （應用程式設定檔）
    • requirements.txt （需要安裝的 Python 套件相依性）
    • transcribe-speech.py （應用程式的程式碼檔案）

設定應用程式

  1. 在 Explorer 窗格中，以滑鼠右鍵按一下 transcribe-speech 資料夾（其中包含應用程式檔案），然後選取 Open in integrated terminal （或在現有終端機中導覽至 /Labfiles/03-gen-ai-speech/Python/transcribe-speech 資料夾）。

    注意：在 Visual Studio Code 中開啟終端機會自動啟用 Python 環境。您可能需要允許系統執行 script。

  2. 確認終端機已在 transcribe-speech 資料夾中開啟，且顯示前綴 (.venv) ，表示您先前建立的 Python 環境已啟用。

  3. 執行下列命令，安裝 OpenAI SDK 套件及其他必要套件：

    pip install -r requirements.txt

    注意：如果您已完成本練習的前一部分，其實不需要此步驟，因為兩個應用程式使用相同環境且具有相同的相依套件；但再執行一次也不會有任何影響！

  4. 在 Explorer 窗格的 transcribe-speech 資料夾中，選取 .env 檔案以開啟它。接著更新設定值，填入 Endpoint 及 deployment 名稱，對應的 model 為 gpt-4o-mini-transcribe 。

    提示：請複製 Endpoint ，其位置在 Foundry portal 的 model deployment 詳細資料頁面。如同語音產生應用程式，請使用 Azure OpenAI resource endpoint 及您的 deployment 名稱，而非 Foundry project URL。

    儲存修改後的設定檔。

撰寫使用 model 轉錄語音的程式碼

  1. 在 Explorer 窗格的 transcribe-speech 資料夾中，選取 transcribe-speech.py 檔案以開啟它。

  2. 檢閱現有程式碼。您將新增使用 OpenAI SDK 存取 model 的程式碼。

    提示：將程式碼新增至程式碼檔案時，請務必維持正確的縮排。

  3. 在程式碼檔案頂端、現有 namespace 參考下方，找出註解 Import namespaces ，然後新增下列程式碼，以匯入使用 OpenAI SDK 所需的 namespace：

    # import namespaces
from openai import AzureOpenAI
from azure.identity import DefaultAzureCredential, get_bearer_token_provider

  4. 在 main 函式中，請注意已提供從設定檔載入 endpoint 的程式碼。接著找出註解 Create the Azure OpenAI client，並新增下列程式碼，以建立 OpenAI API 的 client：

    # Create the Azure OpenAI client
token_provider = get_bearer_token_provider(                    
    DefaultAzureCredential(), "https://ai.azure.com/.default"
)

client = AzureOpenAI(
    azure_endpoint=endpoint,
    azure_ad_token_provider = token_provider,
    api_version="2025-03-01-preview"
)

  5. 找出註解 Call model to transcribe audio file，並新增下列程式碼，將音訊檔案提交至語音轉錄 model，以產生轉錄文字。

    # Call model to transcribe audio file
audio_file = open(file_path, "rb")
transcription = client.audio.transcriptions.create(
    model=model_deployment,
    file=audio_file,
    response_format="text"
)
    
print(transcription)

  6. 儲存程式碼檔案的變更。

清理資源

如果您已完成 Foundry Tools 中支援語音的 model 探索，應刪除在本練習中建立的 resource，以避免產生不必要的 Azure 費用。

  1. 開啟 Azure portal ，並檢視您部署本練習所用 resource 的 resource group 內容。
  2. 在工具列上選取 Delete resource group.
  3. 輸入 resource group 名稱，並確認要刪除它。
