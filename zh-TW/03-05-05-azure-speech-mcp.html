在 agent 中使用 Azure Speech

Azure Speech in Foundry Tools 提供 MCP server，您可以使用它讓 agent 呼叫 speech recognition 與 speech synthesis 功能。

在本練習中，您將設定 Azure Speech in Foundry Tools MCP server，並將它連線至 agent。

本練習所用的程式碼以 Microsoft Foundry SDK for Python 為基礎。您可以使用 Microsoft .NET、JavaScript 與 Java 的 SDK 開發類似的解決方案。請參閱 Microsoft Foundry SDK client libraries 以取得詳細資訊。

本練習約需 30 分鐘。

注意：本練習使用的部分技術仍處於預覽階段或積極開發中。您可能會遇到非預期的行為、警告或錯誤。

必要條件

開始本練習之前，請確認您已具備：

  • 有效的 Azure subscription
  • Visual Studio Code 已安裝
  • Python 版本 3.13.xx 已安裝*
  • Git 已安裝並完成設定
  • Azure CLI 已安裝

* Python 3.14 已推出，但部分相依套件尚未針對該版本完成編譯。本實驗已使用 Python 3.13.12 成功測試。

建立 Azure storage account

Azure Speech MCP server 使用 Azure storage account 儲存產生的音訊檔案。

  1. 開啟 Azure portal ，網址為 https://portal.azure.com，並使用您的 Azure 認證登入。

  2. 建立新的 Azure storage account resource，使用下列設定：

    • Subscription: 您的 subscription
    • Resource group: 建立或選取 resource group
    • Storage account name: storage account 的唯一名稱
    • Region: 任何可用的 region
    • Preferred storage type：Azure blob storage 或 Azure Data Lake Storage Gen2
    • Primary workload：Cloud native
    • Performance：Standard
    • Redundancy：Locally-redundant storage (LRS)

  3. Azure storage account resource 建立完成後，在 portal 中開啟該 resource。

  4. 在 storage account 的左側導覽窗格中展開 Data storage，然後選取 Containers.

  5. 新增 container，名稱為 files。agent 將在此儲存它產生的音訊檔案。

  6. 在快顯功能表（...）中，針對 files container 選取 Generate SAS，並依下列詳細資料建立 SAS token：

    • Signing method ：Account key
    • Signing key：Key1
    • Stored access policy：None
    • Permissions:
      • Read
      • Add
      • Create
      • Write
      • List
    • Start and expiry date/time:
      • Start：目前的日期與時間
      • Expiry：明天晚上 11:59
    • Allowed IP addresses: 留白
    • Allowed protocols：HTTPS only

    重要：複製產生的 SAS token 及 URL，暫時儲存到文字檔案中，稍後您將需要它們！

建立 Microsoft Foundry project

Microsoft Foundry 使用 project 來整理開發 AI 解決方案所需的 model、resource、資料及其他資產。

  1. 在網頁瀏覽器中開啟 Microsoft Foundry portal ，網址為 https://ai.azure.com ，並使用您的 Azure 認證登入。關閉首次登入時開啟的任何提示或快速入門窗格，必要時使用左上角的 Foundry 標誌導覽至首頁。

  2. 如果尚未啟用，請在頁面頂端的工具列啟用 New Foundry 選項。接著，如果出現提示，請建立名稱唯一的新 project；展開 Advanced options 區域，為 project 指定下列設定：

    • Foundry resource: 使用 resource 的預設名稱（通常為 {project_name}-resource）
    • Subscription: 您的 Azure subscription
    • Resource group: 建立或選取 resource group
    • Region：選取任何可用的 region

    注意：請使用建議的 Microsoft Foundry region。可用的 model 可能因 region 而異。

    提示：請記住（或記下）Foundry resource 名稱，稍後您將需要它！

  3. 等待 project 建立完成。

  4. 在 project 首頁上，請注意此處顯示了 API key、project endpoint 及 OpenAI endpoint。

    提示：將 project key 複製到剪貼簿，稍後您將需要它！

建立 agent

您已具備 Foundry project，現在可以建立 agent。

  1. 現在您已準備好 Start building。選取 Create agents （或在 Build 頁面選取 Agents 索引標籤），並建立新 agent，名稱為 speech-agent.

    準備完成後，您的 agent 會在 agent playground 中開啟。

  2. 在 model 下拉式清單中，確認已部署並為 agent 選取 gpt-5 model。

  3. 為 agent 設定以下 Instructions:

    You are an AI agent that uses the Azure AI Speech tool to transcribe and generate speech.

  4. 使用 Save 按鈕儲存變更。

  5. 在 Chat 窗格中輸入下列 prompt，以測試 agent：

    What can you help me with?

    agent 應根據其指示提供適當的回答。

建立 Azure Speech in Foundry Tools 連線

Foundry 包含 Azure Speech in Foundry Tools 的 MCP server，您可以將它連線至 project，並在 agent 中使用。

  1. 在左側導覽窗格中，選取 Tools 頁面。

  2. 在 Tools 索引標籤中連線至工具；選取 Azure Speech MCP Server ，其位於 Catalog 中，然後將它連線至 endpoint，指定下列設定：

    • Name: 工具的唯一名稱。

    • Remote MCP Server endpoint: https://{foundry-resource-name}.cognitiveservices.azure.com/speech/mcp?api-version=2025-11-15-preview

    • Parameters：foundry-resource-name： 您的 Foundry resource 名稱

    • Authentication：Key-based：

    • Ocp-Apim-Subscription-Key: 您的 Foundry project 的 API Key

    • X-Blob-Container-Url: 您的 storage container 的 SAS URL

    注意：如果 Azure subscription 中的原則停用了 key-based authentication，您可以使用 Entra ID authentication，將 agent 連線至 Azure Speech 服務。

  3. 等待 MCP 工具連線建立完成，然後檢視其詳細資料頁面。

  4. 在 Azure Speech in Foundry Tools 連線的詳細資料頁面上，選取 Use in an agent，然後選取先前建立的 Speech-Agent agent。

    agent 應在 playground 中開啟，並已連線至 Azure Speech in Foundry Tools 工具。

在 playground 中測試 Azure Speech 工具

接下來測試 agent 使用您所連線工具的能力。

  1. 在 speech-agent agent 的 agent playground 中，輸入下列 prompt：

    Generate "To be or not to be, that is the question." as speech

  2. 出現提示時，請選取以下選項以核准使用 Azure Speech 工具： Always approve all Azure Speech MCP Server tools.

  3. 檢閱回應，其中應包含產生的音訊檔案連結。接著按一下連結，聆聽合成的語音。

  4. 輸入下列 prompt：

    Transcribe the file at https://microsoftlearning.github.io/mslearn-ai-language/Labfiles/05-speech-tool/speech_1.wav

  5. 如果出現提示，請選取以下選項以核准使用 Azure Speech 工具： Always approve all Azure Speech MCP Server tools.

    注意：如果呼叫工具時發生暫時性錯誤，請重新整理頁面，並重試相同的 prompt。

    注意：您可能會看到訊息，指出互動遭到 Foundry guardrail 封鎖。這是因為 Foundry 內建的 content safety 檢查標記了以下檔案的轉錄內容： speech_1.wav。如果發生此情況，請重試 prompt，改用 speech_2.wav ，此檔案不受影響。

  6. 檢閱輸出；它應為音訊檔案的轉錄文字。

建立 client 應用程式

您已具備可運作的 agent，現在可以建立使用它的 client 應用程式。

從 GitHub 取得應用程式檔案

  1. 開啟 Visual Studio Code。

  2. 開啟命令選擇區（Ctrl+Shift+P），並使用 Git:clone 命令將 https://github.com/microsoftlearning/mslearn-ai-language repo 複製到本機資料夾（任一資料夾皆可），然後開啟它。

    系統可能會要求您確認是否信任作者。

  3. 複製 repo 後，在 Explorer 窗格中導覽至應用程式程式碼檔案所在的資料夾： /Labfiles/05-speech-tool/Python/speech-client。應用程式檔案包括：

    • .env （應用程式設定檔）
    • requirements.txt （需要安裝的 Python 套件相依性）
    • speech-client.py （應用程式的程式碼檔案）

設定應用程式

  1. 在 Visual Studio Code 中檢視 Extensions 窗格；如果尚未安裝，請安裝 Python 擴充功能。

  2. 在 Command Palette中使用命令 python:select interpreter。接著，若已有環境，請選取現有環境；或根據已安裝的 Python 3.1x 建立新的 Venv 環境。

    提示：若系統提示您安裝相依套件，可以安裝 requirements.txt 檔案中列出的套件，該檔案位於 /Labfiles/05-speech-tool/Python/speech-client 資料夾；但即使現在不安裝也沒關係，我們稍後會安裝！

    提示：如果您偏好使用終端機，可以建立 Venv 環境，使用 python -m venv labenv，然後使用以下命令啟用它： \labenv\Scripts\activate.

  3. 在 Explorer 窗格中，以滑鼠右鍵按一下 speech-client 資料夾（其中包含應用程式檔案），然後選取 Open in integrated terminal （或從 Terminal 選單開啟終端機，並導覽至 /Labfiles/05-speech-tool/Python/speech-client 資料夾）。

    注意：在 Visual Studio Code 中開啟終端機會自動啟用 Python 環境。您可能需要允許系統執行 script。

  4. 確認終端機已在 speech-client 資料夾中開啟，且顯示前綴 (.venv) ，表示您建立的 Python 環境已啟用。

  5. 執行下列命令，安裝 Foundry SDK 套件、Azure Identity 套件及其他必要套件：

    pip install -r requirements.txt

  6. 在 Explorer 窗格的 speech-client 資料夾中，選取 .env 檔案以開啟它。接著更新設定值，填入 project 的 endpoint （可從 Foundry Portal 的 project 首頁取得）及 agent 名稱（應為 speech-agent ；請注意此名稱區分大小寫）。

  7. 儲存修改後的設定檔。

實作應用程式程式碼

  1. 在 Explorer 窗格的 speech-client 資料夾中，開啟 speech-client.py 檔案。

  2. 檢閱現有程式碼。您將新增向 agent 提交 prompt 的程式碼。

    提示：將程式碼新增至程式碼檔案時，請務必維持正確的縮排。

  3. 在程式碼檔案頂端、現有 namespace 參考下方，找出註解 Import namespaces ，然後新增下列程式碼，以匯入所需的 namespace：

    # import namespaces
from azure.identity import DefaultAzureCredential
from azure.ai.projects import AIProjectClient

  4. 在 main 函式中，請注意已提供從設定檔載入 endpoint 的程式碼。接著找出註解 Get project client，並新增下列程式碼，以建立 Foundry project 的 client：

    # Get project client
project_client = AIProjectClient(
    endpoint=foundry_endpoint,
    credential=DefaultAzureCredential(),
)

  5. 找出註解 Get an OpenAI client，並新增下列程式碼，以取得用來呼叫 agent 的 OpenAI client。

    # Get an OpenAI client
openai_client = project_client.get_openai_client()

  6. 找出註解 Use the agent to get a response，並新增下列程式碼，向 agent 提交使用者 prompt 並顯示回應。

    # Use the agent to get a response
response = openai_client.responses.create(
    input=[{"role": "user", "content": prompt}],
    extra_body={"agent_reference": {"name": agent_name, "type": "agent_reference"}},
)

print(f"{agent_name}: {response.output_text}")

  7. 儲存對程式碼檔案所做的變更。

測試 client 應用程式

現在讓我們在 Python 環境中執行應用程式，並驗證連線至 project 的身分，以測試應用程式。

  1. 在終端機窗格中，使用下列命令登入 Azure。

    az login

    注意：在大多數情況下，僅使用 az login 即可。不過，如果您的 subscription 分屬多個 tenant，可能需要使用 --tenant 參數指定 tenant。請參閱 使用 Azure CLI 以互動方式登入 Azure 以取得詳細資訊。

  2. 出現提示時，請依照指示登入 Azure。接著在命令列完成登入程序，檢視包含 Foundry resource 的 subscription 詳細資料（必要時進行確認）。

  3. 登入後，輸入下列命令以執行應用程式：

    python speech-client.py

  4. 出現提示時，輸入下列 prompt：

    Synthesize "Better a witty fool, than a foolish wit!" as speech using the voice "en-GB-SoniaNeural".

  5. 檢閱回應；其中應包含可點擊的連結，指向產生的音訊檔案。

  6. 查看產生的音訊檔案後，輸入下列 prompt：

    Transcribe https://microsoftlearning.github.io/mslearn-ai-language/Labfiles/05-speech-tool/speech_2.wav

  7. 檢閱回應。

  8. 若要結束程式，請輸入 "quit" （或直接按 Enter）

清理資源

如果您已完成 Azure AI Language 服務的探索，可以刪除在本練習中建立的 resource。步驟如下：

  1. 在 Azure portal 中，瀏覽至您在本實驗中建立的 Foundry resource。
  2. 在 resource 頁面上選取 Delete ，並依照指示刪除 resource。
