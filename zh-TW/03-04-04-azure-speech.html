辨識與合成語音

Azure Speech in Foundry Tools 是一項提供語音相關功能的服務，包括：

  • 一個 speech-to-text API，可用來實作 speech recognition（將可聽見的口語轉換為文字）。
  • 一個 text-to-speech API，可用來實作 speech synthesis（將文字轉換為可聽見的語音）。

在本練習中，您將使用這兩個 API 實作語音留言助理。

雖然本練習以 Python 為基礎，但您可以使用多種語言專屬的 SDK 開發語音應用程式，包括：

  • Azure Speech SDK for Python
  • Azure Speech SDK for .NET
  • Azure Speech SDK for JavaScript

本練習約需 30 分鐘。

注意：本練習使用的部分技術仍處於預覽階段或積極開發中。您可能會遇到非預期的行為、警告或錯誤。

必要條件

開始本練習之前，請確認您已具備：

  • 有效的 Azure subscription
  • Visual Studio Code 已安裝
  • Python 版本 3.13.xx 已安裝*
  • Git 已安裝並完成設定
  • Azure CLI 已安裝

* Python 3.14 已推出，但部分相依套件尚未針對該版本完成編譯。本實驗已使用 Python 3.13.12 成功測試。

建立 Microsoft Foundry project

Microsoft Foundry 使用 project 來整理開發 AI 解決方案所需的 model、resource、資料及其他資產。

  1. 在網頁瀏覽器中開啟 Microsoft Foundry portal ，網址為 https://ai.azure.com ，並使用您的 Azure 認證登入。關閉首次登入時開啟的任何提示或快速入門窗格，必要時使用左上角的 Foundry 標誌導覽至首頁。

  2. 如果尚未啟用，請在頁面頂端的工具列啟用 New Foundry 選項。接著，如果出現提示，請建立名稱唯一的新 project；展開 Advanced options 區域，為 project 指定下列設定：

    • Foundry resource: 使用 resource 的預設名稱（通常為 {project_name}-resource）*
    • Subscription: 您的 Azure subscription
    • Resource group: 建立或選取 resource group
    • Region：選取任何可用的 region

    注意：請使用建議的 Microsoft Foundry region。可用的 model 可能因 region 而異。

    提示：* 請記住 Foundry resource 名稱，稍後您將需要它！

  3. 等待 project 建立完成，然後檢視 project 首頁。

從 GitHub 取得應用程式檔案

開發語音應用程式所需的初始應用程式檔案，已提供於 GitHub repo 中。

  1. 開啟 Visual Studio Code。

  2. 開啟命令選擇區（Ctrl+Shift+P），並使用 Git:clone 命令將 https://github.com/microsoftlearning/mslearn-ai-language repo 複製到本機資料夾（任一資料夾皆可），然後開啟它。

    系統可能會要求您確認是否信任作者。

  3. 複製 repo 後，在 Explorer 窗格中導覽至應用程式程式碼檔案所在的資料夾： /Labfiles/04-azure-speech/Python/voice-mail。應用程式檔案包括：

    • messages （包含留言音訊錄音的子資料夾）
    • .env （應用程式設定檔）
    • requirements.txt （需要安裝的 Python 套件相依性）
    • voice-mail.py （應用程式的程式碼檔案）

設定應用程式

  1. 在 Visual Studio Code 中檢視 Extensions 窗格；如果尚未安裝，請安裝 Python 擴充功能。

  2. 在 Command Palette中使用命令 python:select interpreter。接著，若已有環境，請選取現有環境；或根據已安裝的 Python 3.1x 建立新的 Venv 環境。

    提示：若系統提示您安裝相依套件，可以安裝 requirements.txt 檔案中列出的套件，該檔案位於 /Labfiles/04-azure-speech/Python/voice-mail 資料夾；但即使現在不安裝也沒關係，我們稍後會安裝！

    提示：如果您偏好使用終端機，可以建立 Venv 環境，使用 python -m venv labenv，然後使用以下命令啟用它： \labenv\Scripts\activate.

  3. 在 Explorer 窗格中，以滑鼠右鍵按一下 voice-mail 資料夾（其中包含應用程式檔案），然後選取 Open in integrated terminal （或從 Terminal 選單開啟終端機，並導覽至 /Labfiles/04-azure-speech/Python/voice-mail 資料夾）。

    注意：在 Visual Studio Code 中開啟終端機會自動啟用 Python 環境。您可能需要允許系統執行 script。

  4. 確認終端機已在 voice-mail 資料夾中開啟，且顯示前綴 (.venv) ，表示您建立的 Python 環境已啟用。

  5. 執行下列命令，安裝 Azure AI Speech SDK 套件及其他必要套件：

    pip install -r requirements.txt

  6. 在 Explorer 窗格的 voice-mail 資料夾中，選取 .env 檔案以開啟它。接著更新設定值，填入 Cognitive Services endpoint ，其所屬 resource 為您的 Foundry resource。

    重要：endpoint 應為 https://{YOUR_FOUNDRY_RESOURCE}.cognitiveservices.azure.com/。Foundry resource 名稱通常採用以下形式： {project_name}-resource.

    儲存修改後的設定檔。

新增合成語音的程式碼

  1. 在 Explorer 窗格的 voice-mail 資料夾中，開啟 voice-mail.py 檔案。

  2. 檢閱現有程式碼。您將新增使用 Azure Speech SDK 的程式碼。

    提示：將程式碼新增至程式碼檔案時，請務必維持正確的縮排。

  3. 在程式碼檔案頂端、現有 namespace 參考下方，找出註解 Import namespaces ，然後新增下列程式碼，以匯入使用 Speech SDK 所需的 namespace：

    # import namespaces
from azure.identity import DefaultAzureCredential
import azure.cognitiveservices.speech as speech_sdk

  4. 在 main 函式中，請注意已提供從設定檔載入 endpoint 的程式碼。接著找出註解 Create speech_config using Entra ID authentication，並新增下列程式碼，以建立 Speech Configuration 物件：

    # Create speech_config using Entra ID authentication
credential = DefaultAzureCredential()
speech_config = speech_sdk.SpeechConfig(    
    token_credential=credential,
    endpoint=foundry_endpoint)

  5. 檢閱其餘的 main 函式，留意已實作一個迴圈，讓使用者可以選擇以下三個選項之一：

    1. Record a voice greeting
    2. Transcribe messages
    3. Exit the application

  6. 找出 record_greeting 函式；您將實作此函式，把語音問候語錄製為音訊檔案。

  7. 在 record_greeting 函式中，找出註解 Synthesize the greeting message to an audio file，並新增下列程式碼，將使用者輸入的文字合成為語音，並儲存為音訊檔案。

    output_file = "greeting.wav"
audio_config = speech_sdk.audio.AudioOutputConfig(filename=output_file)

speech_config.speech_synthesis_voice_name = "en-US-Serena:DragonHDLatestNeural"

speech_synthesizer = speech_sdk.SpeechSynthesizer(
    speech_config=speech_config,
    audio_config=audio_config
)

result = speech_synthesizer.speak_text_async(greeting_message).get()

if result.reason == speech_sdk.ResultReason.SynthesizingAudioCompleted:
    print(f"Greeting recorded and saved to {output_file}")
    speech_synthesizer = None  # Release the synthesizer resources
else:
    print("Error recording greeting: {}".format(result.reason))

  8. 儲存程式碼檔案的變更。接著在終端機窗格中，使用下列命令登入 Azure。

    az login

    注意：在大多數情況下，僅使用 az login 即可。不過，如果您的 subscription 分屬多個 tenant，可能需要使用 --tenant 參數指定 tenant。請參閱 使用 Azure CLI 以互動方式登入 Azure 以取得詳細資訊。

  9. 出現提示時，請依照指示登入 Azure。接著在命令列完成登入程序，檢視包含 Foundry resource 的 subscription 詳細資料（必要時進行確認）。

  10. 登入後，輸入下列命令以執行應用程式：

    python voice-mail.py

  11. 出現提示時，輸入 1 以錄製問候語。

  12. 輸入問候語，例如 Hi. The person you called is not available right now. Leave a message.

  13. 等待語音合成完成並儲存為音訊檔案。

    您可以選取 greeting.wav 檔案（產生於 voice-mail 資料夾中），以在 Visual Studio Code 中播放它。

新增辨識語音的程式碼

  1. 在 voice-mail.py 程式碼檔案中，找出 transcribe_messages 函式；您將實作此函式，轉錄 messages 子資料夾中的各則語音留言。

    此函式已包含用來逐一處理 messages 資料夾中檔案的程式碼。

  2. 在 transcribe_messages 函式中，找出註解 Transcribe the audio file，並新增下列程式碼以轉錄音訊。

    # Transcribe the audio file
audio_config = speech_sdk.audio.AudioConfig(filename=file_path)
speech_recognizer = speech_sdk.SpeechRecognizer(
    speech_config=speech_config,
    audio_config=audio_config
)
result = speech_recognizer.recognize_once_async().get()
if result.reason == speech_sdk.ResultReason.RecognizedSpeech:
    print(f"Transcription: {result.text}")
else:
    print("Error transcribing message: {}".format(result.reason))

  3. 儲存程式碼檔案的變更。接著在終端機中，輸入下列命令以執行應用程式：

    python voice-mail.py

  4. 出現提示時，輸入 2 以轉錄留言。

  5. 檢視每則留言的轉錄文字。

    每個檔案都會自動播放，讓您可以聽到留言。

清理資源

如果您已完成 Azure Speech in Foundry Tools 的探索，應刪除在本練習中建立的 resource，以避免產生不必要的 Azure 費用。

  1. 開啟 Azure portal ，並檢視您部署本練習所用 resource 的 resource group 內容。
  2. 在工具列上選取 Delete resource group.
  3. 輸入 resource group 名稱，並確認要刪除它。
