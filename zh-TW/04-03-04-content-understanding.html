使用 Azure Content Understanding 分析影像

Foundry Tools 中的 Azure Content Understanding 是 Microsoft AI Foundry 提供的功能，使用 generative AI 分析並解讀不同類型的非結構化內容，包括文件、影像、音訊和影片。透過將 AI model 套用至這些內容，此服務可產生符合使用者自訂 schema 的結構化輸出。這些結構化輸出讓擷取的資訊更容易整合至自動化、分析和搜尋工作流程。

組織經常面臨的一項挑戰，是管理大量視覺內容。影像往往包含有價值的資訊，但若沒有描述性的 metadata，這些資訊可能難以搜尋或整理。Azure Content Understanding 可以分析影像並產生結構化描述，協助分類視覺內容並建立索引，讓相關影像更容易被找到，也更容易整合至搜尋系統。

在本練習中，您將探索如何在 Content Understanding Studio 網頁介面中建立及使用影像 analyzer。您將針對範例影像執行 analyzer，並檢閱產生的描述，這些描述可作為建立索引和搜尋所需的 metadata。完成本實驗後，您將了解 AI 生成的影像描述如何讓視覺內容更容易搜尋，並在資料驅動的應用程式中發揮更大效益。

本練習大約需要 30 分鐘。

注意：本練習使用的部分技術仍處於預覽階段或積極開發中。您可能會遇到非預期的行為、警告或錯誤。視設定而定，影片生成可能需要 1 至 5 分鐘才能完成。

必要條件

若要完成本練習，您需要：

  • 一個 Azure 訂用帳戶 ，且具有建立 AI resource 的權限。
  • Visual Studio Code 已安裝於本機電腦。
  • Python 3.13 或更新版本已安裝於本機電腦。
  • Azure CLI 已安裝於本機電腦。

建立 Microsoft Foundry project

Microsoft Foundry 使用 project 來組織開發 AI 解決方案所用的 model、resource、資料及其他資產。

  1. 在網頁瀏覽器中，開啟 Microsoft Foundry portal ，網址為 https://ai.azure.com 以開始建置；請使用 Azure 認證登入。關閉首次登入時開啟的所有提示或快速入門窗格。

  2. 如果尚未啟用，請在頁面頂端的工具列啟用 New Foundry 選項。接著，如果出現提示，請建立名稱唯一的新 project；展開 Advanced options 區域，為 project 指定下列設定：
    • Foundry resource: 使用 resource 的預設名稱（通常為 {project_name}-resource）
    • Subscription: 您的 Azure 訂用帳戶
    • Resource group: 建立或選取 resource group
    • Region：選取任何可用的區域

  3. 等待 project 建立完成。然後在 project 首頁上，檢視 project 詳細資料。

    建立 Foundry project 時，也會在 Azure 中建立與 project 連結的 Foundry resource group。此 resource group 將連線至 Azure Content Understanding 服務，以及您選擇部署供 Foundry project 使用的其他 AI 服務。

建立 Azure storage account

您需要 Azure storage account，以儲存即將使用 Azure Content Understanding 分析的內容資產。

  1. 在新的瀏覽器索引標籤中，開啟 Azure portal ，網址為 https://portal.azure.com ，並瀏覽至您建立 Foundry project resource 的 resource group。

    此 resource group 應包含您的 Foundry resource 和已建立的 project。

  2. 在 resource group 中建立新的 Storage account resource，並使用下列設定：
    • Subscription: 您的 Azure 訂用帳戶
    • Resource group: 包含 Foundry resource 的 resource group
    • Storage account name: storage account 的唯一名稱
    • Region: 與 Foundry resource 相同的區域
    • Primary service：Azure Blob Storage 或 Azure Data Lake Storage Gen 2
    • Performance：Standard
    • Redundancy：Locally-redundant storage (LRS)
  3. 等待 storage account 建立完成。

在 Azure Content Understanding 中建立影像 analyzer

既然已有 Foundry project，您便可以部署內容理解所需的 AI model。

  1. 在新的瀏覽器索引標籤中，瀏覽至 Content Understanding Studio ，網址為 https://contentunderstanding.ai.azure.com/home ；如果出現提示，請使用 Azure 認證登入。

  2. 在右上角，選取 Settings 圖示，以檢視 Azure Content Understanding 的帳戶設定。

  3. 在 Setup Azure resource 頁面上，選取 Add resource 按鈕。

  4. 選取您的訂用帳戶，以及名稱與 Foundry project 相符的 Foundry resource。

  5. 勾選 Enable auto-deployment for required models if no default deployment available.

  6. 選取 Next，接著選取 Save 以部署必要的 model。

    部署程序可能需要數分鐘。model 部署完成後，resource 將顯示於 Connected Azure AI Foundry Resources下方。記下 resource 名稱。

  7. 在功能表列上，選取 Build。接著使用 Create 按鈕，依下列設定建立新的 Content Understanding project。
    • Project name: 影像分析 project 的唯一名稱
    • Description：Image analysis project
    • Type of project：Extract content and field with custom schema
    • Advanced settings：確認已選取 Foundry resource 和 storage account、將建立新的 container，且已選取 gpt-5.2 等 chat completion model。

  8. project 建立完成後，在新的瀏覽器索引標籤中，下載 lion.jpg 影像，來源為 https://microsoftlearning.github.io/mslearn-ai-vision/Labfiles/content-understanding/lion.jpg ，並將其儲存於本機資料夾。

    接著返回 Content Understanding project，並上傳 lion.jpg 檔案至 project。

1. 出現選擇範本的提示時，選取 Image Analysis ，並確認 schema 設為 Start from Scratch。接著儲存 project。

  1. 影像上傳完成後，在 Schema 窗格中，使用 Add new field 將下列欄位加入 schema：

    Field Name Field Descriptopn Value type Method
    Description Image description String Generate
    Tags Image tags List of Strings Generate
  2. 儲存 schema 的變更。
  3. 選取 Run analysis 以針對影像執行 analyzer，並檢閱產生的欄位；這些欄位應包含準確的描述，以及與影像相關的標籤集合。

  4. 確認 analyzer 傳回的欄位值準確且符合需求後，使用 Build analyzer 按鈕，發佈具有唯一名稱和適當描述的 analyzer。

    提示：稍後會需要此名稱，以在應用程式程式碼中識別 analyzer。

  5. analyzer 建置完成後，前往 analyzer 清單，並確認它已列在其中。
  6. 在清單中選取 analyzer 以開啟它，然後檢視 Code Example 索引標籤，查看使用 analyzer 所需的程式碼。

  7. 檢閱 Python 程式碼範例，留意 main 函式中 Content Understanding resource 的 endpoint ；其格式應類似下列範例：

    https://{your_foundry_resource}.services.ai.azure.com/
  8. 在程式碼範例下方，留意您可以取得 resource key 。您 可以 在用戶端應用程式中使用此 key，驗證連線至 endpoint 的身分；但本練習將使用 Microsoft Entra ID 驗證。

建立影像 analyzer 應用程式

既然已建立 analyzer，接下來建立使用它分析影像的 Python 應用程式。

從 GitHub 取得應用程式檔案

開發影像分析應用程式所需的初始應用程式檔案，已提供於 GitHub repo 中。

  1. 開啟 Visual Studio Code。

  2. 開啟命令選擇區（Ctrl+Shift+P），並使用 Git:clone 命令將 https://github.com/microsoftlearning/mslearn-ai-vision repo 複製到本機資料夾（任意資料夾皆可）。然後開啟它。

    系統可能會提示您確認是否信任作者。

  3. 在 Visual Studio Code 中，檢視 Extensions 窗格；如果尚未安裝，請安裝 Python 擴充功能。

  4. 在 Command Palette中，使用命令 python:select interpreter。如果您已有環境，請選取現有環境，或根據已安裝的 Python 3.1x 建立新的 Venv 環境。

    提示：如果系統提示您安裝相依套件，可以安裝 requirements.txt 檔案中列出的套件，此檔案位於 /labfiles/content-understanding/python 資料夾；不安裝也沒關係，稍後我們會進行安裝！

準備應用程式設定

  1. 複製 repo 後，在 VS Code 中開啟資料夾（File > Open Folder），並瀏覽至 /labfiles/content-understanding/python 資料夾。

  2. 在 VS Code 的 Explorer 窗格中，檢閱資料夾內的檔案：

    • .env —應用程式設定的組態檔。
    • analyze-image.py —影像 analyzer 應用程式的 Python 程式碼檔案。
    • requirements.txt —列出相依套件的檔案。
    • images —包含待分析影像的資料夾。

  3. 在 Explorer 窗格中的 python 資料夾內，選取 .env 檔案以開啟它。接著更新檔案，填入 resource endpoint 的 endpoint 值（從 Content Understanding Studio 中的程式碼範例複製），以及 analyzer 的名稱。

    重要：請務必加入 https://{YOUR-RESOURCE-NAME}.services.ai.azure.com Foundry resource endpoint， 而不是 project endpoint 或 Azure OpenAI endpoint！

    儲存修改後的組態檔。

  4. 在 Explorer 窗格中，以滑鼠右鍵按一下 python 資料夾（其中包含應用程式檔案），並選取 Open in integrated terminal （或在 Terminal 功能表中開啟終端機，然後瀏覽至 /labfiles/content-understanding/python 資料夾）。

    注意：在 Visual Studio Code 中開啟終端機會自動啟用 Python 環境。您可能需要在系統上啟用 script 執行。

  5. 確認終端機目前位於 /labfiles/content-understanding/python* 資料夾，且帶有前綴 (.venv) ，表示您建立的 Python 環境已啟用。

  6. 執行下列命令以安裝必要的 Python 套件：

     pip install -r requirements.txt

撰寫程式碼以分析影像並產生描述

提示：加入程式碼時，請務必維持正確的縮排。

  1. 在 VS Code 中開啟 analyze-image.py 檔案。

  2. 找出註解 Add references ，並加入下列程式碼以匯入必要項目：

    # Add references
from azure.ai.contentunderstanding import ContentUnderstandingClient
from azure.ai.contentunderstanding.models import AnalysisInput, AnalysisResult
from azure.core.exceptions import AzureError
from azure.identity import DefaultAzureCredential
  3. 在 main 函式中，留意已提供從環境檔案取得設定值的程式碼。

  4. 找出註解 Set up Content Understanding client ，並加入下列程式碼：

    # Set up Content Understanding client
credential = DefaultAzureCredential()
client = ContentUnderstandingClient(
     endpoint=endpoint,
     credential=credential,
     api_version=api_version)
  5. 留意已提供讓使用者輸入檔案編號或結束程式的程式碼。

  6. 找出註解 Analyze the file ，並加入下列程式碼：

    # Analyze the file
try:
     poller = client.begin_analyze(
         analyzer_id=analyzer_id,
         inputs=[AnalysisInput(data=file_bytes)],
     )
     result: AnalysisResult = poller.result()
except AzureError as err:
     print(f"[Azure Error]: {err.message}")
     sys.exit(1)
except Exception as ex:
     print(f"[Unexpected Error]: {ex}")
     sys.exit(1)

for field in result.contents[0].fields:
     if field == "Description":
         print(f"{field}:\n{result.contents[0].fields[field].value_string}\n")
     elif field == "Tags":
         print(f"{field}:")
         for tag in result.contents[0].fields[field].value_array:
             print("  -", tag.value_string)

    此程式碼會將選取的檔案資料提交至 analyzer、輪詢結果，然後顯示傳回的 Description 和 Tags 值。

  7. 儲存檔案（Ctrl+S).

測試應用程式

  1. 在終端機窗格中，使用下列命令登入 Azure。

     az login

    注意：在大多數情況下，只要使用 az login 即可。不過，如果您的訂用帳戶分布於多個 tenant，可能需要使用 –tenant 參數指定 tenant。詳情請參閱 使用 Azure CLI 以互動方式登入 Azure 。

  2. 出現提示時，請依照指示登入 Azure。接著在命令列中完成登入程序，檢視（並視需要確認）包含 Foundry resource 的訂用帳戶詳細資料。

  3. 登入後，輸入下列命令以執行應用程式：

     python analyze-image.py

  4. 出現提示時，輸入對應下列其中一張影像的編號：
    1 2 3
  5. 觀察輸出，其中應包含選取影像的描述，以及適當的標籤集合。
  6. 完成後，輸入 1、2、3 以外的任意值以結束。

摘要

在本練習中，您建立了 Foundry resource，並部署內容理解所需的 model。您探索了 Content Understanding Studio 中預先建置的影像 analyzer，接著建立 Python 應用程式，將影像傳送至 analyzer 並擷取生成的描述。做得很好！

清理

完成 Foundry 內容理解的探索後，請刪除已建立的 resource，以避免產生不必要的 Azure 費用。

  • 瀏覽至 Azure portal ，網址為 https://portal.azure.com.
  • 在 Azure portal 的 Home 頁面上，選取 Resource groups.
  • 選取您為本練習建立的 resource group。
  • 在 resource group 的 Overview 頁面頂端，選取 Delete resource group.
  • 輸入 resource group 名稱以確認要將其刪除，並選取 Delete.
