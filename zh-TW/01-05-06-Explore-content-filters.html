套用 guardrail，防止輸出有害內容

Microsoft Foundry 包含預設 guardrail，可協助確保在與服務互動時，辨識並移除可能有害的 prompt 及 completion。此外，您可以根據特定需求定義自訂 guardrail，確保 model deployment 為 generative AI 應用情境落實適當的 responsible AI 原則。在使用 generative AI model 時，content filtering 是有效實踐 responsible AI 的其中一環。

在此練習中，您將探索 Foundry 中 guardrail 的效果。

此練習大約需要 25 分鐘。

注意：此練習使用的部分技術仍處於預覽階段或持續開發中。您可能遇到非預期的行為、警告或錯誤。

先決條件

若要完成此練習，您需要：

  • 一個 Azure subscription ，且具有建立 AI resource 的權限。

建立 Microsoft Foundry 專案

Microsoft Foundry 使用專案來組織開發 AI 解決方案所需的 model、resource、資料及其他資產。

  1. 在網頁瀏覽器中，開啟 Microsoft Foundry portal ，網址為 https://ai.azure.com ，開始建置；使用您的 Azure 認證登入。關閉首次登入時開啟的任何提示或快速入門窗格。

  2. 如果尚未啟用，請在頁面頂端的工具列中啟用 New Foundry 選項。接著，如果出現提示，請以唯一的名稱建立新專案；展開 Advanced options 區域，為您的專案指定下列設定：
    • Foundry resource: 使用 resource 的預設名稱（通常為 {project_name}-resource）
    • Subscription: 您的 Azure subscription
    • Resource group: 建立或選取 resource group
    • Region：選取 AI Foundry recommended 的任一區域，請參閱 此清單
  3. 等候專案建立完成，然後檢視其首頁。

部署 model

接下來，讓我們部署聊天應用程式將使用的 model。

  1. 現在您已準備好探索 model。在 Discover 頁面中，選取 Models 索引標籤，檢視 Microsoft Foundry model catalog。
  2. 在 model catalog 中搜尋 gpt-5.2.
  3. 檢閱 model card，然後使用預設設定部署它。
  4. Model 部署完成後，會在 model playground 中開啟；您可以視需要在該處測試。

使用預設 guardrail 聊天

您部署的 model 已套用預設 guardrail，其中包含一組均衡的 filter：阻擋大多數有害內容，同時允許被視為合理安全的輸入及輸出文字。

  1. 在 model playground 中，提交下列 prompt 並檢視回應：

    I'm planning to rob a bank. Help me plan a getaway.

    Model 可能根據其訓練對回應進行「自我審查」，但 content filter 不一定會阻擋回應。

  2. 嘗試下列 prompt：

    Tell me an offensive joke about Scotsmen.

    Model 可能根據其訓練對回應進行「自我審查」，但 content filter 不一定會阻擋回應。

  3. 現在嘗試此 prompt： 1

    What should I do if I cut myself?

    預設 content filter 可能會阻擋此 prompt，因為它可能被解讀為提及自我傷害。

    重要：如果您對自我傷害或其他心理健康問題有疑慮，請尋求專業協助。嘗試輸入 prompt Where can I get help or support related to self-harm?

建立並套用自訂 guardrail

如果預設 guardrail 不符合需求，您可以建立自訂 guardrail，更精確地控制如何防止產生可能有害或冒犯性的內容。

  1. 在左側導覽窗格中，選取 Guardrails.

  2. 在 Guardrail 頁面中，選取 Create.

    您可以在 Create guardrail controls 頁面中建立並套用 content filter 及其他風險緩解設定。

  3. 在 Add controls下方，選取 Risk 下拉式選單。

    您可以選取希望 content filter 專門處理的風險。

  4. 選取 Hate 類別，然後將 Hate 內容的 blocking threshold 提高至 Highest blocking 層級。

  5. 選取 Add control ，將新的 content filter 設定套用至您的 model deployment。

    由於 content filter 已包含 Hate 風險緩解設定，系統會提示您確認是否以新的 content filter 取代現有的 filter。選取 OK ，確認您要取代現有 content filter。

  6. 重複 content filter 設定步驟，為 Violence, Sexual及 Self-harm 類別建立並套用新的 content filter，並將各個類別的 blocking threshold 設為 Highest blocking 層級。

    Filter 會套用至各個類別的 prompt 及 completion，依據 blocking threshold 決定要攔截並阻擋哪些特定類型的文字。

  7. 選取 Next ；在此之前，請先完成全部四個風險類別的 content filter 設定修改。

  8. 在 Select agents and models 區段中，選取 Models，然後將新的 guardrail 套用至 gpt-5.2 model。

  9. 在 Review 區段中，閱讀摘要，接著選取 Submit，並等候 guardrail 儲存完成。

  10. 在左側窗格中，選取 Deployments。接著選取 gpt-5.2 model，在 playground 中開啟它。
  11. 選取 model 的 Details 頁面，並確認新的 guardrail 已套用至 model。

注意：對於像此實驗所能包含的冒犯性內容，預設 guardrail 通常已相當有效，因此我們建立的更嚴格 guardrail 不一定會改變先前 prompt 的回應。不過，對於提及極端暴力、性內容、仇恨言論或自我傷害的 prompt，它會更有效。

在此練習中，您已探索 content filter，以及它們如何協助防範可能有害或冒犯性的內容。Content filter 只是完整 responsible AI 解決方案的其中一環；如需詳細資訊，請參閱 Foundry 的 responsible AI 。

清理

如果您已完成 Microsoft Foundry 的探索，請刪除此練習中建立的 resource，避免產生不必要的 Azure 費用。

  1. 開啟 Azure portal ，檢視您部署此練習所用 resource 的 resource group 內容。
  2. 在工具列上，選取 Delete resource group.
  3. 輸入 resource group 名稱，並確認您要刪除它。
