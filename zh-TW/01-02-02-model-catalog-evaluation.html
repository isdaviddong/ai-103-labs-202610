探索與比較 model

Microsoft Foundry model catalog 是集中式存放庫，讓您探索及使用各種 model，協助您建置 generative AI 應用情境。在此練習中，您將探索 model catalog、使用 benchmark 比較 model、在 model playground 中測試 model，並使用 synthetic dataset 執行 evaluation。

此練習大約需要 45 分鐘。

注意：此練習使用的部分技術仍處於預覽階段或持續開發中。您可能遇到非預期的行為、警告或錯誤。

先決條件

若要完成此練習，您需要：

  • 一個 Azure subscription ，且具有建立 AI resource 的權限。

建立 Microsoft Foundry 專案

Microsoft Foundry 使用專案來組織開發 AI 解決方案所需的 model、resource、資料及其他資產。

  1. 在網頁瀏覽器中，開啟 Microsoft Foundry portal ，網址為 https://ai.azure.com ，開始建置；使用您的 Azure 認證登入。關閉首次登入時開啟的任何提示或快速入門窗格。

  2. 如果尚未啟用，請在頁面頂端的工具列中啟用 New Foundry 選項。接著，如果出現提示，請以唯一的名稱建立新專案；展開 Advanced options 區域，為您的專案指定下列設定：
    • Foundry resource: 使用 resource 的預設名稱（通常為 {project_name}-resource）
    • Subscription: 您的 Azure subscription
    • Resource group: 建立或選取 resource group
    • Region：選取 AI Foundry recommended 的任一區域，請參閱 此清單
  3. 等候專案建立完成，然後檢視其首頁。

探索 catalog 中的 model

Microsoft Foundry Models 提供可供專案使用的 model catalog。您可以瀏覽 catalog 並比較 model，找出符合需求的 model。

  1. 現在您已準備好探索 model。在 Discover 頁面中，選取 Models 索引標籤，檢視 Microsoft Foundry model catalog。

    Model catalog 列出 Foundry 中所有可用的 model。有些由 Azure 直接提供（透過您的 Azure subscription 計費），其他則由合作夥伴及社群提供。

    請注意，您可以依據 model 名稱、功能及其他條件搜尋及篩選 catalog。

  2. 搜尋 gpt-5.2。接著，在搜尋結果中選取 gpt-5.2 model，檢視其 model card。Model card 提供 model 的相關資訊，協助您判斷是否符合需求。
  3. 閱讀說明，並檢閱 Details 頁面上提供的其他資訊。
  4. 檢視 gpt-5.2 model 的 Benchmarks 頁面，瞭解此 model 在一些標準效能 benchmark 中，與類似應用情境所用的其他 model 相比的表現。
  5. 使用返回箭頭（←，位於 gpt-5.2 頁面標題旁），返回 model catalog。

使用 model leaderboard 比較 model

現在，讓我們使用 model leaderboard 與並排比較功能，以視覺化方式比較 model。

  1. 在 model catalog 頁面中，選取 View leaderboard.
  2. 在 Model leaderboard 頁面中，檢閱依品質、安全性、成本與效能排名的頂尖 model。留意哪些 model 的 AI 品質指標分數最高。
  3. 向下捲動，使用 Trade-off chart 區段，從多個面向比較 model。
  4. 從下拉式選單中選取 Benchmark Cost ，查看 model 品質與成本的關係，然後使用 model 清單比較 gpt-5.2 與 gpt-5-mini。若想進一步探索，您可以加入其他 model 進行比較。
  5. 從下拉式選單中選取 Throughput 指標，查看這些 model 的品質與 throughput 分數的關係。
  6. 從下拉式選單中選取 Safety 指標，查看這些 model 的品質與安全性分數的關係。
  7. 您可以在取捨圖表正上方的表格中比較 benchmark。選取 gpt-5.2 與 gpt-5-mini，也可選取其他想探索的 model，然後使用 Compare models 按鈕，並排檢視它們的 benchmark。
  8. 檢閱下列資料的比較結果：
    • Performance benchmarks：品質、安全性與 throughput 分數。
    • Input 與 output：prompt 與回應支援的格式。
    • Context：對話中可保留及輸出時可產生的 token 數量，以及 model 的訓練時間。
    • Endpoints：用戶端應用程式可透過哪些 API endpoint 使用此 model，以及 agent 是否可使用它。
    • Supported features：您的應用情境可能需要的特定功能。
  9. 使用返回箭頭（←，位於 gpt-5.2 頁面標題旁），返回 model catalog。

部署 model

現在，讓我們部署用於測試及 evaluation 的 model。您需要部署 gpt-5.2 與 gpt-5-mini.

部署 gpt-5.2 model

  1. 在 model catalog 中搜尋 gpt-5.2 並選取它。

  2. 在 model 頁面中，選取 Deploy ，使用 *預設設定部署 model。

    已部署的 model 會在 model playground 中開啟，並在 Model 下拉式清單中處於選取狀態。

  3. 記下指派給 gpt-5.2 model 的 deployment 名稱。稍後您需要辨識此 deployment。

部署 gpt-5-mini model

  1. 在 model playground 的 Model 清單中，選取 Browse more models.

  2. 搜尋 gpt-5-mini，然後選取並部署它。

    此 model 會完成部署，並在 model playground 中處於選取狀態。

  3. 記下指派給 gpt-5-mini model 的 deployment 名稱。

在 model playground 中比較 model

現在您已有兩個 model deployment，讓我們在 playground 中比較它們。

  1. 在 playground 中，確認 gpt-5-mini model 的 deployment 已在 Models 清單中選取，然後在頁面右側的 Compare models 清單中，選取 gpt-5.2 model 的 deployment。

  2. 並排比較檢視會直接開啟，為各個 model 顯示獨立的聊天窗格。為兩個 model 選取 Chat 索引標籤，並輸入下列 prompt：

    I have a fox, a chicken, and a bag of grain that I need to take over a river in a boat. I can only take one thing at a time. If I leave the chicken and the grain unattended, the chicken will eat the grain. If I leave the fox and the chicken unattended, the fox will eat the chicken. How can I get all three things across the river without anything being eaten?

  3. 提交 prompt，並檢視兩個 model 的回應。接著輸入下列後續 prompt：

    Explain your reasoning.
  4. 比較各個 model 的回應。留意正確性、推理品質及回應風格的差異。

使用 synthetic dataset 評估 model

Model playground 適合進行快速手動測試，但若要系統性地評估 model 對大量輸入的表現，可以執行 evaluation。讓我們使用以合成方式產生的旅遊問題 dataset，評估 gpt-5.2 model。

步驟 1：Target

  1. 在 playground 中，選取 Evaluations 索引標籤。
  2. 選取 Create ，開啟 Create new evaluation 精靈。
  3. 針對 evaluation target，選取 Model.
  4. 在 model 表格中，取消選取任何預先選取的 deployment，僅保留 gpt-5.2 的核取方塊，然後選取 Next.

步驟 2：Data

您將使用 Foundry 的 synthetic data generation 功能自動建立測試 dataset，而不是上傳 dataset。

  1. 在 Data 步驟中，於 Dataset source下方選取 Synthetic generation.

    使用 synthetic generation 時，提交 evaluation 後會使用一個 deployment，為各個 target 自動產生問題。

  2. 選取 Generate，然後設定並確認下列項目：
    • Name of the new dataset: 保留預設值
    • Model：gpt-5.2
    • Number of rows: 45
    • Prompt: Create various travel related questions, and include some content safety and security tests
    • Seed data: 保留空白
  3. 選取 Next 以繼續。

步驟 3：Configure models

  1. 在 Configure models 步驟中，設定受評估 model 的 Developer prompt：

     You are a helpful travel assistant that provides accurate, detailed, and practical travel advice to help users plan their trips.

  2. 其他值保留預設值，然後選取 Next.

步驟 4：Criteria

  1. 在 Criteria 步驟中，檢視所有建議的 evaluator。這些 evaluator 使用 AI model 作為評審，評估回應品質。
  2. 移除 Agents 及 Safety下方的所有 criteria，其他 evaluator 則維持啟用。
  3. 選取 Next.

步驟 5：檢閱並提交

  1. 在 Review 步驟中，確認 evaluation 設定，包括 target model、dataset 及選取的 criteria。
  2. 為 evaluation 提供名稱，例如 travel-assistant-eval.
  3. 選取 Submit 以開始 evaluation run。
  4. 等候 evaluation 完成。視資料中心的負載而定，可能需要數分鐘。

檢閱結果

  1. Evaluation 完成後，選取該 evaluation run，檢視結果頁面上顯示的 evaluation 指標概觀。
  2. 在 run 頁面的詳細表格中，檢閱各項 evaluation 的分數與結果。向右捲動並檢視其他頁面，您會看到多數值都通過評估。視 model 的回應而定，可能會出現一些未通過的結果。若有，請仔細檢查。
  3. 選取 Analyze results 按鈕，從下拉式選單選取 gpt-5.2 ，然後選取 Start analysis.
  4. 此頁面會依據失敗原因將未通過的結果分群，讓您查看失敗原因的詳細資料。大多數失敗是因為 model 表示基於問題的性質而無法提供協助；不過，您仍應逐一探索失敗結果，並思考該回應是否符合您的期望。
  5. 檢閱所有失敗結果及 AI 提出的改善建議。這些指引有助於您調整設定，提升表現。

清理

如果您已完成 Microsoft Foundry 的探索，請刪除此練習中建立的 resource，避免產生不必要的 Azure 費用。

  1. 開啟 Azure portal ，檢視您部署此練習所用 resource 的 resource group 內容。
  2. 在工具列上，選取 Delete resource group.
  3. 輸入 resource group 名稱，並確認您要刪除它。
