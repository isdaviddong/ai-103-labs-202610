開發 Voice Live agent

支援語音的 AI agent 可讓使用者以對話方式互動：透過口頭命令與問題，取得語音回應。

在本練習中，您將使用 Azure Speech in Microsoft Foundry Tools 的 Voice Live 功能，建立以語音為基礎的即時 agent。

本練習約需 30 分鐘。

注意：本練習使用的部分技術仍處於預覽階段或積極開發中。您可能會遇到非預期的行為、警告或錯誤。

必要條件

開始本練習之前，請確認您已具備：

  • 有效的 Azure subscription
  • Visual Studio Code 已安裝
  • Python 版本 3.13.xx 已安裝*
  • Git 已安裝並完成設定
  • Azure CLI 已安裝

* Python 3.14 已推出，但部分相依套件尚未針對該版本完成編譯。本實驗已使用 Python 3.13.12 成功測試。

建立 Microsoft Foundry project

Microsoft Foundry 使用 project 來整理開發 AI 解決方案所需的 model、resource、資料及其他資產。

  1. 在網頁瀏覽器中開啟 Microsoft Foundry ，網址為 https://ai.azure.com ，並使用您的 Azure 認證登入。關閉首次登入時開啟的任何提示或快速入門窗格，必要時使用左上角的 Foundry 標誌導覽至首頁。

  2. 如果尚未啟用，請在頁面頂端的工具列啟用 New Foundry 選項。接著，如果出現提示，請建立名稱唯一的新 project；展開 Advanced options 區域，為 project 指定下列設定：

    • Foundry resource: 輸入 AI Foundry resource 的有效名稱。
    • Subscription: 您的 Azure subscription
    • Resource group: 建立或選取 resource group
    • Region：選取任何可用的 region

    注意：請使用建議的 Microsoft Foundry region。可用的 model 與功能可能因 region 而異。

  3. 選取 Create。等待 project 建立完成，然後檢視其首頁。

建立 agent

現在讓我們建立 agent。

  1. 現在您已準備好 Start building。選取 Create agents （或在 Build 頁面選取 Agents 索引標籤），並建立新 agent，名稱為 chat-agent.

    準備完成後，您的 agent 會在 agent playground 中開啟。

  2. 在 model 下拉式清單中，確認已部署並為 agent 選取 gpt-5 model。

  3. 為 agent 設定以下 Instructions:

    You are an AI assistant that helps people find information about AI and related topics. You answer questions concisely and precisely.

  4. 使用 Save 按鈕儲存變更。

  5. 在 Chat 窗格中輸入下列 prompt，以測試 agent：

    What can you help me with?

    agent 應根據其指示提供適當的回答。

設定 Azure Speech Voice Live

為 Foundry agent 啟用語音模式會整合 Azure Speech Voice Live，為 agent 加入語音功能。

  1. 在左側窗格中，於 model 選取清單下方啟用 Voice mode.

    如果 Configuration 窗格未自動開啟，請使用 "齒輪" 圖示（位於聊天介面上方）開啟它。

  2. 在 Configuration 窗格的 Voice Live下方，檢閱預設的語音輸入與輸出設定。您可以試用不同的 voice，逐一預聽後決定要使用哪一個。

  3. 關閉 Configuration 窗格，並使用 Save 按鈕儲存 agent。

使用語音與 agent 互動

現在您已準備好與 agent 聊天。

  1. 在 Chat 窗格中，使用 Start session 按鈕開始與 agent 對話。如果出現提示，請允許存取系統麥克風。

    agent 會開始語音 session，並聆聽您的 prompt。

  2. 當應用程式狀態為 Listening…時，說出類似以下的問題： "How does speech recognition work?" ，並等待回應。

  3. 確認應用程式狀態變更為 Processing…。應用程式會處理語音輸入。

    提示：處理速度可能非常快，因此您還沒看到此狀態，它就已切換回 Speaking.

  4. 當狀態變更為 Speaking…時，應用程式會使用 text-to-speech，將 model 的回應轉為語音。若要以文字查看原始 prompt 及回應，請選取 cc 按鈕（位於聊天畫面底部）。

    提示：只需說話即可提交後續 prompt。您甚至可以打斷 agent，讓互動持續聚焦於您需要完成的工作。您也可以使用 Stop generation 按鈕（位於聊天窗格中）停止長時間執行的回應。此按鈕會結束對話。您需要開始新的對話，才能繼續使用 agent。

  5. 若要繼續對話，只需再提出問題，例如 "How does speech synthesis work?"，並檢閱回應。

  6. 與 agent 聊天結束後，使用 X 圖示結束 session。系統將顯示對話的轉錄文字。

建立 client 應用程式

若要在自訂應用程式中使用 agent，您需要撰寫程式碼，使用 Azure Speech Voice Live SDK 啟動並管理對話 session。

從 GitHub 取得應用程式檔案

  1. 開啟 Visual Studio Code。

  2. 開啟命令選擇區（Ctrl+Shift+P），並使用 Git:clone 命令將 https://github.com/microsoftlearning/mslearn-ai-language repo 複製到本機資料夾（任一資料夾皆可），然後開啟它。

    系統可能會要求您確認是否信任作者。

  3. 複製 repo 後，在 Explorer 窗格中導覽至應用程式程式碼檔案所在的資料夾： /Labfiles/06-voice-live/Python/chat-client。應用程式檔案包括：

    • .env （應用程式設定檔）
    • requirements.txt （需要安裝的 Python 套件相依性）
    • chat-client.py （應用程式的程式碼檔案）

設定應用程式

  1. 在 Visual Studio Code 中檢視 Extensions 窗格；如果尚未安裝，請安裝 Python 擴充功能。

  2. 在 Command Palette中使用命令 python:select interpreter。接著，若已有環境，請選取現有環境；或根據已安裝的 Python 3.13.xx 建立新的 Venv 環境。

    提示：若系統提示您安裝相依套件，可以安裝 requirements.txt 檔案中列出的套件，該檔案位於 /Labfiles/06-voice-live/Python/chat-client 資料夾；但即使現在不安裝也沒關係，我們稍後會安裝！

    提示：如果您偏好使用終端機，可以建立 Venv 環境，使用 python -m venv labenv，然後使用以下命令啟用它： \labenv\Scripts\activate.

  3. 在 Explorer 窗格中，以滑鼠右鍵按一下 chat-client 資料夾（其中包含應用程式檔案），然後選取 Open in integrated terminal （或從 Terminal 選單開啟終端機，並導覽至 /Labfiles/06-voice-live/Python/chat-client 資料夾）。

    注意：在 Visual Studio Code 中開啟終端機會自動啟用 Python 環境。您可能需要允許系統執行 script。

  4. 確認終端機已在 chat-client 資料夾中開啟，且顯示前綴 (.venv) ，表示您建立的 Python 環境已啟用。

  5. 執行下列命令，安裝 Foundry SDK 套件、Azure Identity 套件及其他必要套件：

    pip install -r requirements.txt azure-identity azure-ai-voicelive==1.2.0b4 --pre azure-ai-projects==2.0.0b4

  6. 在 Explorer 窗格的 chat-client 資料夾中，選取 .env 檔案以開啟它。接著更新設定值，填入 Foundry resource 的 endpoint （從 Foundry Portal 的 project 首頁取得 project endpoint，但只使用基本 URL，保留到 .com 網域）、project 名稱及 agent 名稱（應為 Chat-Agent ；請注意此名稱區分大小寫）。

重要：修改貼上的 endpoint，移除 "/api/projects/{project_name}" 後綴；endpoint 應為 https://{your-foundry-resource-name}.services.ai.azure.com.

  1. 儲存修改後的設定檔。

實作應用程式程式碼

  1. 在 Explorer 窗格的 chat-client 資料夾中，開啟 chat-client.py 檔案。

  2. 檢閱現有程式碼。大部分應用程式骨架已提供；您必須實作關鍵步驟，以使用 Voice Live SDK 管理與 agent 的對話。

    提示：將程式碼新增至程式碼檔案時，請務必維持正確的縮排。

  3. 在程式碼檔案頂端、現有 namespace 參考下方，找出註解 Import namespaces ，然後新增下列程式碼，以匯入所需的 namespace：

    # import namespaces
from azure.identity.aio import AzureCliCredential
from azure.ai.voicelive.aio import connect
from azure.ai.voicelive.models import (
    InputAudioFormat,
    Modality,
    OutputAudioFormat,
    RequestSession,
    ServerEventType,
    AudioNoiseReduction,
    AudioEchoCancellation,
    AzureSemanticVadMultilingual,
    AgentConfig
)

  4. 在 main 函式中，請注意已提供從設定檔載入 endpoint 的程式碼，也已提供取得 authentication credential，以及建立並執行 VoiceAssistant 物件的程式碼。

    此 VoiceAssistant 類別封裝了管理 Voice Live 對話的邏輯。

  5. 在 main 函式下方，找出 VoiceAssistant 類別定義。

    此 init 函式已實作完成，可初始化以此類別為基礎的物件。

    您必須實作 start 函式，它是建立對話 session 的核心函式。

  6. 找出註解 STEP 1: Connect Azure VoiceLive to the agent，並新增下列程式碼（請注意將它縮排一層，放在 try: 陳述式之下）：

    # STEP 1: Connect Azure VoiceLive to the agent
async with connect(
    endpoint=self.endpoint,
    credential=self.credential,
    api_version="2026-01-01-preview",
    agent_config=self.agent_config
) as connection:
    self.connection = connection

    此步驟會建立與 agent 的連線，讓 Voice Live SDK 能與它進行對話。

  7. 找出註解 STEP 2: Initialize audio processor，並新增下列程式碼（請注意將它 再縮排一層 ，放在您剛新增的步驟 1 程式碼之下）：

    # STEP 2: Initialize audio processor
self.audio_processor = AudioProcessor(connection)

    此程式碼會附加一個 AudioProcessor 物件，其類別定義位於程式碼檔案更下方。AudioProcessor 是管理音訊硬體 I/O 的公用程式類別。

  8. 找出註解 STEP 3: Configure the session，並新增下列程式碼（請注意維持與上述步驟 2 程式碼相同的縮排）：

    # STEP 3: Configure the session
await self.setup_session()

    此程式碼會設定 session，指定適當的音訊格式、對話輪次偵測語意，以及處理回音與背景噪音的選項。

  9. 找出註解 STEP 4: Start audio systems，並新增下列程式碼（請注意維持與上述步驟 3 程式碼相同的縮排）：

    # STEP 4: Start audio systems
self.audio_processor.start_playback()
        
print("\n✅ Ready! Start speaking...")
print("Press Ctrl+C to exit\n")

    此程式碼會啟動 audio processor，使其監聽麥克風的音訊輸入，並播放音訊輸出。

  10. 找出註解 STEP 5: Process events，並新增下列程式碼（請注意維持與上述步驟 4 程式碼相同的縮排）：

    # STEP 5: Process events
await self.process_events()

    此程式碼會執行主迴圈，以處理語音輸入、回應輸出及中斷等事件。

  11. 儲存程式碼檔案的變更。

    完成後的函式應如下所示：

    async def start(self):
        """Start the voice assistant."""
        print("\n" + "=" *60)
        print(f"🎙️   {self.agent_config['agent_name']}")
        print("="* 60)

        # Add your code in this try block!
        try:
            # STEP 1: Connect Azure VoiceLive to the agent
            async with connect(
                endpoint=self.endpoint,
                credential=self.credential,
                api_version="2026-01-01-preview",
                agent_config=self.agent_config
            ) as connection:
                self.connection = connection
                    
                # STEP 2: Initialize audio processor
                self.audio_processor = AudioProcessor(connection)
                                  
                # STEP 3: Configure the session
                await self.setup_session()
                
                # STEP 4: Start audio systems
                self.audio_processor.start_playback()
        
                print("\n✅ Ready! Start speaking...")
                print("Press Ctrl+C to exit\n")
                
                # STEP 5: Process events
                await self.process_events()

        finally:
            if hasattr(self, 'audio_processor'):
                self.audio_processor.shutdown()

執行應用程式

現在您已準備好執行應用程式，並與 agent 對話。

提示：使用耳麥時，應用程式的效果最佳。使用喇叭時，agent 可能會 "聽到" 自己的回應，並將它們當作新的使用者輸入處理。

  1. 在 Visual Studio Code 終端機中，輸入下列命令以登入 Azure

     az login

    出現提示時，使用您的認證登入 Azure。

    注意：在大多數情況下，僅使用 az login 即可。不過，如果您的 subscription 分屬多個 tenant，可能需要使用 --tenant 參數指定 tenant。請參閱 使用 Azure CLI 以互動方式登入 Azure 以取得詳細資訊。

  2. 在 Visual Studio Code 終端機中，確認 Azure subscription 的詳細資料，然後輸入下列命令以執行 client 應用程式：

    python chat-client.py

  3. 出現提示時，提出問題以開始與 agent 對話，例如 "How is computer speech used in AI?".

  4. 聆聽回應，然後繼續對話；請注意，您可以打斷 agent 並提出新問題。

  5. 完成後，按 CTRL+C 以結束對話並停止程式。

清理資源

如果您已完成 Microsoft Foundry 的探索，請刪除不再需要的 resource，以避免累積不必要的費用。

  1. 開啟 Azure portal ，網址為 https://portal.azure.com ，並選取包含您所建立 resource 的 resource group。
  2. 選取 Delete resource group ，然後 輸入 resource group 名稱 以確認。接著 resource group 將會刪除。
