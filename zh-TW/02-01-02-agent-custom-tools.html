在 AI agent 中使用自訂函式

在本練習中，您將探索如何建立能使用自訂函式作為工具來完成任務的 agent。此 agent 將擔任天文助理，可提供天文事件的資訊，並根據使用者輸入計算望遠鏡租借費用。您將定義函式工具，並實作處理 agent 所發出函式呼叫的邏輯。

提示：本練習使用的程式碼以 Microsoft Foundry SDK for Python 為基礎。您也可以使用 Microsoft .NET、JavaScript 和 Java 的 SDK 開發類似的解決方案。請參閱 Microsoft Foundry SDK client libraries 以取得詳細資訊。

本練習大約需要 50 分鐘才能完成。

注意：本練習使用的部分技術仍處於預覽階段或積極開發中。您可能會遇到非預期的行為、警告或錯誤。

必要條件

開始本練習之前，請確認您已具備以下條件：

  • Visual Studio Code 已安裝於本機
  • 有效的 Azure subscription
  • Python 3.13 已安裝
  • Git 已安裝於本機

* 目前尚不支援 Python 3.14：部分相依套件沒有 3.14 的版本。本實驗已使用 Python 3.13.12 測試。

使用 Foundry Toolkit for VS Code 擴充功能建立 Foundry project

身為開發人員，您可能會花一些時間在 Foundry portal 中操作，但也很可能會花大量時間使用 Visual Studio Code。Foundry Toolkit for VS Code 擴充功能可讓您不必離開開發環境，就能方便地使用 Foundry project 的資源。

  1. 開啟 Visual Studio Code。

  2. 選取 Extensions （位於左側窗格），或按下 Ctrl+Shift+X).

  3. 在擴充功能市集中搜尋 Microsoft 提供的 Foundry Toolkit for VS Code 擴充功能，然後選取 Install.

    安裝 Foundry Toolkit 擴充功能後，VS Code 中就會新增 Foundry Toolkit 擴充功能。

    注意：此擴充功能目前列出的名稱為 Foundry Toolkit，但部分 VS Code 標籤、命令或較舊的螢幕擷取畫面可能仍使用 AI Toolkit這個名稱。在本實驗中，請將這些名稱視為同一個擴充功能體驗。

  4. 安裝擴充功能後，選取側邊欄中的 Foundry Toolkit 圖示。

    如果您尚未登入，系統應會提示您登入 Azure 帳戶。

  5. 選取 Create Project ，位於 Microsoft Foundry Resources.

    如果已有啟用中的預設 project，project 名稱會顯示在 My Resources下。您可以在目前啟用的 project 上按一下滑鼠右鍵，然後選取 Switch Default Project in Azure Extension.

  6. 選取您的 Azure subscription 和 resource group，然後輸入 Foundry project 的名稱，以建立本練習使用的新 project。

    deployment 完成後，您應該會看到此 project 出現在 Foundry Toolkit 窗格中，並設為預設 project。

部署 model

每個 generative AI project 的核心都至少有一個 generative AI model。在此任務中，您將從 Model Catalog 部署一個 model，供 agent 使用。

  1. 當「Project deployed successfully」快顯視窗出現時，選取 Deploy a new model 按鈕。這會開啟 Model Catalog。

    提示：您也可以選取 + 圖示（位於 Resources 區段的 Models 旁），或按下 F1 並執行命令 Foundry Toolkit: Show model catalog.

  2. 在 Model Catalog 中找到 gpt-5 model（您可以使用搜尋列快速找到它）。

  3. 選取 Deploy （位於 gpt-5 model 旁）。

  4. 設定 deployment 選項：
    • Deployment name：輸入名稱，例如「gpt-5」
    • Deployment type：選取 Global Standard （或 Standard ，如果無法使用 Global Standard）
    • Model version：保留預設值
    • Tokens per minute：保留預設值

  5. 選取 Deploy to Microsoft Foundry （位於左下角）。

  6. 等待 deployment 完成。已部署的 model 會出現在 Resources 檢視中的 Models 區段。

  7. 在 project deployment 的名稱上按一下滑鼠右鍵，然後選取 Copy Project Endpoint。在後續步驟中，您需要使用這個 URL 將 agent 連線至 Foundry project。

複製起始程式碼 repository

本練習將使用起始程式碼，協助您連線至 Foundry project，並建立使用自訂函式工具的 agent。

  1. 在 VS Code 中開啟 Command Palette（Ctrl+Shift+P 或 View > Command Palette).

  2. 輸入 Git: Clone 並從清單中選取該命令。

  3. 輸入 repository URL：

    https://github.com/MicrosoftLearning/mslearn-ai-agents.git

  4. 選擇本機上的位置，以複製 repository。

  5. 系統提示時，選取 Open 以在 VS Code 中開啟已複製的 repository。

  6. repository 開啟後，選取 File > Open Folder 並瀏覽至 mslearn-ai-agents/Labfiles/02-agent-custom-tools，然後選擇 Select Folder.

  7. 在 Explorer 窗格中，展開 Python 資料夾，以檢視本練習的程式碼檔案。

  8. 在 requirements.txt 檔案上按一下滑鼠右鍵，然後選取 Open in Integrated Terminal.

  9. 在終端機中輸入下列命令，在 virtual environment 中安裝所需的 Python 套件：

    python -m venv labenv
.\labenv\Scripts\Activate.ps1
pip install -r requirements.txt

  10. 開啟 .env 檔案，將 your_project_endpoint 預留位置替換為您 project 的 endpoint（從 Foundry Toolkit VS Code 擴充功能中的 project deployment 資源複製），並確認 MODEL_DEPLOYMENT_NAME 變數已設為您的 model deployment 名稱。使用 Ctrl+S 儲存修改後的檔案。

現在，您已準備好建立使用 MCP server 工具來存取外部資料來源和 API 的 AI agent。

建立供 agent 使用的函式

  1. 開啟 functions.py 檔案，並檢閱現有的程式碼。

    此檔案包含數個可作為 agent 工具的函式。這些函式會使用位於 data 資料夾中的範例檔案，擷取天文事件和地點的資訊。

  2. 找到註解 Determine the next visible astronomical event for a given location 並新增下列程式碼：

    # Determine the next visible astronomical event for a given location
def next_visible_event(location: str) -> str:
    """Returns the next visible astronomical event for a location."""
    today = int(datetime.now().strftime("%m%d"))
    loc = location.lower().replace(" ", "_")

    # Retrieve the next event visible from the location, starting with events later this year
    for name, event_type, date, date_str, locs in EVENTS:
        if loc in locs and date >= today:
            return json.dumps({"event": name, "type": event_type, "date": date_str, "visible_from": sorted(locs)})

    return json.dumps({"message": f"No upcoming events found for {location}."})

    此函式會檢查範例事件資料，找出從指定地點可觀測到的下一個天文事件，並以 JSON 字串傳回事件詳細資訊。接下來，建立能使用此函式的 agent。

連線至 Foundry project

  1. 開啟 agent.py 檔案。

    提示：新增程式碼時，請務必保持正確的縮排。請以註解的縮排層級作為參考。

  2. 找到註解 Add references 並新增下列程式碼，匯入建立使用函式工具的 Azure AI agent 所需的類別：

    # Add references
from azure.ai.projects import AIProjectClient
from azure.identity import DefaultAzureCredential
from azure.ai.projects.models import PromptAgentDefinition, FunctionTool
from openai.types.responses.response_input_param import FunctionCallOutput, ResponseInputParam
from functions import next_visible_event, calculate_observation_cost, generate_observation_report

    請注意，您在 functions.py 檔案中定義的函式會被匯入，供 agent 作為工具使用。

  3. 找到註解 Connect to the project client 並新增下列程式碼：

    # Connect to the project client
with (
    DefaultAzureCredential() as credential,
    AIProjectClient(endpoint=project_endpoint, credential=credential) as project_client,
    project_client.get_openai_client() as openai_client,
):

定義函式工具

在此任務中，您將定義 agent 可使用的各個函式工具。每個函式工具的參數都以 JSON schema 定義，指定函式每個參數的名稱、型別、描述及其他屬性。

  1. 找到註解 Define the event function tool 並新增下列程式碼：

    # Define the event function tool
event_tool = FunctionTool(
    name="next_visible_event",
    description="Get the next visible event in a given location.",
    parameters={
        "type": "object",
        "properties": {
            "location": {
                "type": "string",
                "description": "continent to find the next visible event in (e.g. 'north_america', 'south_america', 'australia')",
            },
        },
        "required": ["location"],
        "additionalProperties": False,
    },
    strict=True,
)

  2. 找到註解 Define the observation cost function tool 並新增下列程式碼：

    # Define the observation cost function tool
cost_tool = FunctionTool(
    name="calculate_observation_cost",
    description="Calculate the cost of an observation based on the telescope tier, number of hours, and priority level.",
    parameters={
        "type": "object",
        "properties": {
            "telescope_tier": {
                "type": "string",
                "description": "the tier of the telescope (e.g. 'standard', 'advanced', 'premium')",
            },
            "hours": {
                "type": "number",
                "description": "the number of hours for the observation",
            },
            "priority": {
                "type": "string",
                "description": "the priority level of the observation (e.g. 'low', 'normal', 'high')",
            },
        },
        "required": ["telescope_tier", "hours", "priority"],
        "additionalProperties": False,
    },
    strict=True,
)

  3. 找到註解 Define the observation report generation function tool 並新增下列程式碼：

    # Define the observation report generation function tool
report_tool = FunctionTool(
    name="generate_observation_report",
    description="Generate a report summarizing an astronomical observation",
    parameters={
        "type": "object",
        "properties": {
            "event_name": {
                "type": "string",
                "description": "the name of the astronomical event being observed",
            },
            "location": {
                "type": "string",
                "description": "the location of the observer",
            },
            "telescope_tier": {
                "type": "string",
                "description": "the tier of the telescope used for the observation (e.g. 'standard', 'advanced', 'premium')",
            },
            "hours": {
                "type": "number",
                "description": "the number of hours the telescope was used for the observation",
            },
            "priority": {
                "type": "string",
                "description": "the priority level of the observation (e.g. 'low', 'normal', 'high')",
            },
            "observer_name": {
                "type": "string",
                "description": "the name of the person who conducted the observation",
            },                   
        },
        "required": ["event_name", "location", "telescope_tier", "hours", "priority", "observer_name"],
        "additionalProperties": False,
    },
    strict=True,
)

建立使用函式工具的 agent

定義好函式工具後，您就可以建立能使用這些工具完成任務的 agent。

  1. 找到註解 Create a new agent with the function tools 並新增下列程式碼：

    # Create a new agent with the function tools
agent = project_client.agents.create_version(
    agent_name="astronomy-agent",
    definition=PromptAgentDefinition(
        model=model_deployment,
        instructions=
            """You are an astronomy observations assistant that helps users find 
            information about astronomical events and calculate telescope rental costs. 
            Use the available tools to assist users with their inquiries.""",
        tools=[event_tool, cost_tool, report_tool],
    ),
)

傳送訊息給 agent 並處理回應

建立具有函式工具的 agent 後，您就可以傳送訊息給 agent 並處理其回應。

  1. 找到註解 Create a thread for the chat session 並新增下列程式碼：

    # Create a thread for the chat session
conversation = openai_client.conversations.create()

    此程式碼會建立與 agent 的聊天工作階段。

  2. 找到註解 Create a list to hold function call outputs that will be sent back as input to the agent 並新增下列程式碼：

    # Create a list to hold function call outputs that will be sent back as input to the agent
input_list: ResponseInputParam = []

    此清單會在聊天迴圈內建立，讓每一輪對話都從全新的一組函式呼叫輸出開始。

  3. 找到註解 Send a prompt to the agent 並新增下列程式碼：

    # Send a prompt to the agent
openai_client.conversations.items.create(
    conversation_id=conversation.id,
    items=[{"type": "message", "role": "user", "content": user_input}],
)

  4. 找到註解 Retrieve the agent’s response, which may include function calls 並新增下列程式碼：

    # Retrieve the agent's response, which may include function calls
response = openai_client.responses.create(
    conversation=conversation.id,
    extra_body={"agent_reference": {"name": agent.name, "type": "agent_reference"}},
    input=input_list,
)

# Check the run status for failures
if response.status == "failed":
    print(f"Response failed: {response.error}")

    在此程式碼中，您會傳送使用者 prompt 給 agent 並擷取回應。您也會檢查回應是否指出失敗，若是，則印出錯誤。

處理函式呼叫並顯示 agent 的回應

  1. 找到註解 Process function calls 並新增下列程式碼，處理 agent 發出的任何函式呼叫：

    # Process function calls
for item in response.output:
    if item.type == "function_call":
        # Retrieve the matching function tool
        function_name = item.name
        result = None
        if item.name == "next_visible_event":
            result = next_visible_event(**json.loads(item.arguments))
        elif item.name == "calculate_observation_cost":
            result = calculate_observation_cost(**json.loads(item.arguments))
        elif item.name == "generate_observation_report":
            result = generate_observation_report(**json.loads(item.arguments))

        # Append the output text
        input_list.append(
            FunctionCallOutput(
                type="function_call_output",
                call_id=item.call_id,
                output=result,
            )
        )

    此程式碼會逐一檢查 agent 回應中的項目，確認是否有函式呼叫。如果找到函式呼叫，就會擷取對應的函式工具，以提供的引數執行函式，並將結果附加至要傳回 agent 的輸入清單。

  2. 找到註解 Send function call outputs back to the model and retrieve a response 並新增下列程式碼：

    # Send function call outputs back to the model and retrieve a response
if input_list:
    response = openai_client.responses.create(
        conversation=conversation.id,
        input=input_list,
        extra_body={"agent_reference": {"name": agent.name, "type": "agent_reference"}},
    )
# Display the agent's response
print(f"AGENT: {response.output_text}")

    此程式碼會檢查輸入清單中是否有函式呼叫輸出；如果有，則將這些輸出作為輸入傳回 agent，以擷取更新後的回應。最後，它會印出 agent 的回應。

    請注意，輸出會附加至相同的 conversation，因此函式呼叫會在 conversation 狀態中完成處理，並將 agent 的答案儲存至聊天記錄。若改用 previous_response_id 傳回這些輸出，則會使 下一則 訊息失敗，並出現 「No tool output found for function call」.

  3. 找到註解 Delete the agent when done 並新增下列程式碼：

    # Delete the agent when done
project_client.agents.delete_version(agent_name=agent.name, agent_version=agent.version)
print("Deleted agent.")
  4. 檢閱您新增至檔案的完整程式碼。現在應包含執行以下工作的區段：
    • 匯入必要的程式庫
    • 連線至 Foundry project 和 OpenAI client
    • 定義供 agent 使用的函式工具
    • 建立具有這些函式工具的 agent
    • 傳送訊息給 agent 並擷取回應
    • 處理 agent 發出的任何函式呼叫，並將輸出傳回 agent
    • 顯示 agent 的回應
    • 完成後刪除 agent
  5. 完成後，儲存程式碼檔案（CTRL+S）。

執行 agent 應用程式

  1. 在整合式終端機中輸入下列命令，以執行應用程式：

    az login

    python agent.py

  2. 系統提示時，輸入 prompt，例如：

    Find me the next event I can see from South America and give me the cost for 5 hours of premium telescope time at normal priority.

    請注意，此 prompt 要求 agent 使用您定義的兩個函式工具： next_visible_event 和 calculate_observation_cost。agent 能在同一輪對話中呼叫這兩個函式，並使用這些函式呼叫的輸出，為使用者提供有用的回應。

    提示：如果應用程式因超過 rate limit 而失敗，請稍等幾秒後再試一次。如果您的 subscription 沒有足夠的 quota，model 可能無法回應。

    您應該會看到類似下列內容的輸出：

    AGENT: The next astronomical event you can observe from South America is the Jupiter-Venus Conjunction, taking place on May 1st.
The cost for 5 hours of premium telescope time at normal priority for this observation will be $1,875.

  3. 輸入後續 prompt 以產生觀測報告，例如：

    Generate that information in a report for Bellows College.

    您應該會看到類似下列內容的回應：

    AGENT: Here is your report for Bellows College:

- Next visible astronomical event: Jupiter-Venus Conjunction
- Date: May 1st
- Visible from: South America
- Observation details:
    - Telescope tier: Premium
    - Duration: 5 hours
    - Priority: Normal
- Observation cost: $1,875

A formal report has been generated for Bellows College.

    在檔案總管中，您可以看到已建立名為 report-<event-type>.txt 的新檔案，其中包含產生的報告。您可以開啟此檔案以檢視報告內容。

  4. 輸入 quit 以結束應用程式。

    您也可以使用 deactivate 以在終端機中離開 Python virtual environment。

清理

完成探索 Foundry Toolkit for VS Code 擴充功能後，請清理資源，以避免產生不必要的 Azure 費用。

刪除您的 model

  1. 在 VS Code 中重新整理 Azure Resources 檢視。

  2. 展開 Models 子區段。

  3. 在已部署的 model 上按一下滑鼠右鍵，然後選取 Delete.

刪除 resource group

  1. 開啟 Azure portal.

  2. 瀏覽至包含 Microsoft Foundry 資源的 resource group。

  3. 選取 Delete resource group 並確認刪除。
