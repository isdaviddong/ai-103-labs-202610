從多模態內容擷取資訊

在本練習中，您將使用 Azure Content Understanding 從各種內容類型擷取資訊，包括發票、包含圖表的投影片影像、語音留言錄音，以及電話會議的影片錄影。

本練習大約需要 40 分鐘。

建立 Microsoft Foundry resource 和 project

本練習將使用的功能需要 Microsoft Foundry resource 和 project。

  1. 在網頁瀏覽器中，開啟 Microsoft Foundry portal ，網址為 https://ai.azure.com ，並使用 Azure 認證登入。關閉首次登入時開啟的所有提示或快速入門窗格。
  2. 確認 New Foundry 切換開關已開啟，以便使用 Foundry (new).
  3. 如果系統未自動提示建立新的 project，請選取左上角的 project 名稱，然後選取 Create new project.
  4. 為 project 命名，並展開 Advanced options 以指定下列設定：
    • Project name: 為 project 提供有效的名稱
    • Foundry resource: 使用預設值
    • Region：選擇下列其中一個支援的區域：*
      • Australia East
      • East US
      • East US 2
      • Japan East
      • North Europe
      • South Central US
      • Southeast Asia
      • Sweden Central
      • UK South
      • West Europe
      • West US
      • West US 3
    • Subscription: 您的 Azure 訂用帳戶
    • Resource group: 建立或選取 resource group

    *Azure Content Understanding 在特定區域提供服務。最新可用性請參閱 區域支援文件 。

  5. 選取 Create ，並等待 project 建立完成。

下載內容

您將分析的內容位於 .zip 壓縮檔中。請下載並解壓縮至本機資料夾。

  1. 在新的瀏覽器索引標籤中，下載 content.zip ，來源為 https://github.com/microsoftlearning/mslearn-ai-information-extraction/raw/main/Labfiles/content/content.zip ，並將其儲存於本機資料夾。
  2. 將下載的 content.zip 檔案解壓縮，並檢視其中的檔案。您將在本練習中使用這些檔案，探索 Content Understanding analyzer。

注意：如果您只想探索特定模態（文件、影像、影片或音訊）的分析，可以直接跳至下方相關工作。為獲得最佳體驗，請依序完成每項工作，了解如何從不同類型的內容擷取資訊。

在 Microsoft Foundry 中試用預先建置的 analyzer

Azure Content Understanding 包含預先建置的 Read 和 Layout analyzer，可直接從文件擷取文字和結構元素，不需要自訂設定。這些預先建置的 analyzer 在 Foundry (new) portal 中以 AI Services model 的形式直接提供。

在 playground 中使用 Layout analyzer

  1. 在 Microsoft Foundry portal中，確認 New Foundry 切換開關已開啟。
  2. 選取 Build （位於右上角功能表），然後選取 Services （位於左側窗格）。
  3. 確認已選取 Playgrounds 索引標籤，以檢視 Foundry Tools 提供的預先建置 model。

  4. 找出並選取 Content Understanding - Document Layout Analyzer.

    這會開啟 Layout analyzer playground 頁面，您可以在其中使用範例資料或自己的檔案測試 layout model。

  5. 在 playground 中，使用上傳自己資料的選項，從您解壓縮內容檔案的資料夾上傳 invoice-1234.pdf 檔案。此檔案包含下列發票：

  6. 執行 analyzer，並等待分析完成。

  7. 檢閱結果。您可以將擷取的內容以格式化輸出或原始 JSON 資料的形式檢視。留意 Layout analyzer 會從文件擷取文字、表格，以及段落和章節等結構元素。

    注意：預先建置的 OCR/Read 和 Layout analyzer 不需要 generative AI model，即可從文件擷取內容。 OCR/Read 會擷取文字元素（單字、段落、公式和條碼），而 Layout 還會擷取表格、圖形、文件結構、超連結和註釋。這些 analyzer 適合一般用途的內容擷取，但不會擷取發票金額或廠商名稱等特定自訂欄位。

  8. 您也可以返回 Services 索引標籤，使用相同檔案試用 Azure Content Understanding - OCR/Read 以比較結果。留意 Read 只擷取文字，不進行版面配置分析。

設定 Content Understanding Studio 以建立自訂 analyzer

若要從內容擷取特定欄位（例如發票金額、來電者姓名或會議參與者），您需要建置自訂 analyzer。自訂 analyzer 是在 Content Understanding Studio中建立的；這是一個獨立的網頁工具，可用來建置及測試採用自訂 schema 的 analyzer。

  1. 在新的瀏覽器索引標籤中，開啟 Content Understanding Studio ，網址為 https://contentunderstanding.ai.azure.com.
  2. 如果出現提示，請使用登入 Foundry portal 時所用的相同 Azure 認證登入。
  3. 在 Settings 頁面上（或被重新導向至 resource 設定頁面時），選取 + Add resource 按鈕。

  4. 選取先前建立的 Foundry resource，並依序選取 Next > Save.

    提示：確認已勾選 Enable autodeployment for required models if no defaults are available 核取方塊。這可確保 resource 已設定好自訂 analyzer 所需的 GPT-4.1, GPT-4.1-mini和 text-embedding-3-large model。

  5. resource 連線完成後，即可建立自訂 analyzer。在頂端導覽列選取 Content Understanding 以前往首頁。

從發票文件擷取資訊

您將建置自訂的 Azure Content Understanding analyzer，以從發票擷取特定欄位。您將在 Content Understanding Studio 中建立 project、根據範例發票定義 schema，接著建置可重複使用的 analyzer。

建立 storage account

Content Understanding Studio 需要 Azure Blob Storage account，才能儲存用來建置自訂 analyzer 的資料。您需要在與 Foundry resource 相同的 resource group 中建立它。

  1. 在新的瀏覽器索引標籤中，開啟 Azure portal ，網址為 https://portal.azure.com ，並使用 Azure 認證登入。
  2. 選取 + Create a resource，搜尋 Storage account，並建立新的 Storage account resource，使用下列設定：
    • Subscription: 您的 Azure 訂用帳戶
    • Resource group: 與 Foundry resource 相同的 resource group
    • Storage account name: 輸入全域唯一的名稱
    • Region: 與 Foundry resource 相同的區域
    • Preferred storage type：Azure Blob Storage 或 Azure Data Lake Storage Gen 2
    • Performance：Standard
    • Redundancy：Locally-redundant storage (LRS)
  3. 選取 Review + create，然後選取 Create。等待部署完成。

定義發票分析的 schema

  1. 在 Content Understanding Studio 中，選取自訂 project 區段中的 Get started 按鈕，並選取 Create.
  2. 選取 Extract content and fields with a custom schema，然後使用下列設定建立 project：
    • Project name: Invoice analysis
    • Description: Extract data from an invoice
    • Advanced settings
      • Connected resource: 確認已選取您的 Foundry resource
      • Connect storage account: 選取剛建立的 storage account
      • Blob container: 建立新的 container，名稱為 content-understanding

  3. 等待 project 建立完成。

    提示：如果發生存取 storage 的錯誤，請稍候一分鐘再試一次。新 resource 的權限可能需要數分鐘才能生效。

  4. 從您解壓縮內容檔案的資料夾，上傳 invoice-1234.pdf 檔案。

    Content Understanding 會將您的資料分類，並根據上傳的內容建議 analyzer 範本。

  5. 在 Choose a template 視窗中，選取 Invoice 範本，並選取 Save.

    此 Invoice 範本包含發票中常見的欄位。您可以使用 schema 編輯器刪除不需要的建議欄位，並加入所需的自訂欄位。

  6. 在建議欄位清單中，選取 BillingAddress。您上傳的發票格式不需要此欄位，因此請使用 Delete field (🗑）圖示（出現在所選欄位列的末端）將其刪除。
  7. 在 schema 索引標籤頂端的列中，選取 Suggest。這會檢視範例發票，並建議 schema 應包含哪些欄位。展開 Items 欄位，查看建議的子欄位。加入這些欄位會取代現有的 schema，因此若您已在 project 中編輯 schema，請謹慎操作。選取 Save.

  8. 使用 + Add new field 按鈕加入下列欄位，並為每個新欄位選取 Save (✓）：

    Field name Field description Value type Method
    TotalQuantity Total number of items on the invoice String Auto

  9. 確認完成的 schema 如下所示，並選取 Save.

  10. 選取 Test 索引標籤，然後選取 Run analysis 以測試 schema。等待分析完成。

  11. 檢閱分析結果，結果應類似下列畫面：

  12. 在 Fields 窗格中檢視已識別欄位的詳細資料。

建置及測試發票 analyzer

既然已定義從發票擷取欄位的 schema，您便可以建置 analyzer，用於類似的文件。

  1. 選取 Build analyzer 按鈕（位於頂端），並使用下列屬性建置新的 analyzer（請完全依照此處所示輸入）：
    • Name: invoiceanalyzer
    • Description: Invoice analyzer
  2. analyzer 建置完成後，選取 Jump to analyzer list 以檢視所有已建置的 analyzer，然後選取 invoiceanalyzer 連結。畫面將顯示 analyzer schema 中定義的欄位。
  3. 在 invoiceanalyzer 頁面上，選取 Test 索引標籤。

  4. 上傳 invoice-1235.pdf （位於您解壓縮內容檔案的資料夾），並執行分析，從發票擷取欄位資料。

    要分析的發票如下所示：

  5. 檢閱 Fields 窗格，並確認 analyzer 已從測試發票擷取正確的欄位。
  6. 檢閱 Results 窗格，查看 analyzer 將傳回給用戶端應用程式的 JSON 回應。
  7. 關閉 invoiceanalyzer 頁面，以返回 analyzer 清單。

從投影片影像擷取資訊

您將建置自訂的 Azure Content Understanding analyzer，以從包含圖表的投影片擷取資訊。

定義影像分析的 schema

  1. 在 Project list 索引標籤中，選取 Create ，並選取 Extract content and fields with a custom schema，然後使用下列設定建立 project：
    • Project name: Slide analysis
    • Description: Extract data from an image of a slide
    • Advanced settings: 確認設定與上一個 project 相同

  2. 等待 project 建立完成。

  3. 上傳 slide-1.jpg 檔案（位於您解壓縮內容檔案的資料夾）。接著選取 Image analysis 範本，並選取 Save.

    此 Image analysis 範本不包含任何預先定義的欄位。您必須定義欄位，描述要擷取的資訊。

  4. 使用 + Add new field 按鈕加入下列欄位，並為每個新欄位選取 Save changes (✓）：

    Field name Field description Value type Method
    Title Slide title String Generate
    Summary Summary of the slide String Generate
    Charts Number of charts on the slide Integer Generate

  5. 使用 + Add new field 按鈕加入新欄位，名稱為 QuarterlyRevenue ，描述為 Revenue per quarter ，值類型為 List of objects。接著選取值類型下拉式選單旁的表格圖示。在開啟的表格子欄位新頁面中，加入下列子欄位：

    Field name Field description Value type Method
    Quarter Which quarter? String Generate
    Revenue Revenue for the quarter Number Generate

  6. 選取 Back 以返回 schema 最上層，並使用 + Add new field 按鈕加入新欄位，名稱為 ProductCategories ，描述為 Product categories ，值類型為 List of objects。接著選取值類型旁的表格圖示，以開啟表格子欄位的新頁面，加入下列子欄位：

    Field name Field description Value type Method
    ProductCategory Product category name String Generate
    RevenuePercentage Percentage of revenue Number Generate

  7. 選取 Back 以返回 schema 最上層，並確認它如下所示。接著選取 Save.

  8. 選取 Test 索引標籤，然後選取 Run analysis ，並等待分析完成。

  9. 檢閱分析結果，結果應類似下列畫面：

  10. 在 Fields 窗格中檢視已識別欄位的詳細資料，並展開 QuarterlyRevenue 和 ProductCategories 欄位，以查看子欄位值。

建置及測試 analyzer

既然已定義從投影片擷取欄位的 schema，您便可以建置 analyzer，用於類似的投影片影像。

  1. 選取 Build analyzer 按鈕（位於頂端），並使用下列屬性建置新的 analyzer（請完全依照此處所示輸入）：
    • Name: slideanalyzer
    • Description: Slide image analyzer
  2. analyzer 建置完成後，選取 Jump to analyzer list，然後選取 slideanalyzer 連結。畫面將顯示 analyzer schema 中定義的欄位。
  3. 在 slideanalyzer 頁面上，選取 Test 索引標籤。
  4. 使用 + Upload test files 按鈕上傳 slide-2.jpg （位於您解壓縮內容檔案的資料夾），並執行分析，從影像擷取欄位資料。

  5. 檢閱 Fields 窗格，並確認 analyzer 已從投影片影像擷取正確的欄位。

    注意：第 2 張投影片未包含按產品類別劃分的明細，因此找不到產品類別營收資料。

  6. 檢閱 Results 窗格，查看 analyzer 將傳回給用戶端應用程式的 JSON 回應。
  7. 關閉 slideanalyzer 頁面。

  1. 在 Content Understanding Studio 首頁上，選取 Create project （或先使用導覽功能返回首頁）。

    • Project name: Conference call video analysis
    • Description: Extract data from a video conference recording
