開發文字分析 agent

Azure Language in Foundry Tools 支援文字分析，包括 language detection、entity recognition 與 PII redaction。

您可以透過 REST API 及多種語言專屬的 SDK，在應用程式中直接使用此服務。您也可以使用 Azure Language in Foundry Tools MCP server ，將其功能整合至 AI agent，這正是您在本練習中要完成的工作。

本練習所用的程式碼以 Microsoft Foundry SDK for Python 為基礎。您可以使用 Microsoft .NET、JavaScript 與 Java 的 SDK 開發類似的解決方案。請參閱 Microsoft Foundry SDK client libraries 以取得詳細資訊。

本練習約需 30 分鐘。

注意：本練習使用的部分技術仍處於預覽階段或積極開發中。您可能會遇到非預期的行為、警告或錯誤。

必要條件

開始本練習之前，請確認您已具備：

  • 有效的 Azure subscription
  • Visual Studio Code 已安裝
  • Python 版本 3.13.xx 已安裝*
  • Git 已安裝並完成設定
  • Azure CLI 已安裝

* Python 3.14 已推出，但部分相依套件尚未針對該版本完成編譯。本實驗已使用 Python 3.13.12 成功測試。

建立 Microsoft Foundry project

Microsoft Foundry 使用 project 來整理開發 AI 解決方案所需的 model、resource、資料及其他資產。

  1. 在網頁瀏覽器中開啟 Microsoft Foundry portal ，網址為 https://ai.azure.com ，並使用您的 Azure 認證登入。關閉首次登入時開啟的任何提示或快速入門窗格，必要時使用左上角的 Foundry 標誌導覽至首頁。

  2. 如果尚未啟用，請在頁面頂端的工具列啟用 New Foundry 選項。接著，如果出現提示，請建立名稱唯一的新 project；展開 Advanced options 區域，為 project 指定下列設定：

    • Foundry resource: 使用 resource 的預設名稱（通常為 {project_name}-resource）
    • Subscription: 您的 Azure subscription
    • Resource group: 建立或選取 resource group
    • Region：選取任何可用的 region

    注意：請使用建議的 Microsoft Foundry region。可用的 model 可能因 region 而異。

    提示：請記住（或記下）Foundry resource 名稱，稍後您將需要它！

  3. 選取 Create。等待 project 建立完成。

  4. 在 project 首頁上，請注意此處顯示了 API key、project endpoint 及 OpenAI endpoint。

    提示：將 project key 複製到剪貼簿，稍後您將需要它！

建立 agent

您已具備 Foundry project，現在可以建立 agent。

  1. 現在您已準備好 Start building。選取 Create agents （或在 Build 頁面選取 Agents 索引標籤），並建立新 agent，名稱為 Text-Analysis-Agent.

    準備完成後，您的 agent 會在 agent playground 中開啟。

  2. 在 model 下拉式清單中，確認已部署並為 agent 選取 gpt-5 model。

    注意：Instant Inference quota 初始化可能需要一些時間。如果您看到 deployment_disabled ，並伴隨 "Instant inference quota is still being initialized for this subscription"，可以稍候再試，或部署 model 以繼續本練習。在側邊窗格選取 Models ，搜尋 gpt-5，然後選取 Custom deploy。保留預設設定並部署，記下 deployment 名稱以供稍後使用。deployment 完成後，在 agent 的 model 下拉式清單中選取它，儲存並重新嘗試您的 prompt。

  3. 為 agent 設定以下 Instructions:

    You are an AI agent that assists users by helping them analyze text.

  4. 使用 Save 按鈕儲存變更。

  5. 在 Chat 窗格中輸入下列 prompt，以測試 agent：

    What can you help me with?

    agent 應根據其指示提供適當的回答。

建立 Azure Language in Foundry Tools 連線

Foundry 包含 Azure Language in Foundry Tools 的 MCP server，您可以將它連線至 project，並在 agent 中使用。

  1. 在左側導覽窗格中，選取 Tools 頁面。

  2. 在 Tools 頁面中，選取 Tools 索引標籤。

  3. 連線至工具：選取 Azure Language in Foundry Tools （位於 Catalog 中），並將它連線至 endpoint，指定下列設定：

    • Name：工具的唯一名稱/
    • Remote MCP Server endpoint: https://{foundry-resource-name}.cognitiveservices.azure.com/language/mcp?api-version=2025-11-15-preview
    • Parameters：foundry-resource-name： 您的 Foundry resource 名稱
    • Authentication：Key-based：
    • Ocp-Apim-Subscription-Key: 您的 Foundry project 的 API Key

    注意：如果 Azure subscription 中的原則停用了 key-based authentication，您可以使用 Entra ID authentication，將 agent 連線至 Azure Language 服務。

  4. 等待 MCP 工具連線建立完成，然後檢視其詳細資料頁面。

  5. 在 Azure Language in Foundry Tools 連線的詳細資料頁面上，選取 Use in an agent，然後選取先前建立的 Text-Analysis-Agent agent。

    agent 應在 playground 中開啟，並已連線至 Azure Language in Foundry Tools 工具。

    注意：在某些情況下，MCP 工具不會自動新增至 agent。請確認 Azure Language in Foundry Tools 出現在 agent 的工具清單中。如果沒有，請從 agent 的可用工具中手動新增它。

在 playground 中測試 Azure Language 工具

接下來測試 agent 使用您所連線工具的能力。

  1. 在 Text-Analysis-Agent agent 的 agent playground 中，依下列內容修改指示：

    You are an AI agent that assists users by helping them analyze text. Use the Azure Language tool to perform text analysis tasks.

  2. 使用 Save 按鈕儲存變更。

  3. 在 Chat 窗格中輸入下列 prompt，以測試 agent：

    Identify the PII entities in this article, and generate a redacted version:

Microsoft was founded on April 4, 1975, by childhood friends Bill Gates (then 19) and Paul Allen (22) after they were inspired by the Altair 8800, one of the first personal computers, featured on the cover of Popular Electronics. They contacted the Altair’s maker, MITS, and successfully developed a version of the BASIC programming language, despite initially not owning the machine themselves. The pair formed a partnership called “Micro‑Soft” in Albuquerque, New Mexico, close to MITS’s headquarters, with the goal of writing software for emerging microcomputers.

In the late 1970s, Microsoft grew by supplying programming languages to multiple hardware vendors, then relocated to the Seattle area in 1979. A pivotal moment came in 1980 when Microsoft partnered with IBM to provide an operating system for the IBM PC, leading to MS‑DOS and establishing the company’s dominance in personal computing. Gates guided the company’s long-term strategy as CEO, while Allen contributed key technical vision in its early years, setting Microsoft on a path that would reshape the software industry.

  4. 出現提示時，選取 Always approve all Azure Language in Foundry Tools tools 以核准使用 Azure Language 工具（由於 prompt 要求兩項不同的文字分析工作，您可能需要執行此操作兩次）。

    注意：視環境而定，核准工具後偶爾可能出現 403、502 或其他暫時性錯誤。這些錯誤通常不會阻止您繼續。請重新整理頁面，並重試相同的 prompt。

  5. 檢閱回應；它應識別關於 Microsoft 創立過程文章中的任何可識別個人身分資訊，並建立遮蔽這些資訊的文章版本。

  6. 檢閱聊天的 Logs ，確認 agent 已使用 Azure Language 工具處理 prompt。

設定工具核准方式

如同您在 playground 中所見，agent 需要取得核准才能使用工具。

  1. 在 playground 中，找到 Tools 清單（位於 Instructions下方），在您新增的 Azure Language 工具選單中選取 Configure.
  2. 確認 Approval setting for tools in this MCP server for this agent 設定為 Always auto-approve all tools （若不是，請變更設定並新增）。
  3. 儲存 agent 的所有變更。

建立 client 應用程式

您已具備可運作的 agent，現在可以建立使用它的 client 應用程式。

從 GitHub 取得應用程式檔案

  1. 開啟 Visual Studio Code。

  2. 開啟命令選擇區（Ctrl+Shift+P），並使用 Git:clone 命令將 https://github.com/microsoftlearning/mslearn-ai-language repo 複製到本機資料夾（任一資料夾皆可），然後開啟它。

    系統可能會要求您確認是否信任作者。

  3. 複製 repo 後，在 Explorer 窗格中導覽至應用程式程式碼檔案所在的資料夾： /Labfiles/02-language-agent/Python/text-agent。應用程式檔案包括：

    • .env （應用程式設定檔）
    • requirements.txt （需要安裝的 Python 套件相依性）
    • text-agent.py （應用程式的程式碼檔案）

設定應用程式

  1. 在 Visual Studio Code 中檢視 Extensions 窗格；如果尚未安裝，請安裝 Python 擴充功能。

  2. 在 Command Palette中使用命令 python:select interpreter。接著，若已有環境，請選取現有環境；或根據已安裝的 Python 3.1x 建立新的 Venv 環境。

    提示：若系統提示您安裝相依套件，可以安裝 requirements.txt 檔案中列出的套件，該檔案位於 /Labfiles/02-language-agent/Python/text-agent 資料夾；但即使現在不安裝也沒關係，我們稍後會安裝。

    提示：如果您偏好使用終端機，可以建立 Venv 環境，使用 python -m venv labenv，然後使用以下命令啟用它： \labenv\Scripts\activate.

  3. 在 Explorer 窗格中，以滑鼠右鍵按一下 text-agent 資料夾（其中包含應用程式檔案），然後選取 Open in integrated terminal （或從 Terminal 選單開啟終端機，並導覽至 /Labfiles/02-language-agent/Python/text-agent 資料夾）。

    注意：在 Visual Studio Code 中開啟終端機會自動啟用 Python 環境。您可能需要允許系統執行 script。

  4. 確認終端機已在 text-agent 資料夾中開啟，且顯示前綴 (.venv) ，表示您建立的 Python 環境已啟用。

  5. 執行下列命令，安裝 Foundry SDK 套件、Azure Identity 套件及其他必要套件：

    pip install -r requirements.txt

  6. 在 Explorer 窗格的 text-agent 資料夾中，選取 .env 檔案以開啟它。接著更新設定值，填入 project 的 endpoint （可從 Foundry Portal 的 project 首頁取得）及 agent 名稱（應為 Text-Analysis-Agent ；請注意此名稱區分大小寫）。

  7. 儲存修改後的設定檔。

實作應用程式程式碼

  1. 在 Explorer 窗格的 text-agent 資料夾中，開啟 text-agent.py 檔案。

  2. 檢閱現有程式碼。您將新增向 agent 提交 prompt 的程式碼。

    提示：將程式碼新增至程式碼檔案時，請務必維持正確的縮排。

  3. 在程式碼檔案頂端、現有 namespace 參考下方，找出註解 Import namespaces ，然後新增下列程式碼，以匯入所需的 namespace：

    # import namespaces
from azure.identity import DefaultAzureCredential
from azure.ai.projects import AIProjectClient

  4. 在 main 函式中，請注意已提供從設定檔載入 endpoint 的程式碼。接著找出註解 Get project client，並新增下列程式碼，以建立 Foundry project 的 client：

    # Get project client
project_client = AIProjectClient(
    endpoint=foundry_endpoint,
    credential=DefaultAzureCredential(),
)

  5. 找出註解 Get an OpenAI client，並新增下列程式碼，以取得用來呼叫 agent 的 OpenAI client。

    # Get an OpenAI client
openai_client = project_client.get_openai_client()

  6. 找出註解 Use the agent to get a response，並新增下列程式碼，向 agent 提交使用者 prompt 並顯示回應。

    # Use the agent to get a response
prompt = input("User prompt: ")
response = openai_client.responses.create(
    input=[{"role": "user", "content": prompt}],
    extra_body={"agent_reference": {"name": agent_name, "type": "agent_reference"}},
)

print(f"{agent_name}: {response.output_text}")

  7. 儲存對程式碼檔案所做的變更。

測試 client 應用程式

現在讓我們在 Python 環境中執行應用程式，並驗證連線至 project 的身分，以測試應用程式。

  1. 在 Visual Studio Code 終端機中，輸入下列命令以登入 Azure

     az login

    注意：在大多數情況下，僅使用 az login 即可。不過，如果您的 subscription 分屬多個 tenant，可能需要使用 --tenant 參數指定 tenant。請參閱 使用 Azure CLI 以互動方式登入 Azure 以取得詳細資訊。

  2. 出現提示時，請依照指示登入 Azure。接著在命令列完成登入程序，檢視包含 Foundry resource 的 subscription 詳細資料（必要時進行確認）。

  3. 登入後，輸入下列命令以執行應用程式：

    python text-agent.py

  4. 出現提示時，輸入下列 prompt：

    Extract named entities from the following text: "Pierre and I went to Paris on July 14th."

  5. 檢閱回應；它應識別具名人物、地點及日期。

檢視工具詳細資料

Azure Language in Foundry Tools 工具提供多種功能，agent 必須選擇適當的函式來呼叫。我們可以在 agent 的回應中查看可用選項。

  1. 在 text-agent.py 程式碼檔案中，緊接著先前新增的 print(f"{agent_name}: {response.output_text}") 那一行之後（ except Exception as ex: 那一行之前），新增以下一行：

    print(f"\nResponse Details: {response.model_dump_json(indent=2)}")

  2. 儲存程式碼檔案的變更。

  3. 在終端機中，重新輸入執行應用程式的命令（python text-agent.py).

  4. 出現提示時，輸入下列命令：

    Tell me what entities and dates are mentioned in this review, and whether it is positive or negative: "I booked my flight to Paris in July with Margie's Travel, and it was fantastic!"

  5. 檢閱回應（您可能需要向上捲動很長一段距離才能看到）；它應識別 entity 及日期，並判斷文字的 sentiment。

  6. 檢閱 JSON 回應詳細資料，其中列出 agent 可用的各項工具。在此案例中，它應已使用 extract_named_entities_from_text 和 detect_sentiment_from_text 這兩個 Azure Language in Foundry Tools 工具。

清理資源

如果您已完成 Azure Language 服務的探索，可以刪除在本練習中建立的 resource。步驟如下：

  1. 在 Azure portal 中，瀏覽至您在本實驗中建立的 Foundry resource。
  2. 在 resource 頁面上選取 Delete ，並依照指示刪除 resource。
