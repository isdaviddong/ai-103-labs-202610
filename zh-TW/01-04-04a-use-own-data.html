建立使用工具的 generative AI 應用程式

在此練習中，您將使用 Microsoft Foundry portal 與 Responses API 建置 AI 聊天應用程式。接著，您將使用 web_search 與 file_search 工具，將知識整合到應用程式中。

此練習大約需要 30 分鐘。

注意：此練習使用的部分技術仍處於預覽階段或持續開發中。您可能遇到非預期的行為、警告或錯誤。

先決條件

開始此練習之前，請確認您具備下列項目：

  • 有效的 Azure subscription
  • Visual Studio Code 已安裝
  • Python 版本 3.13.xx 已安裝*
  • Git 已安裝並完成設定
  • Azure CLI 已安裝

* Python 3.14 已推出，但部分相依套件尚未針對此版本編譯。此實驗已使用 Python 3.13.12 成功測試。

建立 Microsoft Foundry 專案

Microsoft Foundry 使用專案來組織開發 AI 解決方案所需的 model、resource、資料及其他資產。

  1. 在網頁瀏覽器中，開啟 Microsoft Foundry portal ，網址為 https://ai.azure.com ，開始建置；使用您的 Azure 認證登入。關閉首次登入時開啟的任何提示或快速入門窗格。

  2. 如果尚未啟用，請在頁面頂端的工具列中啟用 New Foundry 選項。接著，如果出現提示，請以唯一的名稱建立新專案；展開 Advanced options 區域，為您的專案指定下列設定：
    • Foundry resource: 使用 resource 的預設名稱（通常為 {project_name}-resource）
    • Subscription: 您的 Azure subscription
    • Resource group: 建立或選取 resource group
    • Region：選取 AI Foundry recommended 的任一區域，請參閱 此清單
  3. 等候專案建立完成，然後檢視其首頁。

部署 model

接下來，讓我們部署聊天應用程式將使用的 model。

  1. 現在您已準備好探索 model。在 Discover 頁面中，選取 Models 索引標籤，檢視 Microsoft Foundry model catalog。
  2. 在 model catalog 中搜尋 gpt-5.2.
  3. 檢閱 model card，然後使用預設設定部署它。
  4. Model 部署完成後，會在 model playground 中開啟。

在 playground 中試用工具

開發聊天應用程式之前，讓我們先探索 model 在 playground 中如何回應。這將協助您瞭解 grounding data 為何重要。

  1. 部署 model 後，您應已進入 playground，且該 model 已選取。如果沒有，請在頂端功能表列中選取 Build ，接著在左側選取 Deployments ，然後選取您部署的 model。

  2. 在 model playground 左側窗格中，確認您的 gpt-5.2 model 已選取。

  3. 在 Instructions 欄位中，輸入下列 prompt：

    You are a travel assistant that provides information on travel services available from Margie's Travel.

  4. 在聊天窗格中，輸入查詢 What are some recommended tourist activities in New York next month? 並檢閱回應。

    回應應相當籠統：model 會根據訓練資料提供一般知識，但無法存取有關下個月 New York 活動的最新資訊。

  5. 在左側窗格的指示下方，於 Tools 區段中選取 Add ，並新增 web_search 工具。

  6. 在聊天窗格中，輸入相同的查詢 What are some recommended tourist activities in New York next month? 並檢閱回應。

    這次，model 會使用 web_search 工具，尋找 New York 活動的最新資訊。

建立使用工具的應用程式

現在您已在 playground 中看到工具如何擴充 model 的功能，讓我們建置用戶端應用程式，使用工具為 Margie’s Travel 顧客提供旅遊建議。

取得 endpoint

您需要 endpoint，才能從用戶端應用程式連線至 model。在此練習中，我們將使用 OpenAI SDK 與 model 聊天，並使用 Azure OpenAI endpoint 搭配 Entra ID authentication 進行連線。

注意：除了 Entra ID authentication，您也可以使用專案的 API Key。只要可行，都應優先使用 Entra ID authentication。

  1. 在功能表列中，選取 Home 頁面。

  2. 記下該頁面顯示的 Azure OpenAI Endpoint 。

    提示：在此練習中，您會使用 Azure OpenAI Endpoint ， 而不是 project endpoint！

從 GitHub 取得應用程式檔案

開發聊天應用程式所需的初始應用程式檔案已提供於 GitHub repo。

  1. 開啟 Visual Studio Code。

  2. 開啟命令選擇區（Ctrl+Shift+P），並使用 Git:clone 命令，將 https://github.com/microsoftlearning/mslearn-ai-studio repo 複製到本機資料夾（任一資料夾皆可），然後開啟它。

    系統可能會提示您確認是否信任作者。

準備應用程式設定

  1. 在 Visual Studio Code 中，檢視 Extensions 窗格；若尚未安裝，請安裝 Python 擴充功能。

  2. 在 Command Palette中，使用命令 python:select interpreter。然後，若已有環境，請選取現有環境；或根據您安裝的 Python 3.1x，建立新的 Venv 環境。

    提示：如果系統提示您安裝相依套件，可以安裝 requirements.txt 檔案中列出的套件，該檔案位於 /labfiles/tools/python/tools-app 資料夾；如果沒有安裝也沒關係，我們稍後會安裝！

  3. 在 Explorer 窗格中，瀏覽至包含應用程式程式碼檔案的資料夾： /labfiles/tools/python/tools-app。應用程式檔案包括：
    • brochures （包含 Margie’s Travel 宣傳手冊的資料夾）
    • .env （應用程式設定檔）
    • requirements.txt （需要安裝的 Python 套件相依項目）
    • tools-app.py （應用程式的程式碼檔案）

  4. 在 Explorer 窗格中，以滑鼠右鍵按一下包含應用程式檔案的 tools-app 資料夾，然後選取 Open in integrated terminal （或在 Terminal 功能表中開啟終端機，並瀏覽至 /labfiles/tools/python/tools-app 資料夾）。

    注意：在 Visual Studio Code 中開啟終端機會自動啟用 Python 環境。您可能需要允許系統執行 script。

  5. 確認終端機已在 /labfiles/tools/python/tools-app 資料夾中開啟，且具有 (.venv) 前綴，表示您建立的 Python 環境已啟用。

  6. 執行下列命令，安裝 OpenAI SDK、Azure identity 及其他必要套件：

     pip install -r requirements.txt

  7. 在 Explorer 窗格的 /labfiles/tools/python/tools-app 資料夾中，選取 .env 檔案以開啟它。接著更新設定值，加入 Azure OpenAI Endpoint 及指派給 gpt-5.2 model 的 deployment 名稱。

    提示：從 Foundry portal 的專案首頁複製 Azure OpenAI Endpoint （不是 project endpoint！），並在 MODEL_DEPLOYMENT 設定中輸入指派給您的 deployment 的完整正確名稱。

    儲存修改後的設定檔。

撰寫程式碼，實作使用工具的聊天功能

  1. 在 Explorer 窗格的 /labfiles/tools/python/tools-app 資料夾中，選取 tools-app.py 檔案以開啟它。

  2. 檢閱現有程式碼。您將新增程式碼，使用 OpenAI SDK 存取 model。

    提示：將程式碼新增至程式碼檔案時，務必維持正確的縮排。

  3. 在程式碼檔案頂端的現有 namespace 參考下方，找到註解 Import namespaces ，並新增下列程式碼，匯入使用 OpenAI SDK 所需的 namespace：

    # import namespaces
from openai import OpenAI
from azure.identity import DefaultAzureCredential, get_bearer_token_provider

  4. 在 main 函式中，請注意已提供從設定檔載入 endpoint 與 key 的程式碼。接著找到註解 Initialize the OpenAI client，並新增下列程式碼，建立 OpenAI API 的 client：

    # Initialize the OpenAI client
token_provider = get_bearer_token_provider(
     DefaultAzureCredential(), "https://ai.azure.com/.default"
)
    
openai_client = OpenAI(
     base_url=azure_openai_endpoint,
     api_key=token_provider
)

  5. 在 main 函式中，找到註解 Create vector store and upload files，並新增下列程式碼：

    # Create vector store and upload files
print("Creating vector store and uploading files...")
vector_store = openai_client.vector_stores.create(
     name="travel-brochures"
)
file_streams = [open(f, "rb") for f in glob.glob("brochures/*.pdf")]
if not file_streams:
     print("No PDF files found in the brochures folder!")
     return
file_batch = openai_client.vector_stores.file_batches.upload_and_poll(
     vector_store_id=vector_store.id,
     files=file_streams
)
for f in file_streams:
     f.close()
print(f"Vector store created with {file_batch.file_counts.completed} files.")

    此程式碼會為 model 建立 vector store，並將宣傳手冊上傳至其中。我們將搭配 file_search 工具使用此 vector store。

  6. 在 main 函式中，請注意已提供持續要求使用者輸入 prompt、直到使用者結束應用程式為止的程式碼。在此迴圈中，找到 Get a response using tools 註解，並新增下列程式碼：

    # Get a response using tools
response = openai_client.responses.create(
     model=model_deployment,
     instructions="""
     You are a travel assistant that provides information on travel services available from Margie's Travel.
     Answer questions about services offered by Margie's Travel using the provided travel brochures.
     Search the web for general information about destinations or current travel advice.
     """,
     input=input_text,
     previous_response_id=last_response_id,
     tools=[
         {
             "type": "file_search",
             "vector_store_ids": [vector_store.id]
         },
         {
             "type": "web_search"
         }
     ]
)
print(response.output_text)
last_response_id = response.id

    此程式碼會提交 prompt，並指定可使用 file_search 工具搜尋 vector store，以及使用 web_search 工具進行一般網頁搜尋。

  7. 儲存程式碼檔案的變更。接著，在終端機窗格中使用下列命令登入 Azure。

     az login

    注意：在大多數情況下，只使用 az login 就足夠。不過，如果您的 subscription 分散在多個 tenant 中，可能需要使用 –tenant 參數指定 tenant。詳情請參閱 使用 Azure CLI 以互動方式登入 Azure 。

  8. 出現提示時，依照指示登入 Azure。然後在命令列中完成登入程序，檢視包含您的 Foundry resource 的 subscription 詳細資料（必要時加以確認）。

  9. 登入後，輸入下列命令執行應用程式：

    python tools-app.py

    程式應會在終端機中執行（如果沒有，請解決所有錯誤後再試一次）。

  10. 出現提示時，輸入 What's happening in San Francisco next month? 並檢閱您的 generative AI model 的回應。

    回應應包含使用 web_search 工具擷取的資訊。

  11. 嘗試下列後續問題： What hotels does Margie's Travel offer there?

    回應應包含使用 file_search 工具擷取的資訊。

  12. 完成後，輸入 quit 以結束程式。

清理

如果您已完成 Microsoft Foundry 的探索，請刪除此練習中建立的 resource，避免產生不必要的 Azure 費用。

  1. 開啟 Azure portal ，檢視您部署此練習所用 resource 的 resource group 內容。
  2. 在工具列上，選取 Delete resource group.
  3. 輸入 resource group 名稱，並確認您要刪除它。
