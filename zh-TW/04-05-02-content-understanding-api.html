開發 Content Understanding 用戶端應用程式

在本練習中，您將使用 Azure Content Understanding Python SDK 建立 analyzer，以從名片擷取資訊。接著您將開發用戶端應用程式，使用 analyzer 從掃描的名片擷取聯絡資訊。

本練習大約需要 30 分鐘。

建立 Microsoft Foundry resource 和 project

本練習將使用的功能需要 Microsoft Foundry resource 和 project。

  1. 在網頁瀏覽器中，開啟 Microsoft Foundry portal ，網址為 https://ai.azure.com ，並使用 Azure 認證登入。關閉首次登入時開啟的所有提示或快速入門窗格。
  2. 確認 New Foundry 切換開關已開啟，以便使用 Foundry (new).
  3. 選取左上角的 project 名稱，然後選取 Create new project.
  4. 為 project 命名，並展開 Advanced options 以指定下列設定：
    • Subscription: 您的 Azure 訂用帳戶
    • Resource group: 建立或選取 resource group
    • Location：選擇下列其中一個支援的區域：*
      • Australia East
      • East US
      • East US 2
      • Japan East
      • North Europe
      • South Central US
      • Southeast Asia
      • Sweden Central
      • UK South
      • West Europe
      • West US
      • West US 3

    *Azure Content Understanding 在特定區域提供服務。最新可用性請參閱 區域支援文件 。

  5. 選取 Create ，並等待 project 建立完成。這會建立 project 及其父 resource。
  6. 建立完成後，選取頁面頂端的 project 名稱，並選取 Project details。在該頁面上，依照連結前往父 resource。請保持此瀏覽器索引標籤開啟。

設定 Content Understanding model 和連線

透過 CU portal 連線至 Foundry

Content Understanding 使用部署於 project 中的 OpenAI model 進行分析。使用 analyzer 前，您需要部署這些 model，並設定 Content Understanding 與 Foundry resource 之間的連線。最簡單的方法是透過 Content Understanding Studio 進行。

  1. 在新的索引標籤中，瀏覽至 Content Understanding Studio ，網址為 https://contentunderstanding.ai.azure.com/home ，並使用您的認證登入。
  2. 選取頂端導覽列的設定齒輪圖示，並選取 + Add resource.
  3. 選取建立 Foundry resource 時所用的訂用帳戶和 resource group，然後從下拉式選單選取 Foundry resource 名稱。此 resource 是您先前建立之 project 的父 resource。
  4. 確認 Enable auto-deployment 核取方塊已勾選，然後選取 Next 和 Save 以建立設定。
  5. 等待系統部署 Content Understanding 所需的 model。

準備開發環境

您將使用 Visual Studio Code 作為開發環境。

  1. 啟動 Visual Studio Code.
  2. 開啟 Command Palette（按下 Ctrl+Shift+P），輸入 Git: Clone，並選取該命令。

  3. 在 URL 列中貼上下列 repository URL，並按下 Enter:

     https://github.com/microsoftlearning/mslearn-ai-information-extraction
  4. 選擇要複製至的本機資料夾，然後在出現提示時選取 Open ，以在 VS Code 中開啟複製的 repository。
  5. 在 VS Code 的 Explorer 窗格中，瀏覽至 Labfiles/02-content-understanding-api。此資料夾包含兩張掃描的名片影像，以及建置應用程式所需的 Python 程式碼檔案。

  6. 開啟新的終端機，並瀏覽至應用程式資料夾：

    cd Labfiles/02-content-understanding-api

  7. 安裝必要的程式庫：

    python -m venv labenv
labenv\Scripts\activate
pip install -r requirements.txt azure-ai-contentunderstanding
  8. 在 VS Code 的 Explorer 窗格中，開啟 .env 檔案，此檔案位於 Labfiles/02-content-understanding-api 資料夾。

  9. 在檔案中，將 YOUR_ENDPOINT 和 YOUR_KEY 預留位置替換為 Microsoft Foundry resource endpoint 和 API key（從您保持開啟的 portal 索引標籤複製），並確認 ANALYZER_NAME 設為 businesscardanalyzer.

    提示：若要取得 endpoint 和 key，您也可以在 Azure portal 中瀏覽至 Microsoft Foundry resource，並檢視 Resource Management > Keys and Endpoint.

  10. 儲存檔案（CTRL+S).

使用 Python SDK 建立 analyzer

現在您將使用 Content Understanding Python SDK 建立 analyzer，以從名片影像擷取資訊。

  1. 在 VS Code 的 Explorer 窗格中，開啟 biz-card.json 檔案並檢閱其內容。此 JSON 定義名片的 analyzer schema，指定要擷取的欄位（Company、Name、Title、Email、Phone）。

  2. 開啟 create-analyzer.py 檔案（在 VS Code 中）。

  3. 檢閱程式碼，其功能如下：
    • 匯入 ContentUnderstandingClient 和 AzureKeyCredential ，來源為 Azure Content Understanding SDK.
    • 從 biz-card.json 檔案載入 analyzer schema。
    • 從環境組態檔擷取 endpoint、key 和 analyzer 名稱。
    • 呼叫名為 create_analyzer的函式，此函式目前尚未實作。

  4. 在 create_analyzer 函式中，找出註解 Create a Content Understanding analyzer ，並加入下列程式碼（請注意維持正確的縮排）：

     # Create a Content Understanding analyzer
 print(f"Creating {analyzer}")

 # Create the Content Understanding client
 client = ContentUnderstandingClient(
     endpoint=endpoint,
     credential=AzureKeyCredential(key)
 )

 # Parse the schema JSON into a ContentAnalyzer object
 analyzer_definition = json.loads(schema)

 # Create the analyzer using the SDK (long-running operation)
 poller = client.begin_create_analyzer(
     analyzer_id=analyzer,
     resource=analyzer_definition,
     allow_replace=True
 )

 # Wait for the operation to complete
 result = poller.result()
 print(f"Analyzer '{analyzer}' created successfully.")
 print(f"Status: {result['status'] if isinstance(result, dict) else 'Succeeded'}")
  5. 檢閱您加入的程式碼，其功能如下：
    • 建立 ContentUnderstandingClient 執行個體，並使用 endpoint 和 API key。
    • 剖析 analyzer schema JSON。
    • 使用 begin_create_analyzer 啟動建立 analyzer 的長時間執行作業。
    • 呼叫 .result() 以等待作業完成。

    注意：SDK 會透過 LROPoller 模式自動處理輪詢，不需要手動輪詢！

  6. 儲存檔案（CTRL+S).

  7. 在 VS Code 終端機中（確認虛擬環境仍處於啟用狀態，且您目前位於 Labfiles/02-content-understanding-api 資料夾），執行 Python 程式碼：

     python create-analyzer.py
  8. 檢閱程式輸出，其中應指出 analyzer 已建立。

使用 Python SDK 分析內容

既然已建立 analyzer，您便可以透過 Content Understanding Python SDK，從用戶端應用程式使用它。

  1. 在 VS Code 中，開啟 read-card.py 檔案。

  2. 檢閱程式碼，其功能如下：
    • 匯入 ContentUnderstandingClient 和 AzureKeyCredential （來源為 SDK）。
    • 指定要分析的影像檔案，預設為 biz-card-1.png.
    • 從環境組態檔擷取 endpoint 和 key。
    • 呼叫名為 analyze_card的函式，此函式目前尚未實作。

  3. 在 analyze_card 函式中，找出註解 Use Content Understanding to analyze the image ，並加入下列程式碼（請注意維持正確的縮排）：

     # Use Content Understanding to analyze the image
 print(f"Analyzing {image_file}")

 # Create the Content Understanding client
 client = ContentUnderstandingClient(
     endpoint=endpoint,
     credential=AzureKeyCredential(key)
 )

 # Read the image data
 with open(image_file, "rb") as file:
     image_data = file.read()

 # Submit the image for analysis
 print("Submitting request...")
 poller = client.begin_analyze_binary(
     analyzer_id=analyzer,
     binary_input=image_data
 )

 # Wait for the analysis to complete
 result = poller.result()
 print("Analysis succeeded:\n")

 # Save JSON results to a file
 output_file = "results.json"
 with open(output_file, "w") as json_file:
     json.dump(dict(result), json_file, indent=4, default=str)
     print(f"Response saved in {output_file}\n")

 # Iterate through the contents and extract fields
 for content in result.contents:
     if hasattr(content, 'fields') and content.fields:
         for field_name, field_data in content.fields.items():
             value = field_data.value if hasattr(field_data, 'value') else None
             print(f"{field_name}: {value}")
  4. 檢閱您加入的程式碼，其功能如下：
    • 建立 ContentUnderstandingClient 執行個體。
    • 以位元組形式讀取影像檔案內容。
    • 呼叫 begin_analyze_binary 以將影像提交至 analyzer（SDK 會自動處理非同步輪詢）。
    • 呼叫 .result() 以等待並擷取分析結果。
    • 儲存 JSON 回應，並剖析擷取的欄位。
  5. 儲存檔案（CTRL+S).

  6. 在 VS Code 終端機中，執行 Python 程式碼：

     python read-card.py biz-card-1.png

  7. 檢閱程式輸出，其中應顯示下列名片的欄位值：

  8. 使用另一張名片再次執行程式：

     python read-card.py biz-card-2.png

  9. 檢閱結果，其中應反映此名片的值：

  10. 若要檢視傳回的完整 JSON 回應，請在 VS Code 中開啟 results.json 檔案，或在終端機中執行下列命令：

     cat results.json

清理

如果您已完成 Content Understanding 服務的操作，請刪除本練習中建立的 resource，以避免產生不必要的 Azure 費用。

  1. 在 Azure portal中，刪除您為本練習建立的 resource group。
